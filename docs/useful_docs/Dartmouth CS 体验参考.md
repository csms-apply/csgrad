# Dartmouth CS 与 Digital Arts：就读体验参考

## 项目介绍

普通 MSCS 和 Digital Arts（CSDA）是两条不同的路。普通 MSCS 现在是两年、7 个 term，可以选 coursework 或 thesis；Digital Arts 必须写论文。想学图形、交互、动画的话，CSDA 很有特色；纯冲找工就没那么省心，艺术课和论文都要占不少时间。

## 选课和 wld

3D Modeling 要做角色模型，Animation 做动画短片，AR/VR 是设计和开发一起合作，喜欢这些方向会学得很有意思。不过图形课里数学和编程都不少，不是会玩几个软件就能过的。2026–2027 的课表里，Animation 在秋季，3D Modeling 和 Rendering Algorithms 在冬季。

2021–2023 年 CSDA 能选的课偏少，OS、compiler 这类基础硬课占了不少位置，算法课还要写数学证明。课少就很难绕开 wld 大的课，当时想轻松上课、剩下时间全拿去刷题，没那么容易。

## 找工和生活

项目小，没有那种大家抱团刷题的氛围，找工信息主要靠自己挖。2022 年赶上大厂 freeze，位置偏、课业压力又大，纯找工的体验并不好。图形方向的课程和研究才是这里更吸引人的地方，但别把 CSDA 直接当普通 MSCS 来选。

Hanover 是真小镇，冬天冷，吃饭选择少，住得远又没车会很麻烦。喜欢 hiking、ski 的人会挺舒服，喜欢热闹大城市的容易憋坏。夏秋景色很好，放假本科生一走又冷清得很，生活跟纽约、波士顿完全是两种感觉。

## CPT（2026-10-11 更新）

COSC295 还在研究生实习课程名单里，但没找到 CS、CSDA 全体学生必修实习的要求。OVIS 目前保留了按课程申请的路径，需要系里签字说明实习和学业的关联，拿到 CPT I-20 之后才能开始。这不代表一定能批，实际办理还要 OVIS 确认。
