# Dartmouth CS 与 Digital Arts：就读体验参考

Dartmouth 的 [CS 研究生项目](https://web.cs.dartmouth.edu/graduate/overview) 包含普通计算机科学与 Digital Arts 方向。[Digital Arts 的课程说明](https://digitalarts.cs.dartmouth.edu/academics) 涉及计算机图形、交互及艺术实践等内容。申请前先确认自己看的是哪条培养路径，再比较课程与导师。

## 小规模项目，需要更具体的匹配

一位 2021 年入学的 CSDA 学生，从第一学期一直更新到毕业后。对选校最有参考价值的线索是：课程作业占用时间较多、可选课范围影响学习计划，小镇居住和交通也会显著影响体验。作者对图形与数字艺术相关训练有肯定，同时对求职信息和社交支持提出了担忧。后期回顾又更认可这段独特生活经历的价值。

因此，不宜把原帖压缩成一句“推荐”或“不推荐”。尤其不能把一位 CSDA 学生的体验，直接套到所有 CS 学生身上。

## 选校时具体比较什么

- **研究匹配**：先找仍在招学生、研究方向吻合的导师，再看项目名气；不要依靠多年前的教师名单判断。
- **课程安排**：把想学的内容对应到近期实际开课记录，确认论文、项目和求职准备能否同时推进。
- **生活与预算**：看具体房源到校园的通勤，以及假期生活安排。用自己的奖学金通知计算费用，不把帖子中的奖学金比例或住宿价格当作现价。
