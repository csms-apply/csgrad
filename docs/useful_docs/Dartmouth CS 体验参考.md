# Dartmouth CS 与 Digital Arts：就读体验参考

## 项目介绍

普通 MSCS 和 Digital Arts 是两条不同路径。现在普通 MSCS 是两年、7 个 term，可以选 coursework 或 thesis；Digital Arts 要写论文。想学图形、交互、动画，CSDA 蛮有特色，纯找工的话没有那么省心，艺术课和论文也要花时间。

## 选课和 wld

3D Modeling 要做角色模型，Animation 做动画短片，AR/VR 有设计和开发合作，喜欢这些方向会学得很有意思。图形课还有不少数学和编程，并不是玩玩软件就能过。2026–2027 的课表里，Animation 在秋季，3D Modeling 和 Rendering Algorithms 在冬季。

2021–2023 年的 CSDA 课程选择偏少，OS、compiler 这些基础硬课占了不少位置，算法课要写数学证明。课少就很难绕开 wld 大的课，想轻松上课、剩下时间全刷题，没那么容易。

## 找工和生活

小项目没有很浓的抱团刷题氛围，找工信息主要靠自己找。2022 年碰上大厂 freeze，偏僻位置加上课业压力，纯找工体验并不好。图形方向的课程和研究更有吸引力，但不能把 CSDA 直接当成普通 MSCS 来选。

Hanover 是真小镇，冬天冷，吃饭选择少，住远了又没车会很麻烦。喜欢 hiking、ski 的人会舒服一些，喜欢热闹大城市的容易憋坏。夏秋景色很好，放假本科生走了以后又会很冷清，生活和纽约、波士顿完全两种感觉。

## CPT（2026-10-11 更新）

COSC295 仍在研究生实习课程名单里，但未找到 CS、CSDA 全体学生必修实习的要求。OVIS 目前保留课程申请路径，需要系里签字说明学业关联，拿到 CPT I-20 才能开始。不能据此保证获批，实际办理仍需 OVIS 确认。
