# USC CS37：转码项目就读体验参考

## 项目介绍

Scientists and Engineers，给理工背景转码的人补 CS 基础。37 学分里面有 4 学分的 455x 编程课，第一学期必修，不算进其余 33 个学位学分。比普通 MSCS 多花时间和学费，补基础的路线也更明确。不设 thesis。

## 选课和 wld

455x 后面接 402 OS，基础要求还有 450 网络或 457 计算机组成，570 算法也是必修。402、450、570 这几门对转码比较有用。想做应用开发可以选 571 Web，585 DB 看着不难，内容在实际开发里用得上。

整体可以选出比较轻的课表，不过补基础的必修占了不少学分，选修没有整个 CS 目录看起来那么自由。2021—2022 年入学时流行的轻 load 组合，也要看具体老师和课程版本。

## 找工和校内岗位

求职导向挺强，海投、刷题和实习经历比较重要，career fair 作用有限。企业实习之外，校内 lab 也有写代码的机会，RA 信息会通过学校邮件发出来。TA、RA 有岗位才有钱，2023 年的 honors 转 TA 经验不能理解成 GPA 到线就自动发工作。

## 生活和 CPT

LA 生活蛮舒服，Koreatown、华人区吃饭选择多，周末也不缺地方去。学校附近、DTLA 和更远的住处各有取舍，通勤和有没有车对体验影响很大。缺点就是贵，37 学分的学费之外还要负担更长时间的生活费。

截至 2026-10-11，USC 只认可全体学生必修的实践。CS37 未见这项毕业要求，597/598 不计学位，不能再把“两次 CPT 实习”当成项目固定福利。
