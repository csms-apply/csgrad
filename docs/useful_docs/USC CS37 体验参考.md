# USC CS37：转码项目就读体验参考

## 补基础，先把几门课的顺序排明白

CS37 的全名是 Computer Science for Scientists and Engineers，面向理工背景、CS 基础有限的学生。37 学分里包含第一学期要上的 CSCI 455x 编程课，它的 4 学分不计入其余 33 个学位学分。之后有 CSCI 402 操作系统、EE 450 网络或 EE 457 计算机组成，再加 CSCI 570 算法。对转码的人，这几门课会占掉相当一部分时间，选修空间没有看到 CS 课程目录时想象得那么大。

455x 要先完成，402 再往后排。入学前能把编程练熟一点，开学后就少一项需要同时应付的事。课程通过以后，想在面试里解释代码为什么这样写，还需要自己补数据结构、做练习。

## 找工选课，也有值得认真上的部分

2021—2022 年入学批次的体验里，整体课业可以给求职留出时间，但具体收获很依赖选课。CSCI 571 Web Technologies 适合缺应用项目的人；CSCI 585 Database Systems 的内容，也值得结合实际开发去学。能用数据库做完作业，和能解释查询、数据组织、系统取舍，差得还挺远。

对刚转码的人，可以先围绕一个方向把项目做完整。准备 SDE，就把代码、测试和调试过程讲清楚；喜欢系统，再继续学网络和操作系统。每门课都浅尝一下，最后简历上课号很多，面试里还是不知道该讲哪个项目。

## 多一点在校时间，也要多算一点钱

较长的学程能让补基础、做项目和投递分开安排。没有企业实习时，校内实验室也是可以尝试的去处，编程能力可能正好能帮上科研项目。学校邮件里的岗位信息值得看，有兴趣的老师可以提前联系，讲清楚自己做过什么、每周能投入多少时间。

TA、RA 要有具体岗位，不能先当成学费减免写进预算。2023 年前后的 honors、助教经验也不是今天照着 GPA 就能兑换的路线。CS37 本身就要修更多学分，再加住宿和生活费，经济上最好能承担完整学程。

LA 的吃饭和周末出行选择很多，Koreatown、华人区和校园附近的生活半径却不一样。租住 DTLA、学校附近还是更远的地方，要连着通勤一起考虑。找工忙的时候，住得方便、能稳定做饭休息，往往比周末能去多少地方更影响每天的状态。

## CPT 按现在的规则安排

截至 2026 年 10 月 11 日，USC OIS 要求实践是项目全体学生的必修内容，普通选修实习不符合条件。CS37 的公开课程要求没有列出全体必修实习，ENGR 597/598 也不计学位，因此不能再把“学程长，可以做两次 CPT 实习”当作既定优势。
