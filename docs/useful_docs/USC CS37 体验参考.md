# USC CS37：转码项目就读体验参考

## 项目介绍

CS37 就是 Scientists and Engineers，专门给理工背景想转码的人补 CS 基础。37 学分里有 4 学分是 455x 编程课，第一学期必修，不算进其余 33 个学位学分。比普通 MSCS 多花时间和学费，换来的是一条更明确的补基础路线。不设 thesis。

## 选课和 wld

455x 之后接 402 OS，基础课里还有 450 网络或 457 计算机组成，570 算法也是必修。402、450、570 这几门对转码挺有用。想做应用开发可以选 571 Web；585 DB 看着不难，内容在实际开发里是真用得上。

课表整体可以排得比较轻，但补基础的必修占掉不少学分，选修没有整个 CS 课程目录看上去那么自由。2021—2022 年入学时流行的那些轻 load 组合，也得看具体老师和课程版本。

## 找工和校内岗位

项目求职导向很强，海投、刷题和实习经历比较关键，career fair 作用有限。除了公司实习，校内 lab 也有写代码的机会，RA 信息会通过学校邮件发出来。TA、RA 得有岗位才有钱，2023 年有过 honors 转 TA 的经验，但不是 GPA 到线就会自动给工作。

## 生活和 CPT

LA 生活挺舒服，Koreatown、华人区吃饭选择多，周末也不愁没地方去。住学校附近、DTLA 还是更远的地方各有取舍，通勤和有没有车对体验影响很大。缺点就是贵，37 学分的学费之外，还要多扛一段时间的生活费。

截至 2026-10-11，USC 只认可全体学生必修的实践训练。CS37 没看到这项毕业要求，597/598 也不计入学位学分，所以“两次 CPT 实习”不能再当成这个项目的固定福利。
