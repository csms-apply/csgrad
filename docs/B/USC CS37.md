# USC CS28

## 项目介绍
两年项目，出了名的只看gpa, class size巨大（除了cs28还有cs37），快一千来号人了

## 录取情况
只看bg和gpa，推荐信optional，rolling制度。
是把所有学校申请人放到一块看gpa，然后按照gpa 从上往下发offer，看重985/211背景。

不看实习不看科研，推荐高gpa 选手拿来保底

## RA转phd机会

很难，usc cs相关专业class size巨大，很难找到RA机会，转博也很难

## 找工情况
一般，主要靠amazon 捞人

1. 电子科技大学cs本科gpa3.79，腾讯两年全职，上岸tt mle
2. 中南政法cs 本科gpa3.84/4, 有美团四个月实习和qd实习，上岸tt intern
3. 印度同学，一年全职，上岸la小厂
4. 印度同学，无实习，上岸amazon intern
5. 西电cs无实习，上岸小厂intern
6. 印度同学，一年全职，上岸amazon intern并且转正

## 选课和 wld

CS28 是老叫法了，2024 fall 起普通 MSCS 无论文方向改成了 32 学分，比以前多一门课。

570 算法挺值得上，偏理论和证明，不是刷题课。571 Web 适合补开发项目，2020—2022 年那版有 Web 和手机端作业，后半段 wld 不小。402 OS 偏硬核，想学系统可以上。585 DB、572 搜索相对好搭配找工，不过 DB 的内容工作以后真用得上，别只当水课。

同一个课号换个老师，体验能差很多，570 的讲法、作业计不计分都有过不同版本。系统课为主的课表和轻 load 的找工课表，读下来完全是两种路数。

## 找工

找工氛围很浓，但投简历、找内推、刷题基本靠自己。学校有 career fair 和 Handshake，有人能从招聘会拿到面试，不过人在 LA 并不会多送你几个面试。2022 年和 2025 年的 ng 行情差很多，以前那种“大厂 offer 随便拿”的说法，放到现在不能当预期。

## 生活

LA 吃喝玩乐是真的多，但有车没车体验差很多。住学校附近、自己做饭，不买车也过得下去；想常跑华人区、周边到处玩，有车方便太多。生活上限挺高，花销也会跟着往上走。

## CPT（2026-10-11 更新）

USC 现在要求实践训练是项目全体学生的必修，选修实习课不够。普通 MSCS 没看到全体必修实习的要求，597/598 也不计入学位学分，以前那套 CPT 实习安排没法直接照搬。
