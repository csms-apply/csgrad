# 转码项目

转码项目分为完全0基础（完全没有修过cs先修课程）和部分0基础转码项目（修过部分cs先修课程），如果一个同学从经济/商科/生物等系，且没有修过诸如数据结构、计算机组成原理、操作系统等先修课，
可以参考[转码同学需要补的专业课](useful_docs/转码需要补的专业课)来进行补课

## 完全0基础转码


1. [NEU CS Align](B/NEU%20CS%20ALIGN.md)
2. [Upenn MCIT](A/Upenn%20MCIT.md)(喜欢名校高gpa，gpa 3.9+比较稳)
3. [Uchicago MPCS](A-/uchicago%20mpcs.md)
4. [USC CS37](B/USC%20CS37.md)
5. [NEU ISB](B-/NEU%20IS.md)
6. [UIUC MSIM](B-/UIUC%20MSIM.md)
7. Columbia CS Bridge
8. NYU TANDON MSCS Bridge
9. [JHU MSECS](A-/jhu%20msecs.md)
10. [CMU MITS](A/cmu%20mits.md)
