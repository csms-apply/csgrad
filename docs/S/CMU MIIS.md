# CMU MIIS

## 项目介绍
LTI开设，主要是就业导向，可以一年半毕业，也可以两年毕业。MIIS开在scs学院下面，
选课优先级很高，可以选到各种CS热门课程，比如Distributed Systems、Operating System 等等，
前两个学期需要强制做researchLTI有分配专门的自习机房，msaii、miis、mcds的同学都可以使用。MIIS找工氛围很好，负责MIIS的advisor很负责，
