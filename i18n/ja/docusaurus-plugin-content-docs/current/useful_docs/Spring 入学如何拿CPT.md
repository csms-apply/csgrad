# Spring入学でCPTを取得するには？

この方法の前提条件は、米国の学部出身であることです。CPTの中心的な要件は、フルタイムで少なくとも1学年（2学期）を修了していることです。
そのため、1年制のSpring入学プログラムに出願する場合や、FallのオファーをSpringに延期（deferral）した場合、たとえばCornell CS MEngやYale MSCS 1 Yearでも、米国の学部出身で
以前に米国で少なくとも1学期連続して在籍したことがあれば（米国の学部出身者はほぼ全員が該当します）、大学院の最初の学期を加えることで
1学年（2学期）の要件を満たせます。

注意すべきなのは、学部のI-20と修士のI-20を新たに発行し直して差し替えてはいけないということです。そうするとCPTを申請できなくなります。正しい方法は、I-20を学部の大学から大学院の大学へtransferすることです。ただし、これには別の問題が生じます。I-20のtransfer要件では、学部のF-1ステータスが終了してから修士のF-1ステータスが始まるまでの空白期間が5か月を超えてはいけません。

では、学部を5月に卒業したのに、Spring入学の修士プログラムが1月開始で、空白期間が5か月を超えてしまう場合はどうすればよいでしょうか？
解決方法は次のとおりです。

1. F-1 Grace Period（60日間の猶予期間）を利用します。学部卒業後も、F-1ステータスはさらに2か月間有効です。

2. 猶予期間が終わる前に、学部のOPTを有効化します（実際には使わなくても構いません）。OPTは最短3か月間有効です。

3. こうすればF-1ステータスを10月まで延ばせ、10月から翌年1月までの空白は3か月だけになるので、I-20のtransfer要件を満たせます。

## そんな面倒な手続きはしたくない。ほかに方法はありますか？
あります。
1. 学部の卒業を1学期延長する
2. 学費の安い大学（例：UIUCやGT）に1学期入学してからtransferする
3. Day 1 CPTの大学に1学期入学してからtransferする
4. OPTのスポンサーになってくれる無給の会社を見つける（OPT期間中はF-1ステータスが維持されます）
