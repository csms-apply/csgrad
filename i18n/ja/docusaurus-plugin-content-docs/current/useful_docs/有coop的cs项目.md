# Co-opのあるCSプログラム

Gatech MSCS

Gatech MS CSE — MSCSとは別の独立した学位で、MSCSプログラムに移る必要はありません。co-opはGT全学のGraduate Co-op Programなので、CSEの学生も参加できます

Duke ECE MEng — 2024年Fallから、プログラムとしてco-opを提供すると発表しました

JHU MSECS（知っている人は少ないですが、友人がJHUにメールで問い合わせたところ、co-op可能との回答がありました）

UCSD ECE／CS75（ECEはco-op可能。CS75も2025年からco-opを提供しています）

NYU Tandon MSCS（春学期にco-op可能）

UT Austin ECE（SES）— co-op可能で、修了を延長することもできます

UIUC MCS（本校、Chicago、さらにSpring入学でも同じ条件で、米国の学部出身でなければ1年後にco-opを申請できます）

UIUC ECE

UW EE PMP（修了を延長せずに、秋学期にフルタイムのco-opが可能）

NEU MSCS
