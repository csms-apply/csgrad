# 成績証明書が出る CS 前提科目の履修方法
[どの CS 前提科目を取るべきか](转码需要补的专业课.md)がわかったら、次のステップは実際にどう履修するかを考えることです。
大事な原則が一つあります。成績証明書が出ない MOOC を受講しても、CS 前提科目を履修したとは認められません。MOOC には成績証明書がなく、出願先の大学はあなたが本当にその授業を受けたのか
確かめる方法がありません。試験があり、単位が出て、正式な成績証明書を発行するプログラムを探す必要があります。

## 正式な成績証明書を発行する機関
1. WGU（実務型の授業で、SDE 志向が非常に強い）
2. University of the People（私の考えでは最もコストパフォーマンスの良い学校で、全分野の授業を提供）
3. ASU Online
4. University of Colorado Boulder Post-Bacc–Applied Computer Science

上記の機関はすべてオンラインプログラムなので、中国の学生でもリモートで受講して正式な成績証明書を受け取りやすいです。
## University of the People

まとめ：本当に気軽に使える「庶民の大学」で、ここで紹介する中で最も安い選択肢です。1 科目わずか $140 です。Databases 1、
Communications and Networking、Software Engineering 1、Data Structures、Discrete Mathematics、
College Algebra、Introduction to Statistics などの基礎科目を提供しています。専攻転向者が前提科目を補うには十分すぎるほどです。


![University of the People のコンピュータサイエンス学位の費用](/img/en/1.png)

## WGU
WGU も素晴らしい選択肢で、Web Development Foundations、Linux Foundations、
Java Frameworks、Data Structures and Algorithms I、Software Engineering、Network and Security - Foundations、Operating Systems for Computer Scientists のように非常に実用的な授業があります。
こちらもおすすめです。

![WGU のコンピュータサイエンスの授業一覧](/img/en/WGUcourses.png)

## ASU Online
学費は 1 学期 $8,451 で、許容できる水準です。Data Structures、Operating Systems、Compilers など必須の授業を提供していますが、やや高いので強くはおすすめしません。

![Arizona State University の学費の目安](/img/en/2.png)
![Arizona State University のオンラインのコンピュータサイエンスの授業](/img/en/3.png)



## University of Colorado Boulder
Computer Systems、Algorithms、Machine Learning、Software Development Methods and Tools、
Computer Science 2: Data Structures、Discrete Structures、Principles of Programming Languages を提供しています。
対面授業もあり、2 つ目の学士号の課程も提供しているので、すでにアメリカにいる学生は対面での受講も検討できます。

![University of Colorado Boulder の科目履修生向けコンピュータサイエンスの授業](/img/en/BoulderCourses.png)
