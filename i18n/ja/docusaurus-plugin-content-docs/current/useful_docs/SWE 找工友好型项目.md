# SWE 就活に強い学校/プログラム

中国国内の秋採用シーズンと米国でのインターン就活を実際に経験し、米国でインターンを探す学生の一部をメンタリングしてきた経験をもとに、身の回りの DataPoints に基づいた就活に強い学校/プログラムについての個人的な観察をまとめます（あくまで就活のしやすさの話で、合格の難易度とは関係ありません。観察した DataPoints が十分かどうかも考慮しています — たとえば MIT CS の卒業生が就活に強いのは明らかですが、私の知る MIT CS の学部生は多くないので、ここには入れていません）。

1. Gatech MSCS/CSE：個人的な印象では、Gatech は就職率が堅調です。私が見てきた MSCS の学生は就活の結果が良く、Meta でも Amazon でも合格した人が多いです。
2. Stanford CS/EE：インターン経験なしでも就職が決まった人をかなり知っています。私の知る Stanford の学生はほぼ全員が NVIDIA の面接を受けられます。ある友人は学科全体に送られた NVIDIA の採用メールを受け取って応募し、30分以内に面接日程が決まりましたが、これは中国で面接日程が決まるスピードに匹敵します。
3. UW EE PMP/HCI：このプログラムは、私の考えでは深刻に過小評価されています。Open CS では B- ですが、就活のしやすさでは A+ をつけるべきだと思います。このプログラムの友人たちは、就活の際に EE と CS の違いをほとんど感じませんでした。EE PMP の学生の多くが Meta と Amazon の面接を受けられます。EE PMP には co-op もあり、2023年には Amazon が UW EE PMP の学生の約10%を採用しました。しかも UW EE PMP の co-op は修了を延長する必要がありません（たとえば 2024 Fall に入学すれば、修了を遅らせることなく2025年8月～11月にインターンができます）。就活に非常に向いています。ソフトウェアの授業だけを選び、ハードウェアの授業は飛ばすこともできます。UW HCI は合格がより難しいですが、6か月のインターンも提供しており、キャンパスでは10単位だけ履修すればよいです。
4. UCSD：CS75 と ECE はどちらも就活に強いです。CS75 は授業の難易度の面で楽な授業を選び、採用シーズンに自分を追い込まずに済みます。ECE には co-op があり、CS75 も2025年から co-op を提供しています。UCSD は NVIDIA のターゲット校でもあります。
5. NEU：就活に強いです — CS Align、MSCS、IS のいずれも co-op を提供しています。LinkedIn のターゲット校でもあります。
6. CMU：私が見てきた DataPoints では、HR はどの学部に所属しているかをあまり気にしません — CMU 所属でさえあれば CS を学んでいると思われます。ビジネススクール出身でもビッグテックに合格した人は多いです。INI/SCS の就職率も堅調で、友人によるとおよそ2/3です。Snowflake や Databricks のような企業は CMU から特別に採用しています。DB の授業を履修していれば、履歴書を集めて面接を組んでくれます。2025年には INI と SCS の new grad の多くが Databricks と Snowflake に入社しました。
7. UT Austin ECE/MSCS：ECE も就活に非常に好意的です。主な理由は、修了を延長でき co-op があるので、学期中にフルタイムでインターンができることです。同級生からのプレッシャーもほとんどありません。ECE SES トラックはコホートあたり10人未満です。2023 Fall 入学の学年では、summer の7人がほぼ全員就職を決めました。
