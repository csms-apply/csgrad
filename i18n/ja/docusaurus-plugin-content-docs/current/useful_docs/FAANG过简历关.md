# FAANGの書類選考を突破する

幸運なことに、今年の25 Summerのインターン探しでは、FAANGのすべての企業から面接の機会をもらい、受けた面接もすべて通過しました（ここではNetflixの代わりにNVIDIAを数えています）。FAANGの書類選考を突破し、VO（virtual onsite）にたどり着く方法を書いておきます。

Facebook（Meta）：HRからのリーチアウトと社内リファラルが重要です。私の知っているMetaに入った人は大きく2つに分かれます。1つ目はHRから直接声がかかった人、2つ目はポジションが公開された直後に先輩に社内リファラルを頼んだ人です。「リファラルなくしてMetaなし」とよく言われます。Metaの社内リファラル制度では、リファラルの申請を14日以内に処理する必要があります。Metaのインターンでリファラルを探すなら、ポジションが公開されたらすぐに動きましょう。2024年9月末には、Metaはポジションを公開したあと、インターンのリファラルを数日間しか受け付けず、すぐに受付を締め切りました。

Apple：履歴書のマッチ度がとても重視されます。チームのメンバーが自分たちの仕事に合っていると判断した場合にだけ面接が組まれます。私は以前Edgeで拡張機能（extension）の開発をしており、このチームはSafariの拡張機能を担当していたので、面接を組んでもらえました。

Amazon：社内リファラルはあまり役に立たず、ポジション公開の初日に応募するほうが効果的です。Amazonがポジションを公開したかどうかは、GitHubのインターン情報リポジトリで確認できます。OAはとても簡単で、難しいのはOAを受け取ることと、OAのBQパートです。コーディングパートはいつも簡単です。BQパートは、YouTubeでSoroushがまとめている動画や掲示板で共有されている資料が参考になります。1つのBQ回答で、LP（Leadership Principles）を2〜3個押さえるのが理想です。

Netflix：面接の機会を得た人をほとんど見たことがありませんが、報酬は非常に高く、インターンの時給は約$110です。

Google：社内リファラルが比較的効きますが、運の要素も大きいです。私個人のデータポイントでは、2024年6月にGoogleのインターンに手当たり次第応募したものの音沙汰がありませんでした。10月に先輩に強く推薦してもらって改めて応募したところ、OAが届きました。

プロジェクト、履歴書、面接の準備方法については、私の個人ページに固定しているインターン探しの体験談を参考にしてください。面接や履歴書の個別指導が必要な場合も、お気軽にご連絡ください。
