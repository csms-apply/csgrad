# 2026 Summer 米国就活タイムライン
2025年1月～6月：中国でインターンを探す

2025年6月～8月：Google、DE Shaw、Citadel など、2026 summer の SDE インターン枠を早めに開く企業に応募

2025年9月～12月：面接。TikTok のような企業は早めに面接の案内を送ってきます。オファーをもらえたら、ゆっくり休んで構いません。

2026年1月～3月：面接。オファーをもらえたら、ゆっくり休んで構いません。3月までに決まらなければ、中国でのインターンの機会を探し始めてください。

2026年3月～5月：休んで楽しむ。

2026年5月～8月：インターン。return offer を目指しましょう。

2026年8月～12月：New grad の面接。
