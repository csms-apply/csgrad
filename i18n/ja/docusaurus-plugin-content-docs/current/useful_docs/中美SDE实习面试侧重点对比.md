# SDEインターン面接の重視点比較：米国 vs. 中国


## 米国：
評価されるポイント：
1. 運
2. アルゴリズム問題
3. 行動面接（BQ）
4. プロジェクトの詳細

夏季インターンの応募スケジュール：
通常は入学前年の8月から翌年の3月までです。選考プロセスはとても長く、4〜5か月かかることもあります（例：Google）。面接後、結果が出るまで少なくとも2週間待つのが一般的です。

上の評価ポイントは、重要度の高い順に並べています。米国のSDE面接では、運とアルゴリズム問題の比重が最も大きくなります。運は、HRがあなたの履歴書を見て面接に声をかけてくれるかどうかを左右します。アルゴリズム問題の習熟度は、面接に通るかどうかを左右します。面接で出るアルゴリズムの難易度は、おおむね中国と同程度です。中国のSDE面接と比べると、プロジェクトの詳細はあまり重視されず、たいていは「最も誇りに思うプロジェクトは何ですか？」といった行動面接の質問で確認される程度で、深い追加質問はありません。面接全体の焦点はアルゴリズム問題です。一般的な流れは、問題の言い直し → 例を使った確認 → コードを書く → 時間計算量の分析です。面接中に沈黙が続いてはいけないので、コードを書きながら話し続ける必要があります。社内リファラルは面接の機会を得るのに役立ちます（私も社内リファラルで小規模企業の面接を1件得ました）。BQはとても重要で、Amazonなど一部の企業ではオファーの有無を直接左右することもあります。BQは、YouTubeの動画や掲示板の資料にあるLP（Leadership Principles）のフレームワークで対策できます。




## 中国：
評価されるポイント：
1. インターン経験
2. プロジェクト
3. CSの基礎（OS、Computer Networks、MySQL、Redis）
4. アルゴリズム問題

夏季インターンの応募スケジュール：
通常は同じ年の3月から5月までです。準備ができたら応募すればOKです。中国の選考プロセスは非常にスピーディーで、比較的早く（2週間以内に）勤務を開始することを求められるのが一般的です。

上の評価ポイントは重要度の高い順に並べていますが、アルゴリズム問題が解けなければその時点で不合格です。面接時間の大半はインターン経験とプロジェクトの話に費やされます。面接は通常、技術面接3回＋HR面接1回で、技術面接が2回の場合もあります。米国と比べて技術面の評価はより深く、ビジネスの詳細に関する質問が多くなります。たとえばインターン経験が検索／広告／レコメンド分野なら、コールドスタート問題や、大規模データをどう保存するか、リアルタイム性をどう確保するかなどを聞かれることがあります。行動面接の質問は基本的にありません。ただしAlibaba系企業の面接は例外で、HRの権限が大きく、候補者を直接不合格にすることもあります。アルゴリズムのパートでは、通常コードを書きながら説明する必要はなく、最適解を書ければ十分です。社内リファラルは面接の機会を得るのに役立ちません。
