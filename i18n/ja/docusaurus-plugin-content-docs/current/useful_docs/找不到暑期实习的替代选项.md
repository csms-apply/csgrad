# 2025年に米国の SWE 夏季インターンが見つからないときの代替案

今年、米国で SWE の夏季インターンが見つからなかった場合は、中国でのインターンの機会を検討してみましょう。
たとえば Microsoft China、Optiver、Alibaba Cloud、Tencent WXG、NVIDIA、Google Shanghai などは、すでに採用を始めています。

1. Microsoft：中国国内での採用がすでに始まっています。私が指導した学生のデータポイントによると、米国留学の経歴がある人や中国のトップ大学（Hua-5 レベル以上）の出身者を好む傾向があります。私の知る Microsoft Suzhou のインターン生の経歴は、1）Tsinghua の学部＋GT の修士 2）Xi'an Jiaotong の学部＋Duke の修士 3）Shanghai Jiaotong の学部＋修士 4）Tongji の学部＋修士などでした。学歴をとても重視します。1次面接の面接官が「hire」をつければ合計2ラウンドだけで、そうでなければ3ラウンドです。
2. GSoC：Google が主催するオープンソースプログラムで、知名度が非常に高く、競争も非常に激しいです。報酬は高く、米国水準の報酬を受け取るには CPT を使う必要があります。報酬は主にコミュニティでの存在感（social presence）、PR、プロジェクト提案書（proposal）で評価されます。CPT がなければ中国水準の報酬しか受け取れません。履歴書では大きな強みになります。
3. Open Source Summer（OSPP）：中国科学院（Chinese Academy of Sciences）が主催しており、こちらも知名度が高いです。GSoC ほど競争は激しくありませんが、プロジェクト提案書は丁寧に作り込む必要があります。誰がプロジェクトを担当するかは主に提案書で決まります。
4. Alibaba Cloud：Alibaba Cloud は通常、ほぼどの大手企業よりも早く採用を始めます（今年は例外で、WXG が最初でした）。例年、Gateway チームや Luoshen Networking チームなどさまざまなチームが春節（旧正月）明けすぐに採用を始めます。985大学または有力な211大学（例：BUPT、Xidian）の学部卒であることを厳しく求めており、これを満たさないとオファーを得るのは非常に難しいです。米国にいる学生は、春節明けに Boss Zhipin や Nowcoder をチェックしてみてください。これらのプラットフォームで採用を行っています。適任だと判断されれば早めに面接が組まれ、オファーも早く出ます。複数のチームの面接を同時に受けて、一番合うと思うチームを選ぶこともできます。Alibaba Cloud の夏季インターンからの return の割合は非常に高いです。
5. WXG（WeChat）：夏季インターンは面接ラウンドが多く、技術スタックは C++ です。1次面接は通常アルゴリズム問題4問です。通過すると、その後のすべてのラウンドでプロジェクトについて徹底的に掘り下げられるため、履歴書のあらゆる細部を把握しておく必要があります。アルゴリズム問題を解けるのは第一歩にすぎず、大切なのは技術的な細部を理解し、明確に説明できることです。
