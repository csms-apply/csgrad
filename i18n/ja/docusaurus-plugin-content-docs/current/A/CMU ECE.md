# CMU ECE

## プログラム概要
最短1.5年、最長2年で、延長はできません。各学期、最低36 units、最大48 units まで履修できます。1学期通しの授業は12 units、mini 授業（半学期）は6 units です。修了には97 units が必要です（Standard プログラム、3学期、2026-27 学年度時点）：ECE core 60 units、CIT 選択科目 24 units、General Technical Electives 12 units、さらに Introduction to Graduate Studies 1 unit です。

ECE トラック自体は低レイヤー/ハードウェア寄りですが、CMU は CS へのキャリアチェンジの一大拠点なので、ECE にも CS 色の強い授業の選択肢がたくさんあります。ソフトウェアに転向したいなら、授業選択は十分に可能です -- 実際の CS 修士よりも純粋な CS の時間割を組むことさえできます。ただしその分、CMU 名物の過酷なカリキュラムを覚悟しておく必要があります。SCS の単位制限はありますが、純粋な CS の授業も履修できます。多くの ECE の授業は CS 学科とクロスリストされており、18613 と 15513（CSAPP）、18741（Computer Networks）、ACC、Storage Systems などがその例で、いずれも SCS の単位制限にはカウントされません。ECE 学科の開講授業数は非常に多く、INI の約3倍あり、おおよそ1/3がシステム系、1/3が ML 系、1/3がハードウェア系の授業です。なので、ECE の授業選択が INI より制限されているとは思いません。ただ、ソフトウェアエンジニアリング系の授業はやや少なめです -- 今のところ見つけられたのは Intro to SE と Full Stack くらいです。また、CMU は作業量が非常に多いです。私は学部でしっかりした CS の基礎がありましたが、それでも lab のために徹夜することがよくありました。CS へのキャリアチェンジ組にはかなり大変かもしれません。

隣の INI と大きな違いはありません。むしろプログラム名に "computer" が入っているので、CS っぽく見えるくらいです。（でも誰も気にしていません -- どちらの学科も就職率が高く、選べる CS の授業も多いので良いことです。）

授業は素晴らしいですが、生活は本当に疲れます。学期中は lab や project に膨大な時間がかかるので、LeetCode 対策にも影響が出るかもしれません。

## 学業のプレッシャー

CMU の授業の進度は、中国の学部よりはるかにハードです。1学期目は課題が絶対に終わらない気がするほどで、締め切りがカレンダーを埋め尽くします。CMU は「頑張れば簡単に A が取れる」場所ではありませんが、真面目に勉強すれば B 以上は十分に取れます。

私の勉強スケジュールはだいたい「10-2-7」でした -- 朝10時から夜中の2時まで、週7日です。健康的な生活リズムを保てる人もいますが、現実には日中は授業 + 就活 + 宿題で、自由な時間はほとんどありません。効率が良ければ深夜0時前に寝られるかもしれませんが、全体としては「夜更かし」というより「宿題が本当に終わらない」という感じです。

大学院が学部と一番違うのは、入学してすぐにインターン/就職活動を始めなければならないことです -- 学業と就活を並行して進める必要があります。私はひどい先延ばし癖があって、1学期目に大きな代償を払いました。入学予定の方には、早めに計画を立て、学業が落ち着くのを待ってから動き出すようなことはしないようアドバイスしたいです。

## PhD への転籍

PhD に興味があるなら、ECE は素晴らしい選択だと思います。CS 学科の教授の多くが ECE 学科とクロスリストされています（そのため学内での PhD 転籍も可能になります -- 要件を満たした ECE 修士の学生は、理論上 PhD に転籍できます。私の知り合い2人が現在この道を進んでいますが、転籍できるのは ECE とクロスリストされている教授のもとだけです。たとえば、ECE とクロスリストされている RI の教授のもとで研究してきて、その教授が同意し、要件も満たしていれば、ECE の PhD に転籍して RI の学生と同じ研究室で働けます）。また、このプログラムでは学期ごとに授業2つを research の単位に置き換えることができます。全体として、研究に興味がある人にとって良い選択肢だと思います。（注：公式の Incoming MS FAQ には、現在 MS ECE から PhD ECE プログラムへ直接転籍する選択肢はなく、修士の学生も PhD プログラムに正式に出願して入学審査を受ける必要があると明記されています。上記の友人の例は、今すぐ直接転籍できることを意味するものではありません。）
