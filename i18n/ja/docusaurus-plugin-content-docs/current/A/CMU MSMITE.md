# CMU MSMITE


## プログラム概要
正式名称は Master of Science in Mobile and IoT Engineering です。CS の学位名ではありませんが、大きな問題ではありません。就職は主に本人の経験と履歴書のマッチ度で決まりますし、オンラインで求人に応募するときも専攻は CS としか書けないからです。
MSMITE は最初の 2 学期を Pittsburgh で過ごし、その後 Silicon Valley に移ります（2026-27 年度の公式サイトによると、Standard オプションは CMU-SV で 1 学期、Advanced オプションは 2 学期）。異なる 2 つの土地を経験できるのはなかなか良いです。授業選択はとても柔軟で、楽に過ごすことも難しい授業を取ることもでき、成長の自由度は十分です。1 学期の practicum も可能で、NASA や Adobe などの企業と連携でき、履歴書に書けます。
就職実績は堅実です。詳しくは公式レポートをご覧ください（実際の数字はレポートより良いはずです。INI には、一度オファーを報告すると変更できないという厄介な方針があり、後でより良いオファーをもらっても切り替えられません。そのため、すべてのオファーが確定してから報告する学生もいます）。主な就職先（Top Employers）：NVIDIA、Amazon、Apple、TikTok。

INI 内の各プログラムの結果を見ると、大きな差はありません。結局、米国に来てみると、就職結果の約 95% は本人の努力とマクロ経済の状況で決まることがわかります。
残りの 5% が、学校のリソースと履修科目によるものです。

## 授業選択
22 Fall から、MSMITE の degree-specific core に SCS の授業が追加されました：
Distributed Systems、Advanced Cloud Computing (ACC)、Cloud Computing (CC)。
この 3 科目は 24 ユニットの選択科目枠にカウントされなくなったため、浮いた単位で他の SCS の授業（例：15445）を取れます。

1. 15213：伝説の CSAPP。ほぼすべてのシステム系授業の前提科目です。夏学期または最初の学期に履修できます。負荷は中程度です。SDE 志望の学生の大半が履修し、HCI の学生もこの授業は必修です。
2. 15440：Distributed Systems。就職に役立ちます。INI 学科が開講する DS は取らないよう注意してください。授業の質が SCS 版に及びません。
3. 14776：ビジネス/マネジメント系の楽な授業です。出席して宿題をこなすだけで A が取れます。タスクは多いものの、実際の負荷は重くありません。負荷のバランスが取れた時間割は、このガイドの後半で提案しています。
4. 15619：Cloud Computing。定番の授業です。負荷は非常に重いです。評価は大きく分かれます。ラボでは多くの技術を扱います。時間と労力をたくさん費やしたのに、プロジェクトで 0 点になったとネットで不満を述べる学生も多いです。
5. 18709/15719：Advanced CC。CC の負荷軽減版です。就職活動の学期には CC の代わりに ACC を取れば、LeetCode 演習や面接対策の時間を確保できます。
6. 10714：Deep Learning Systems。PyTorch の実装を自分で作ります。とても実践的な授業です。この授業を取ると NVIDIA との相性が非常に良くなります。
