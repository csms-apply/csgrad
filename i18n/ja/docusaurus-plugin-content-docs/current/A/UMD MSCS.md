# UMD MSCS


## プログラム概要
UMDはCSのランキングが非常に高く、AIで2位、NLPで7位、Visionで8位です。
MSCSは研究志向のプログラムです。MSとPhDの志願者が同じプールで審査されるため、PhDへの移行を考えている学生には理想的です。修士の学生にとっては就職活動のサポートが比較的少なく、学科内のLeetCode対策や就職活動の雰囲気も比較的弱めです。一般的に、合格した学生はTA／RAのポジションを見つけられます。学部生が非常に多くTAが必要なため、TAのポジションのほうが多く、ほぼ全員が得られます。
ただし公式サイトには、MSへの合格は資金援助（funding）を保証するものではないと明記されています。CMSCのTAは時給制の仕事で、給与は出ますが授業料免除（tuition remission）も健康保険もありません。graduate assistantshipとしての任用になるのはRAのポジションだけです（2026-27学年度の公式サイトに基づく）。

UMDは研究が非常に強く、就職実績もまずまずのプログラムです。採用人数が少なく、研究経験を大きく重視します。Fall入学は特に競争が激しく、UMDの学部出身者のSpring入学は比較的容易です。

## 合格ラインとデータポイント
Redditには「UMD MSCSは毎年定員が約20人で、約2K人が出願する」と書かれています。
平均GPAは3.8です。このプログラムは研究を最も重視します。トップカンファレンスの論文や非常に強力な推薦状があれば、合格に大きく有利になります。合格した中国人学生の大半は米国の学部出身です。中国本土出身者は、かなり強いスペックが必要かもしれません。清華大学／北京大学の学部出身者や上位の985大学の学生、数年の職務経験がある人、トップカンファレンスの筆頭著者論文がある人が合格するのは珍しくありません。18 Fallには、MSとPhDを合わせて2000人以上が出願しました。約190件のオファー／合格が出され、最終的に79人が入学しました。内訳はMS 19人、PhD 60人です。具体的には、MSの合格率は約4%、PhDの合格率は約20%でした。入学者のうち、中国、インド、米国の学生がそれぞれ約30%を占め、ヨーロッパ＋その他が10%でした。
