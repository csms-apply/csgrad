# Yale MSCS 1 year

## プログラム概要
Yale のブランド力は最高レベルです。MSCS 1-year は 1 学期または 1 年の入学延期を認めています。

アメリカの学部出身であれば、1 学期延期して Spring に入学し CPT を得る方法を試せます。これは 1 年制プログラムでインターンができないというよくある問題を解決してくれます。詳しい手順は [Spring 入学で CPT を得る方法](../useful_docs/Spring%20入学如何拿CPT.md)を参照してください。CPT 承認の具体的な詳細は、必ず学校に改めて確認してください。


## 合格ラインと Data Points
実質的には加重 GPA 計算機です。以前は GRE 328 で厳格に足切りされていました。最近は緩和の兆しが見られ、325 で合格した data point もあります。
ZJU は feeder school です。以前は CS＋ZJU-UIUC joint プログラムだけで 20 人以上が合格したこともありました。インターンや研究は考慮されません。プログラムは公式に「研究は必須ではない」と明言しています。GPA、学部の出身校、TOEFL、GRE だけを見ます。

1. アメリカの学部、Top 100、CS、GPA 3.92
2. UW-Madison CS+Math 学部、GPA 3.9
3. University of Hartford CE、GPA 3.97
4. UIUC Math+CS、GPA 3.91
5. UCSB CS 学部、GPA 4.0、中国の小規模企業でのインターン複数回
6. NYU CS 学部、GPA 3.95、GRE 332
7. UW CS 学部、GPA 3.9

## 就職実績と Data Points
普通です。主な理由は、アメリカでのインターン経験がないと new grad のポジションを得るのが非常に難しいからです。就職は主に TikTok と Amazon の採用頼みです。24 Fall の new grad の就職率は 10%〜15% でした。全体として、同じ 1 年制プログラムの UCB EECS MEng ほどは良くありません。

就職に成功した data point の一部：
1. Wuhan University CS 学部、中国の TikTok で 1 年インターン、修了と同時に TikTok の new grad に就職
2. Wuhan University Software Engineering 学部、Ant Group で 4 か月インターン、2 Sigma に就職
3. Tulane University Math+CS 学部、インターンなし、小規模企業に就職
4. NYU 学部、Baidu のインターン経験、AWS の new grad に就職
5. UW CS 学部、AWS のインターン経験、DoorDash の new grad に就職
6. Waterloo 学部、カナダの小規模企業で 4 か月インターン、Google の new grad に就職
7. Yale CS 学部、スタートアップでの 3 年の経験と小規模企業でのインターン、Google の new grad に就職
