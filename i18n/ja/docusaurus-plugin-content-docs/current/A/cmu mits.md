# CMU MITS

## プログラム概要
SCS、CIT、IPS が共同で運営する joint プログラムです。（実際のところ、気にする人はいません。CMU では MSCS を除けば、他のプログラム間の評判の差は個人差に埋もれてしまいます。）

## 4 つのトラック
Software and Networked Systems、Data Analytics、Information Security、Technology Strategy & Governance

## 授業
非常に柔軟です。その気になれば、MSCS/DS の履修計画のように時間割をほぼ SDE 中心で組めます。とても楽に組んで、すぐに LeetCode の問題演習を始めることもできます。いわば Pittsburgh 版の NEU です。今年の就職実績を見ると CMU の評判は依然として非常に高く、プログラム間に目立った差はありません。しかも Adobe、Apple、NVIDIA、Databricks などの一部の企業は CMU で直接採用を行っています。

授業選択の柔軟性と優先度はどちらも非常に高いです。
SDE を目指す学生は Software and Networked Systems トラックを選べば、1 学期の上限単位（51 units）の範囲内で SCS の伝説的なシステム系の授業を自由にすべて取れますが、負担のバランスには注意が必要です。MLE を目指す学生は、Data トラックで同じくトップクラスのデータ系の授業をほぼすべて取れます。CS へ専攻を転向する場合：可能です。データ構造から始めれば大丈夫です。ただ個人的には、アメリカに着いてすぐ面接を受けられるよう、中国で LeetCode の問題演習を終えてから来ることをおすすめします。

プログラムには capstone もあり、UW EE PMP の capstone に少し似ていて、企業と一緒にプロジェクトを進めます。

後半の学期には、希望する SCS の授業にほぼすべて入れます。授業選択に制限はなく、たとえば次のような授業があります。
15640 Distributed System
15619 Cloud Computing
17637 Web Application Development

## 合格情報
学費は比較的高めで約 $85K です。合格ラインは妥当で、GPA 3.8+ に speaking のスコアが 25 あれば可能性は非常に高いです。選考の過程で speaking のテストを受ける可能性が高いです。speaking のスコアが 25 未満なら必ずテストがあり、25 点でも受けることがあります。メールで面接日程の調整の連絡が来ます。
