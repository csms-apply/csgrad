# Columbia MSCS
Columbia MSCS の評判を弁護するための記事です。以前、多くの人がネット上で Columbia CS に関する古いネガティブな投稿を読み、このプログラムはよくないと思い込んでいました（投稿者は 2 か月後にはすでに Google に就職していました）。

この記事では 1. 就職の評価 2. トラック 3. 授業の感想 4. 合格情報 5. 費用 の順に、Columbia MSCS プログラムをできるだけ客観的に紹介します。

## 就職の評価
真剣に就職活動をし、毎日応募していた人はほぼ全員が仕事を見つけています。オファーの大半は大企業からです（ビザのスポンサーをしてくれるのは大企業だけだからです）。

周りでは Adobe、TikTok、Meta、Amazon、NVIDIA、Databricks からインターンのオファーをもらった人がいます。Columbia が書類選考に与える効果はまずまずのようです。私の知っている学生は Citadel、Jane Street、D.E. Shaw、Bloomberg、Meta、Stripe、TikTok、WeRide、Five Rings などから virtual onsite を受けています。学部時代に比較的大きな会社（TikTok/Alibaba/Google/Microsoft）でインターン経験があれば、上で挙げたクオンツ企業＋大手テック企業の面接は、少なくとも 1/3 くらいは通るでしょう。私の知る Columbia MSCS の学生で Amazon の virtual onsite を受けた人は、全員が面接に合格しました。また、Columbia は Bloomberg の社内評価システムで ROI の高い学校に分類されており、直接採用に来ます（2022 年には大量に採用していきました）。Columbia MSCS を担当する Meta の HR もとても熱心です（Columbia MSCS 担当の Meta リクルーターは S ティア校も一緒に担当しています）。メールの返信が早く、24 Fall の募集が始まった初日に、多くの Columbia MSCS の学生へ new grad とインターンの面接の連絡を自ら送ってきたのは本当に印象的でした。

ただし、Columbia CS の就職活動の雰囲気は決して強くありません。キャリアフェアには Bloomberg しか来ず、学部のキャリアフェアには大学院生は参加できないなど、全体的にサポートが不足しています。



## トラック
Columbia CS には 10 以上のトラックがあります。最も人気があるのは Software Systems と Machine Learning で、私は前者を選びました。Machine Learning トラックは必修科目が少なく、より柔軟です。Software Systems トラックは制約が多いものの、授業内容はほぼすべて SDE に関連しています。履歴書の送付＋LeetCode＋面接対策＋授業を同時にこなす必要があるなら、負担は決して軽くありません。

thesis トラックもあり、thesis トラックを選ぶと 2 年制のプログラムになります。研究を指導してくれる教授は自分で探す必要があります。2 年に延長でき、うまくいけば PhD に移行することもできます。



## 授業の感想
ネット上の多くの投稿では Columbia は課題量がとても多いと言われていますが、私はやや偏った見方だと思います。Columbia でも楽な授業だけで十分に時間割を組めます。負担は重くも軽くもできます。以下は私と友人が受けた授業の一部です（また、そうした投稿に出てくる履修登録の難しさや長すぎる waitlist は、私は経験したことがありません。楽な授業でも負担の大きい授業でも、受けたい授業にはすべて入れました）。

1. Operating Systems：SS トラックの必修科目。課題量が非常に多いです。すでに就職が決まっている場合にだけおすすめします。1 科目分の単位で 3 科目分の内容を学びます。ただし、この授業をしっかり身につけておくと quant dev の面接で大いに役立ちます。Kostis のクラスは取らないでください。講義中に「like like like」と言い続け、1 文に「like」が 6 回も入ります。Stanford の PhD 出身ですが講義についていくのが難しく、アメリカ人の学生も何を言っているのかわかりません。Jae のクラスを取りましょう。その教授は素晴らしいそうです。（Kostis 教授のための弁明をひとこと：Kostis 教授はトゥレット症候群があり話し方にチックがあるため、言葉を発する前に長く間が空くこともあります。この授業はスライドと課題が中心で、講義は補足に近いものです。Kostis 教授はとても親切な方で、Ed の多くの質問に自ら回答し、学生の悩みや授業体験を心から気にかけています。私の知る限り、Kostis 教授の試験は Jae 教授ほど難しくありません。そもそも授業資料はすべてもともと Jae 教授のものです。Jae 教授は SS トラックの関門と言える存在です。）
2. Programming Language Translators：SS の必修科目。課題量は普通です。プロジェクトはコンパイラ作りです。試験の難易度は中国の大学の多くのコンパイラの授業より低めです。1 学期目に取っても大丈夫です。
3. Cloud Computing：楽な授業。1 学期目に取るのがベストです。課題はほとんどありません。
4. Introduction to Database：楽な授業。これも 1 学期目に取るのがベストです。内容は中国の大学のデータベースの授業と同様で、SQL の記述＋第 1/2/3/4 正規形です。その学期を完全に楽に過ごして就職活動に集中したいなら Donald のクラスを取りましょう。この教授は学期の途中で Ed に「バックエンドを確認したら 300 人中 40 人しか出席しておらず、平均接続時間は 30 分、録画を見たのは 3 人だけだ」と、誰も授業に来ないことに怒ったりします。それでもこの授業の負担はとても軽いままです。Wu 教授など別の講師だと課題が多く難しいので、すでに就職が決まっている場合に取るほうがよいでしょう。
5. Distributed Systems：MIT の授業とまったく同じです。採点がとても甘いです。プロジェクトは MIT のものをそのまま流用（良い意味で）＋Columbia 独自のプロジェクト 1 つです。SDE の就職にとても役立ちます。良い授業です。
6. Competitive Programming：LeetCode/Codeforces の集中トレーニング。課題量が非常に多いです。アルゴリズムの授業よりも面接向けの内容です。
7. Advanced Software Engineering：SS の必修科目。課題量は普通です。Java でフルスタックのプロジェクトを作り、Google Cloud にデプロイします。
8. UI Design：楽な授業。React を学び、フルスタックのプロジェクトを作ります。最近、面白いアイデアを思いつきました。interview coder を作ることです。
9. Advanced Algorithm：学部のデータ構造・アルゴリズムとは**まったく関係ありません**。この授業は 1 文でまとめられます。**P > P_r** のときに成り立つ randomized algorithm を設計せよ。「数学的アルゴリズムにおける確率・統計の応用」と名前を変えてもいいくらいです。OS と同時に取らないでください。
10. Artificial Intelligence：主に AI と ML の入門です。基礎があれば難しくありません。概念の課題 5 つとコーディング課題 5 つ、中間・期末試験があります。やや手間はかかりますが、採点はまずまずです。ML トラックの必修科目としておすすめです。
11. Applied Machine Learning：楽な授業で、課題量も軽めです。コーディング課題 5 つ、中間試験 1 回、グループプロジェクトがあります。採点も良いです。おすすめです。
12. Software as a Service：Advanced Software Engineering と同じく SS トラックの必修科目ですが、どちらか一方を取れば十分です。Junfeng Yang 教授が担当しており、とても良い先生です。授業内容は Ruby と Rails です。学期前半は Ruby と Rails の実習課題が中心で、後半はグループプロジェクトの進捗報告と発表で進みます。


授業の選び方次第では、Columbia MSCS の授業は決して楽ではありません。私が受けたすべての授業（UI、SE、NLP、AI などを含む）で、教授は実際に内容を教えてくれ、スライドを読み上げるだけの人は一人もいませんでした。授業資料もとても詳しいです。授業の質は心配しなくて大丈夫です。

## 合格情報
中国人が 40%、インド人が 40%、残りはアメリカ人です。

合否は主に GPA で決まります。中国本土の学部出身者に求められる GPA は比較的高く、アメリカの学部出身者の基準は相対的に低めです。インド人学生の多くは各地の IIT や VIT の出身で、GPA は 10 点満点で 9.1〜9.2 程度です。たいてい 2 年の職務経験があります。



## 費用


ネット上の費用情報も正確ではありません。それほど高くはありません。学校に払う金額は約 $80K（学費＋各種手数料＋保険など）です。Manhattan の家賃は月約 $2,000 です。このプログラムは 16 か月なので、$80K + $2,000 x 16 + $1,000 x 16 = $128K となり、CMU とほぼ同じです。

2025.2 更新：最近、友人たちも Jump Trading、HRT、NVIDIA、Databricks、Amazon、Datadog で面接を受けました。D.E. Shaw も Columbia から何人か早めに選んで正社員の面接を行いました。要するに、学校が足かせになることはありません。履歴書に大企業でのインターン経験があれば、上で挙げた会社の半分ほどで面接を受けられるでしょう。

また、半年住んでみて New York City がますます好きになりました。活気にあふれ、ダウンタウンにはレストランや楽しめる場所がたくさんあります。Broadway の公演はほぼ毎日満席です。ここではより彩り豊かな生活を経験できます。真剣に検討することを強くおすすめします。結局のところ、New York こそが最高の大学です。

## TA/RA の機会
TA の時給は約 $24 で、週 10 時間までに制限されています。月に約 $950 です。TA になるための条件はそれほど高くありませんが、次の条件があると大きく有利です。第一に、その授業で優秀な成績（A または A+）を取っていること。第二に、関連する授業や職務の経験があること。この条件を満たす学生は多く、最終的に誰が選ばれるかは教授次第です（なので、ある程度は運です）。CS の TA は必ずしも CS 専攻である必要はなく、主にその授業がどれだけ幅広い学生を対象としているかによります。他専攻の学生でも、その授業で A を取っていればその授業の TA になれることがあります。

RA については、無給の RA ポジションはかなり簡単に見つかりますが、有給のポジションは非常にまれです（ほぼないに等しいですが、資金が特に潤沢な PI に出会う可能性も否定できません）。周りで有給 RA のオファーをもらった人は見たことがありません。Columbia CS では PhD への移行は教授の承認さえあればよいので、指導教員と相性が合えば PhD への移行は問題になりません。PhD を目指すなら Columbia は真剣に検討する価値があると思います。Columbia CS の PhD 学生の経歴を見ると、ほぼ全員が Tsinghua/Peking のようなトップ校＋IIT の出身で、特に IIT 出身者が多いです。
