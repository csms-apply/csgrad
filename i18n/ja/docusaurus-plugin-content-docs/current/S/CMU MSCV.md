# CMU MSCV


## プログラム概要
SCS Robotics Institute傘下の1年半のCVプログラムです。夏季インターンが必須ですが、学内での夏季研究で代替することもできます。


## 合格の傾向
プログラムとのマッチ度を非常に重視します。CVのトップカンファレンス論文、CVの研究経験、CV分野のインターンや職務経験がある志願者が好まれます。CVのバックグラウンドがない場合は、非常に高いスペックが必要です。

学生の大半は中国本土／香港・台湾の学部出身者とインド出身者です。中国本土からの合格者の出身校は多岐にわたります。インド出身の学生は、ほぼ全員が2年ほどの職務経験を持っています。

## 就職実績とデータポイント
インターンでは、多くの人がMLEインターンに進み、自動運転、3D Vision、LLM／VLMなど、業界で注目されている分野を幅広くカバーしています。

就職率は91%で、DeepMind、Adobe、TikTok、Meta、Amazonなどに就職しています。残りの人はPhDに進学しました。
