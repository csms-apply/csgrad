# UT MSCS
## プログラム紹介
学費が安い＋評判が良い＋CS ランキングが高い＋立地が良い、と全体的な満足度はかなり高いです。UT の授業の質は確かに評価できますし、特に Austin という街はここ数年で急速に発展していて、Apple、Meta、Google、Amazon のいずれもオフィスを構えています。就職の機会も少なくありません。全体として、MSCS を取りつつある程度の研究の機会もほしい人や、トップ 10 の CS PhD への移行を考えている人にとって、UT は十分に検討する価値があります。


## 合格基準
難易度は MSIN より少し高いと思います。EE から CS への転向にも寛容で、しっかりした研究経歴のある学生が好まれます。
1. トップ 10 のリベラルアーツカレッジ CS、GPA 3.9、論文 2 本
2. インドの学生、CS 学部、GPA 9.62、論文多数
3. インドの学生、GPA 9.49、ETH の研究インターンを含む研究インターン多数
4. Tufts University CS 学部、GPA 3.2

## RA の機会と PhD への移行
指導教員が同意すれば移行でき、とても簡単で、I-20 を 1 枚差し替えるだけです。入学の難しさのほうが、PhD への移行を認めてくれる指導教員を見つける難しさよりも上でしょう。

## 就職実績
雰囲気は CMU ほどではありませんが、学内の同期からのプレッシャーがない分、就職データは実はそれほど悪くありません。ECE と CS の就職状況はどちらも同じくらい良好です。FLAG はほぼすべて実績があります。

Career Fair には毎年 Google、Amazon、Facebook、Microsoft など多くの大手企業が参加します。

1. インドの学生、CS 学部、正社員経験 1 年、NVIDIA に合格し正社員登用
2. UT CS 学部、GPA 3.98、AWS に合格し return
3. UT CS 学部、Paycom に合格（この会社はテキサス州の学生しか採用しません）
4. Tufts University CS 学部、小規模企業の new grad に合格
5. インドの学生、Morgan Stanley で正社員 2 年、Apple に合格
6. UT CS 学部、小規模企業に合格
7. UT CS 学部、Apple のインターンに合格
8. UT CS 学部、オープンソースの経験あり、Meta のインターンに合格

9. Stony Brook CS 学部出身、2025 年にキャンパスの MSCS に入学。2026 年に UT Human Signals Lab で RA を務め、同じ年の夏にソウルの HANWHA LIFE で AI Modeling Research Intern。

## 授業
UT の MSCS は標準的な CS 修士課程で、PhD と共通の授業が多いため研究寄りの授業がやや多く、論文発表レベルを求められるプロジェクトもあります。プログラムには coursework と thesis の 2 つの track があり、どちらも 30 単位の履修が必要です。thesis を選ぶと 6 単位は論文執筆に充てられるので、授業が 2 科目少なくなります。どちらの track でも、theory、system、application の 3 分野でそれぞれ最低 1 科目は履修する必要があります。

授業選択の面では、UT CS は学部の授業がとても充実していて質も高く、多くの修士の学生が最初の学期に Web Dev や Mobile Dev のような学部の授業を取ります。負担が少し軽く、学ぶ内容も実用的だからです。ただし大学院の授業はほとんどが負担が大きく、特に研究寄りの授業では、毎回論文を読む必要がある授業や、ほとんどコードを書かず数式の導出と証明だけで進める純粋な理論のアルゴリズムの授業もあります。履修登録の優先順位は修士 2 年生のほうが高いので、新入生は人気の授業を取るのが少し大変です。

具体的には、CS の授業はカバー範囲が広く、システムが好きならオペレーティングシステム、ネットワーク、分散システム、AI/ML が好きなら NLP、強化学習、深層学習、Web 寄りなら Web Dev や Cloud Computing などの授業があります。ほとんどの授業は負担が軽くありません。たとえば次のとおりです。

1. NLP の授業（Natural Language Processing）：プロジェクトは ACL/NIPS の論文形式で書く必要があり、課題には HMM/CRF なども出てくるので、なかなか手ごわいです。
2. アルゴリズムの授業：コードは書かず純粋に理論を扱い、NP 完全、近似アルゴリズム、フィボナッチヒープなどを学びます。課題はすべて証明問題で、理論が好きな人に向いています。
3. Web 開発：Web 開発に興味があれば Modern Web Application を履修できます。多くの学生がこの授業を終えた後、Full Stack 系の仕事を探します。
4. CS のセミナー：毎回論文を読む必要があり、システム、AI、データベースなど特定の分野を深く掘り下げたい人に向いています。




## 生活

Austin は本当に暑く、9 月中旬でも夕方 5〜6 時に 30 度を超えることがあるので、外出時の日焼け対策は欠かせません。その代わり冬はそれほど寒くなく、一番寒いときでも 0 度を上回ると聞いています。東海岸や中西部のような吹雪とは無縁です。
生活面では Austin には必要なものが一通りそろっていて、日用品は Walmart、HEB、99 Ranch Market で買え、物価も比較的手ごろです。住まいは Far West が中国人学生の主な集まる地域で、家賃は 600〜800 ドルほどです。West Campus は主に学部生が住む地域で、800〜1000 ドルと少し高めですが、大学に近く、CS の建物まで自転車で 10 分で行けてシャトルバスを待つ必要もないので、とても快適です。

人付き合いの面では、UT には International Student Activities が多くありますが、CS の大学院生の多くはコーディング問題の練習と就職活動で忙しく、実際に参加する人はあまりいません。CS ではネットワーキングの機会も多く、毎年 Google、Apple、Microsoft、Bloomberg、Goldman Sachs など多くの大手企業がキャンパス採用のための専用イベントを開いています。さらに UT には Friends of Computer Science (FoCS) というプログラムもあり、ほぼ毎日企業が来ていて、学科の建物に入ると履歴書を出すために並んでいる人たちを見かけます。
