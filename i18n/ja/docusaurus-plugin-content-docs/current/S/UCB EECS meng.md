# UCB EECS MEng

## プログラム概要



Berkeley EECS は CS 全体で top 4 に入る学校です。プログラムの目的は明確で、できるだけ短期間で就職できるよう学生を支援することです。

授業面では、MEng は MSR のような研究重視の修士ではなく、実務重視です。技術科目に加えて Leadership 科目が必修で、Capstone プロジェクトは学年全体を通して行われます。MEng は1年しかないため就職活動に使える時間が極めて短く、ほとんどの学生は初日から LeetCode に取り組み、履歴書を出し始めます。

以前は粘り強く延長を申請して在籍期間を延ばせた学生もいたかもしれませんが、少なくとも 24 Fall からは、インターンをして正社員登用を狙うための CPT 延長は認められなくなりました。在校生のデータによると、2025年2月時点の正社員内定率は約30%です。どれだけ延長を求めても CPT は承認されません。

出願時にはトラックを選ぶ必要があります。CS 出身者は通常 DSS トラックを選びます（DSS トラックは 24 Fall から Data Science と Computer Systems の2トラックに分かれました）。修了には Capstone プロジェクトを完了する必要があり、UW EE PMP の Capstone プロジェクトと似ています。ただし、そのプロジェクトに興味を持つ理由を説明するエッセイを書く必要があり、面接がある場合もあるため、出願プロセスに近い面があります。在校生によると、Capstone プロジェクトの質にはばらつきがあり、意味のある成果を出せない確率は90%だそうです。

UCB 周辺はホームレスが比較的多いため、安全には注意が必要です。ただし EECS の工学部棟はキャンパス北側の比較的奥まった場所にあり、景色が良く、ホームレスの心配はありません。家賃は比較的安く、2025-26年度の州外学生（nonresident）の学費と諸費用は約 $71.4K です。奨学金（Fung Excellence Scholarship で約25%-50%をカバー）を受けると、学費と諸費用は約 $36K-$54K になります。

CPT は承認されませんが、学校は学生への支援に非常に積極的で、卒業生ネットワーキングや面接対策などさまざまなイベントを頻繁に開催しています。卒業生も快く助けてくれます。Berkeley の名前は今でも一流のブランドです（何しろ CS top 4 ですから）。


## 理想的な出願者像

1. 米国の学部4年生からそのまま修士に進学し、すでに大手企業でインターンを経験して return offer を得ている人。
2. 中国本土の学部出身で、インターン経験が9か月以上ある人。
3. 学部卒業後、1年以上の正社員経験がある人。
4. 学費を払う意思があり、このプログラムを通じて直接就職に挑戦したい人。

## 合格の傾向と代表的なデータポイント

合否において GPA の比重は非常に大きいです。奨学金の配分も基本的に GPA 次第で、3.9以上ならおおむね $10K、3.93以上なら $15K、3.95以上なら $20K です。インターンや研究経験も重要ですが、GPA が依然として最も重要な要素です。

GRE はパンデミック期間中は任意だったため、受験しなくても問題ありませんでした。TOEFL は米国の学部出身者なら免除でき、中国本土の学部出身者は最低基準を満たせば十分で、重要な評価項目ではありません。

プログラムは GPA の高い学生と米国の学部出身者を好みます。中国本土の学生はほとんどが985大学の出身です。米国の学部出身者と中国本土の985大学出身者がそれぞれ約40%を占めます。70%以上の学生が GPA 3.8以上です。非公式の統計によると、Berkeley への交換留学経験がある学生が特に好まれます。

## 授業構成
MEng の授業は、技術科目、リーダーシップ科目、Capstone プロジェクトの3つに分かれています。

技術科目の選択範囲は通常の MS よりかなり狭く、トラックごとに決められた科目リストがあります。ほとんどの科目はそれなりに難しいものの、選択の自由が限られていることに不満を持つ学生は多いです。たとえば出願時にトラックを選び間違えると、興味のない科目を履修するしかなく、他トラックの科目の履修を目指すしかありませんが、多くの場合は追加の申請が必要で、取れるかどうかは運次第です。全体として授業の質は保証されています。CS189（Machine Learning）や CS285（Deep Reinforcement Learning）などの人気科目は教授陣が優秀で課題量も充実しており、真剣に取り組めば必ず多くを学べます。

リーダーシップ科目は賛否が分かれます。名前は立派に聞こえますが、内容が浅い、少なくとも費やす時間と労力に見合わないと感じる人が多いです。毎週300-500語の文章を書き、多くのケーススタディを読み、授業のディスカッションに積極的に参加しなければなりません。ランダムに指名されて質問に答える cold call の仕組みまであります。

Capstone プロジェクトは2学期にわたる長期プロジェクトです。企業と連携するものもあれば、純粋な学術研究のものもあります。面倒見の良い指導教員に当たり、プロジェクトが自分の興味と合っていれば多くを学べます。しかし指導教員が放任型だったり、プロジェクトの方向性が自分の目標と合わなかったりすると、最低限こなすだけで終わることもあります。PhD 出願を考えている人にとっては、Capstone の深さは十分ではありません。

全体として就職実績は悪くなく、同じ1年制の Yale MSCS より明らかに良好です。

3. UBC EE 学部、小規模企業でのインターン複数回、小規模企業の new grad に内定
4. UofT EE 学部、Amazon と Huawei でのインターン（カナダ拠点）経験あり、NVIDIA に内定

## 生活面
Bay Area に近く、気候が快適で、周辺にはおいしいレストランがたくさんあります。特に車があれば、週末に SF へ夕食を食べに行ったり海を見に行ったりでき、生活の質は高いです。

キャンパスの設備は平凡です。EECS の建物はかなり古く、図書館の席もすぐに埋まるため、静かに勉強できる場所を見つけにくいこともあります。Berkeley の運動施設は充実しており、学生はプールやジムなどを無料で利用できます。アウトドアが好きなら、キャンパス近くにハイキングコースが多く、ランニングやハイキングにとても便利です。
