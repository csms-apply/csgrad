# CMU MSIN

## プログラム概要
INI スクールに属する代表的な就職志向のプログラムです。CMU MSCS とほぼ同じ時間割を組めるため、就職を目的に米国の CS 修士に出願する中国本土の学部生にとって、事実上の最高目標です。プログラムはハードで授業のプロジェクトも奥が深く、歴代コホートの就職実績は抜群です（詳細は下記参照）。14-513（CSAPP）は MSIN の必修科目であり、ほかの多くの授業の前提科目でもあるので、プログラムは1学期目に履修することを強く推奨しています。CS の学生が取りたい CS の授業（ML、Storage、ACC...）は事実上すべてそろっています。分散システム/OS/ストレージの三本柱を取るつもりなら、このプログラムは MSCS より 14 番台の楽な授業が2つ（ビジネスとセキュリティ）多いだけなので、事実上ミニ MSCS です。

## インターン就活の実績

周りの DataPoints を見ると、HR は CMU 内のどのスクールに所属しているかをあまり気にしておらず、CMU の各プログラムの区別もついていないようです -- CMU 出身でさえあれば CS を学んでいると思われます。友人に聞いたところ、25 summer の INI の就職率はおよそ2/3です。最初はオファーが取れなかったものの、Amazon が面接案内を送り始めてから最終的に取れた人もいます。Snowflake/Databricks のような企業は CMU から特別に採用しています -- INI 所属で DB（15445）を履修していれば、履歴書を集めて面接を組んでくれます（少なくとも 24 Fall のコホートはそうでした）。

2024 summer（23 Fall 入学）の就活実績 -- この年は多くの企業がそもそも採用を行わず、就活が最も厳しい年でしたが、インターンの DataPoints はそれでも悪くなく、オファー数では Amazon がトップでした。

## New Grad 就活の実績
就職市場が厳しかった2024年卒のコホートでも、new grad の実績は堅調でした。CMU CS の評判が全米で認められていることに加え、合格した学生に十分な実力があるからです。就職した割合は91%です。多くの学生が Apple、Oracle、TikTok、Adobe などのトップ企業に入りました。25 new grad では、INI・SCS の卒業生の多くが Databricks と Snowflake に入社しました。

1. UESTC CS 学部、Microsoft でインターン10か月、Amazon でインターン8か月、Google に合格
2. NYU CS + Math 学部、2026年に MSIN Advanced Study を修了；2025年に Amazon で SDE インターン、2026年に Google で SWE の正社員。
