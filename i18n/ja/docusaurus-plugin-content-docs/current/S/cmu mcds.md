# CMU MCDS

## プログラム概要
CMUはCS分野で世界トップ4に入る大学で、MCDSはSCS（School of Computer Science）傘下の看板プログラムとして、一貫して非常に高い知名度を誇ります。SCSのCS授業と専門分野（ML、並列計算、分散システム、ML sys、コンパイラ、OS、組み込みシステムなど）は極めて幅広く、CMUで受けたい授業が見つからないなら、ほかのどの大学でもまず見つからないでしょう。研究に関心がある人やPhDへの進学を考えている人にとっても、分野ごとに教員が多いため、合う指導教員を見つけるのに困ることはありません。

MCDSには3つのトラック（Systemトラック、Analyticsトラック、HCIトラック）があります。出願時にトラックを選ぶ必要がありますが、入学後に変更できるので、それほど重要ではありません。

学部がDS／数学専攻ならAnalyticsトラックを選べます。CSへのキャリアチェンジを目指すなら、入学後にSystemトラックへ移ることも可能です。ただし非公式のデータポイントを見る限り、このプログラムはシステム系のバックグラウンドを持つ志願者を特に好むわけではありません（たとえばMLやDSのバックグラウンドのほうが適性が高く、合格の可能性も高いかもしれません）。

出願時にはビデオエッセイの提出が必要です。また、CMU LTIのポータルで、SCS内で出願したすべてのプログラムに順位を付ける必要があります（大学入試で第1志望・第2志望を書くのに似ています）。


## 合格の傾向とデータポイント
24 Fallを見ると、このプログラムは中国本土の出身大学の知名度をかなり重視しています。清華大学・北京大学、華東五校（復旦大学、上海交通大学、浙江大学、南京大学、中国科学技術大学）に加え、CSに強いほかの大学も含まれます。2023年には学科に1,099件の出願があり、140人が合格、77人が入学しました。詳しくはこちらをご覧ください：https://www.cs.cmu.edu/academics/masters/programs-comparison

英語を母語としない志願者は語学スコアの提出も求められます（たとえば中国本土生まれの学生は、米国の学部を卒業していてもTOEFLスコアの提出が必要です）。GREは必須です。

* 25 Summerインターン：私の周りでは、SDE志望者は全員オファーを獲得しました。MLEについてはあまり詳しくありませんが、私が知っている数少ない事例もすべて決まっています。DS／DA志望者の中にはオファーを得られなかった人もいます。
* 大学のメリット：Career Fairには多くの企業が来ます。DatabricksやSnowflakeのようなユニコーン企業は特にCMUの学生を好み、ここ数年はNVIDIAとAppleがCareer EventでMLEやシステム系の開発者を積極的に採用しています。たとえばOperating Systemを履修していると、Appleに採用されやすくなります。インターン経験がなくても、システム系のプロジェクトだけでこの厳しい市場でNVIDIAやAppleのオファーを得たMSINの学生を何人も知っています。DatabaseやCloud Computingの授業を履修した学生向けに専用の応募ルートを設ける企業も多く、そこから中小規模のデータベース企業に採用された学生もたくさんいます。
* 大学のデメリット：まず、MCDSはSCS以外のプログラムと比べて明確な優位性があるようには見えません。次に、いまだに枠（クォータ）制を採用している企業が一部あり、そうした企業ではCMUの学生がオファーを得にくくなっています。最後に、私の考えでは、システム系以外のSDE職（ざっくり言えばVerilog／C／C++／Rustを扱わない職種。残念ながら私もここに入ります）では、CMUという肩書きの強みと枠制の不利が相殺されます（結局、Databricksは私に面接の機会をくれました）。一方、MLE／Systems SDE職では、CMUの肩書きは大きな強みになります。
* 特記事項：MCDSの就職実績が良いのはプログラムそのもののおかげではなく、このプログラムが職務経験や研究実績のある学生を優先して合格させているからです。今の市場にもチャンスはありますが、全学向けにアルゴリズム面接を行うMetaとAmazon、ごく少数のターゲット校からアルゴリズム面接で採用するDatabricks／Snowflakeを除けば、大手・中小を問わずほとんどの企業がチーム単位の採用に移行しています。実質的に新卒採用が中途採用になったようなものです。そのため、オファーを得られるかどうかは、競争力のある分野固有の経験があるかどうかで決まります。言い換えれば、企業は今や技術スタックだけでなく業界経験も見ています。たとえば志願者の母国での経験がFintech分野でのJava開発なら、米国で受ける面接10件のうち5件はFintech分野のJava職になるでしょう。

## 授業レビュー
* Chain-of-Thoughtが登場してから、どの大学の授業プロジェクトも「難しい」か「楽にこなせる」かに二極化しました（Cloud Computingは例外）。そのため、CMUの重い学業負担が就職活動の妨げになるという昔の問題は過去のものです。むしろ、かつて週16時間以上かかっていたこうした授業こそ、AI時代でも学生が何かを学べる授業だと私は考えています。そこで学業負担には触れず、授業内容と実用性についての私の考えを中心に書きます。
* 3学期コースと4学期コースでは、履修の感覚がまったく違います。4学期なら、どのトラックでも受けたい授業はほぼすべて受けられます（2つのトラックを両方修了することさえ可能です）。3学期だと必修科目がスケジュールの大部分を占め、CCや秋の就職活動も重なるため、受けたい授業をすべて入れるのは難しくなります。

### 必修科目
* FCDS：LeetCode（Design In-memory File System）からデータ分析、ML、クラウドまで幅広く扱う素晴らしい授業で、構成もしっかりしています。私のようにDS／MLのバックグラウンドがない人にはとても役立ちます。
* 10601：MLの基礎科目で、伝統的なMLアルゴリズムを網羅的に学びます。試験の難しさは人によって異なり、数学の素養がしっかりしている人ほど楽に感じます。ML面接対策には欠かせないと聞いています。
* MCDS Seminar：負担は軽く、評価は分かれます。
* 05839：修了すると、さまざまなデータビューへの理解が深まります。課題にコーディング面の難しさはなく、いろいろなツールを呼び出す程度で、実際の負担は週2時間未満です。
* 15619：有名なCloud Computingの授業です。総評としては、技術スタックを幅広くカバーする良い授業です。修了すると業界で使われるさまざまなクラウド関連ミドルウェアをしっかり理解でき、System Designにも大いに役立ちます。秋のうちにインターンを決められるなら、ACCで代替せずCCを履修することをおすすめします。ただし、本格的なインターン経験がある学生（珍しくありません）にとっては、Course Staffが授業プロジェクトに無理やり組み込んだビジネスロジックを書かされるのは少しストレスです（仕事ですでに大量のビジネスロジックを書いているのに、技術を学びに大学へ来たらまたビジネスロジック？？？？）。それでも長所が短所を上回り、全体としては良い授業です。
* Capstone Planner：評価は分かれます。不満を言う人は多いですが、私個人にとっては、インターン直前の学期に会議・交渉・コミュニケーション・必要書類の対応を頻繁にこなしたことが、むしろ良い準備期間になりました。米国での就業経験がある学生にとっては、純粋に時間の無駄です。
* 注意：'24入学生からは、CCをACCで代替することは事実上認められなくなりました。

### 選択科目
* 4学期コースなら、SCSの授業をほぼ自由に選べます。3学期コースだと、実質的にSystemとAnalyticsのどちらか一方の方向しか選べません。



## 費用
CMUは私立大学なので、学費が安かったことはありません。INIでもECEでもSCSでも、MCDSの3学期分の学費（授業料のみで、家賃などの追加費用は含みません）は、2026-27年度のSCS修士の学期あたり$31,100で計算すると$93,300です。
