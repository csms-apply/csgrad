# CMU MIIS

## プログラム概要
LTI が開設しており、主に就職志向です。1年半で修了することも、2年で修了することもできます。MIIS は SCS に属しているため履修登録の優先度が高く、Distributed Systems や Operating System など人気の CS 科目をいろいろ履修できます。最初の2学期は research が必須です。LTI には専用の自習用コンピュータ室があり、MSAII、MIIS、MCDS の学生は誰でも使えます。MIIS は就職活動の雰囲気がとても良く、MIIS 担当のアドバイザーも非常に面倒見が良いです。

## 就職実績とデータポイント
例年の就職率は92%、初任給の中央値は $150K です。SDE と MLE のどちらに進む人もいます。主な就職先は Databricks と TikTok です。
