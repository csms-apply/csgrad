# Gatech MSCS

## プログラム概要
このプログラムはほぼすべての面でバランスの取れたパッケージです。評判はしっかりしていて、学費は安く（TA/RA になれば学費が免除され給料ももらえます。TA/RA は最低でも月 $1,184 で、これは修士課程の2026-27年度の最低額です）、多くのテック企業の拠点である Atlanta にあるため就職活動もしやすいです。23 Fall の期は内定率が非常に高かったそうです。

Georgia Tech の学部出身で GPA が十分なら修士課程にそのまま進学できるため、学内生の多くは他校に出願せずにそのまま残ります（そもそも GT CS より良いプログラムはごくわずかだからです）。授業の質は本格的でハードです。詳しくは 1point3acres のレビュー記事を参考にしてください。

CS のランキングは高く（csrankings で4位）、専門分野の幅も非常に広く、NLP、CV、architecture など、受けたい授業はほぼすべて受けられます。CS に希望の授業がなければ CSE の授業を取ることもでき、楽な科目でもハードな科目でも、ほぼ必ず必要なものが見つかります。MSCS は CS 科目の履修登録の優先度が非常に高く（CSE、CoC と同じ第1優先）、履修登録はとても簡単です。就職にも PhD 進学にも向いています。CSE の学生が学内の PhD にそのまま移った例もあります。

## 合格基準

おそらく唯一やさしくない点は合格のハードルです。このプログラムは成績・スコアの基準がかなり厳しいです。公式サイトには MSCS の出願に GRE は不要と書かれています。GRE が必須だった以前は、スコアを提出した知人はほぼ全員が合計326以上でした。中国本土からの合格者はほぼ全員が高スペックです（ただし学部の専攻に制限はなく、たとえば EE の学生も出願して合格できます）。米国の学部出身者はもっと楽で、top 100 の学校出身で GPA が比較的高ければ挑戦する価値があります。（GT 出身の教授から推薦状をもらえると合格率は大きく上がります。論文なしで GT の教授の推薦状を頼りに GT CS に合格した友人がいます。）

## 代表的な合格データポイント
中国本土の学部から直接合格する人はごくわずかです（特に 24 Fall）。中国本土からの合格者はほぼ Tsinghua、Peking、SJTU、ZJU の出身です。中国本土の学部＋海外修士の中退／海外で2つ目の修士という経路は、いくらか合格しやすいようです。米国の学部出身者はかなり有利です。プログラムは専攻転換者を歓迎しており、在校生にも Tsinghua や NTU の学部から CS に転向した人がいます。

1. Peking University 学部出身、NOI 金メダル、スマートフォンメーカーでのインターン
2. UESTC 学部出身、GPA 3.9以上、Tencent と Alibaba でのインターン
3. カナダ top 2 の学部出身、GPA はやや低め、大手企業でのインターン5回
4. USC CS 学部出身、GPA 3.8
5. University of Rochester DS＋Math 学部出身、GPA 3.95

## GT MSCS に合格するためのコツ
MSCS への合格が難しすぎると思うなら、まず競争の緩やかな GT CSE トラックに出願し、入学後に MSCS へ移る方法があります。あるいは先に GT OMSCS に出願してから、キャンパスのプログラムに移ることもできます（GPA だけが求められます）。私の知る限り、この方法を試した友人は全員移ることに成功しました。（ただし公式 FAQ には、MSCS は専攻変更の申請を受け付けておらず改めて出願する必要があると書かれているため、どちらの経路に頼る場合も事前に学校に確認してください。）



## 就職実績
23 Fall の期は内定率が非常に高かったそうで、暗い景気の中での朗報です。このプログラムには co-op もあり、学期中にフルタイムのインターンができるため、秋の採用シーズンに2度目のチャンスが得られるのは素晴らしい点です。co-op はグローバルで、中国に戻ったり日本でインターンをしたりすることもできます。米国の学部出身者なら、1学期目からフルタイムのインターンを始めることもできます。

個人的に見ている限り、GT の内定率は堅実です。私が見てきた MSCS の学生は皆、良い就職結果を出しています。Meta や Amazon に決まった人も多いです（25 Summer）。ある GT の学生は、面接の3時間後に Meta のオファーを受け取りました。

身近なサンプルデータ：私の知る 24 Fall GT MSCS の中国人学生のうち、大半が夏のインターンを見つけられました。少なくとも6人が Meta の SWE intern のオファーを、少なくとも5人が Amazon の SDE intern のオファーを受け取り、Amazon はまだオファーを出し続けています。（from cwy）


1. インド人学生、SAP＋Oracle でインターン、小規模企業に内定
2. USC 学部出身、米国の小規模企業でのインターン経験あり、Amazon に決まり return
3. University of Rochester DS＋Math 学部出身、中国国内の小規模企業での経験あり、Tesla の intern に内定
4. IIT 学部出身、GPA 8.87/10、インドで3年の正社員経験、Amazon の new grad に内定
5. GT CS 学部出身、GPA 4.0、AWS の intern に決まり return
6. インド人学生、Oracle で2年の勤務経験、SLB の new grad に内定
7. GT CS 学部出身、GPA 3.89、Google に内定
8. インド人学生、1年の正社員経験、AWS に決まり return
9. IIT CS 学部出身、Apple に内定

10. UCB Cognitive Science 学部出身、DS を副専攻、以前は Salesforce で SWE 正社員。2024–2026年にキャンパスの MSCS に在籍、Nissan で research intern、2026年に NetSuite の SWE II 正社員。

## TA の機会
Georgia Tech はオンライン科目の TA を大量に採用しています。ただし早めに探し始める必要があります。最初は難しいと思っていましたが、後になって、あまり詳しくない人でも TA になれていることがわかりました。
