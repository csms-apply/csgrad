# CMU MSAII

## プログラム概要
SCS 傘下の看板 AI プログラムで、就職志向です。研究をしたいなら SCS の MSR や MSML を見てください。プログラムは非常に柔軟で異分野からの CS 転向にも好意的で、さまざまなバックグラウンドからの転向 DataPoints がたくさんあります。学科長はスペックの高い出願者を好みます -- GPA、GRE、TOEFL は高ければ高いほど良いです（TOEFL 105+、GRE 330+、最上位の GPA）。作業量の少ない楽な授業が多く、選択科目8枠をすべてハードな SCS のシステム系授業で埋めることもできます -- CC、ACC、OS、Storage いずれも可能です。Coding Bootcamp という LeetCode のトレーニング授業があり、SDE 職を探すのに非常に好都合です。


## 合格ライン & DataPoints
TOEFL 105+、GRE 330+、最上位の GPA は事実上必須です。同じ学校の同級生からの peer pressure を感じるかもしれません。

1. Rutgers CS 学部、GPA 3.984
2. Illinois Wesleyan University Biology 学部、GPA 3.78、Duke の PhD に合格したものの半年で中退
3. インドの Telecom 学部、GPA 8.09/10、Adobe でインターン、Amex でアナリストとして正社員3年
4. Tsinghua 建築学部、学年1位、GPA 3.87、経済学副専攻
5. UVA CS + Physics 学部、GPA 3.91

## 就職実績 & DataPoints
インターン先の企業は事実上 FAANG をすべて網羅しています。SDE と MLE が主な進路で、就職率はほぼ100%です。PhD に進学する人はほとんどいません。

主な就職先：TikTok、Amazon、Google、Oracle、C3.ai



1. インドの学部、小規模企業でインターン3回（合計1年）、Amazon の SDE インターンに合格、その後小規模企業の MLE に転職
2. Tsinghua 建築学部、中国の小規模企業でインターン2回、Adobe の MLE インターンに合格し return offer を獲得
3. インドの学部、インドの小規模企業で MLE インターン多数、Pittsburgh の BNY で MLE インターンに合格
4. インドの学部、Deloitte で MLE として1年勤務、BNY の MLE に合格し Senior DS に昇進
5. UVA CS + Physics 学部、Riot Games でインターン、AWS の SDE インターンに合格
6. Tsinghua 学部 + Automation 修士、ByteDance で RS インターン9か月、Palo Alto の小規模企業の MLE に合格
7. インドの学部、小規模企業でのインターン多数、MathWorks の SDE インターンに合格

8. Illinois Wesleyan Biology 学部、2022年に修士修了；小規模企業で MLE インターン、2022年に Meta で Research Data Scientist の正社員、2023年に ByteDance で Data Engineer の正社員。
