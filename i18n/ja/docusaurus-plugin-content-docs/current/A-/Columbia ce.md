# Columbia MSCE
## プログラム概要
1.5年のプログラムです。夏のインターンはできますが、秋の co-op はサポートされていません。論文オプションがあるので、指導教員が見つかれば修了時期を遅らせることができます。

## 就活体験談
学校のキャリアフェアは事実上役に立ちません。以前は Bloomberg が受け皿だったと聞きましたが、今はそこに行った人の話も聞きません。ただ、周りを見ると早めに応募した人はそれでも面接を受けられていました。一つの DataPoints として、私はインターン経験がまったくなかったにもかかわらず、書類選考を通過して Meta と Amazon からオファーをもらいました。とはいえ、Columbia が一部の企業のターゲット校でないのは事実です。インターン経験ゼロで Uber と Snowflake の OA を満点で通過したのに不合格でした。FAANG のインターン経験が複数ある同級生も、OA で満点を取ったのに不合格でした。就活には、UIUC や UCSD CS75 のような州立大学のプログラムのほうが明らかに有利です。

1. BITS Pilani Electronics & Communications 学士、学部在学中に NVIDIA で ASIC インターン、2025年に Arm で SoC インターン、2026年から Arm で Graduate Engineer の正社員。

## 授業体験談
Columbia は学期ごとに授業が4つあるので作業量が多い、というよくある誤解がありますが、実は間違いです。CE は授業選択が極めて柔軟で CS の授業も自由に取れますし、CS の授業の履修登録の優先順位も CE と MSCS で同じです。必修の core 5科目をすべてソフトウェア中心で選ぶことができ、楽な授業の選択肢も多いです。作業量が事実上ゼロの授業をいくつかおすすめします：
Modeling：core 科目として認められます。統計の授業です。学部で多次元ランダムウォークを扱う統計の授業を取っていれば、既存の知識で楽に乗り切れます。
Verification：core 科目です。離散数学に似ていて、FSM と論理を扱います。
Data Center Processing：core 科目です。グループプロジェクトで短い論文を書きます。

## MSCS と CE のどちらを選ぶか
CS のほうが合格ラインが高く、ときどき予測がつきません。工学部では1つのプログラムにしか出願できないので、私のようにどうしてもニューヨークにいたいなら CE をおすすめします。どのみちマンハッタンでは Columbia と NYU しか選択肢がないのですから。
