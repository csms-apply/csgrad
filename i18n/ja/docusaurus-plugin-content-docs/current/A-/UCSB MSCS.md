# UCSB MSCS

## プログラム概要
MSCS プログラムは通常2年ですが、最長4年まで延長でき、学校が発行する I-20 にもこの期間が反映されます。就活に好意的です：ゲームに残っている限り、チャンスはいつでもあるというわけです。

生活はとても快適です。UCSB は信じられないほど美しいです — 海のすぐそばで、日差しと砂浜があります。PhD でも MS でも、5年あるいは2年を素敵に過ごせます。

これは UCSB MSCS プログラムのちょっとしたデメリットでもあります。キャンパスは海岸に面していて景色はまぶしいほど美しく、周りの町もとてものどかです。ここでは「ガツガツした」雰囲気を感じにくいです — みんな自分のペースで進んでいます。ほとんどの修士学生は修了後に就職したいと考えていますが、LeetCode を解いて履歴書をばらまくという全体の雰囲気は CMU や NEU ほど強くありません。その話をする人もあまりいません — 同級生に会ったときにたまに調子はどうかと聞く程度で、就活は完全に自分で何とかするものです。


## 合格傾向 & 代表的な DataPoints
22 Fall のコホートでは修士学生が約30人合格し、そのうち中国人学生は約16人でした。事実上 UC 系の学校出身者しか合格させていません — 詳しくはグラフを参照してください。中国本土の学部から出願するのは ROI が極めて低いので、非常に優れた実績がない限り出願しないでください。

1. UCSB CS 学部、GPA 3.98
2. UCSB CS 学部、GPA 3.90
