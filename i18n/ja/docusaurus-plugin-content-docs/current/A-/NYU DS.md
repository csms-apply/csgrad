# NYU DS

## プログラム概要
CS/DS/Math の学部出身で、修士課程で研究のバックグラウンドを強化してから PhD に進みたい学生に非常に向いています。Instagram で nyucds をフォローすると、どれほど研究を重視しているかがわかります。CS へのキャリアチェンジには向いておらず、DS 職を探している人に向いています。
学科内で PhD に転籍する学生がかなりいます。研究に興味があれば合格直後から教授にメールを送ることができ、多くの研究プロジェクトでは夏から研究室に参加できます。



授業は厳しく数学的な負担も大きいので、合格者には数学のバックグラウンドを持つ人が多いです。ここの学生のほとんどは PhD か DS 職を目指しています。2年間真面目に勉強すれば、身につく知識で事実上どんな DS 職にも対応できます。（ただし LLM の時代には、DS 職にも ML/DL のスキルが求められます。）このプログラムは、Data Scientist になるために必要な知識をとてもよく教えてくれます。キャリアフェアには、ニューヨークの金融業界の企業が多く来る傾向があります。


## 合格傾向 & 代表的な DataPoints
米国の学部 top-50 の math/stat/econ 専攻者を合格させる傾向があります。学生の構成はおおよそ中国人1/3、韓国人 + インド人1/3、白人およびその他1/3です。

公式の入学レポート：2021年の入学サイクルでは平均 GPA は 3.87 でした。学生の成績証明書は通常 A と B のみで構成されており、選抜度の低い大学から出願する人には、より関連性の高い科目（下記参照）でより良い成績を期待しています。

GRE Verbal 平均：159.3（80パーセンタイル）
GRE Quantitative 平均：167.4（90パーセンタイル）
GRE Analytical 平均：4.14（61パーセンタイル）
TOEFL 平均（必要な場合）：111

1. NYU Data Science 学部、GPA 4.0
2. UCI DS 学部、GPA 3.97
3. NYU BA 学部、GPA 3.96
4. UW Math 学部、GPA 3.95
5. Rutgers University DS 学部、DS の正社員経験3年
6. Brandeis University CS 学部、GPA 3.79


## 就職実績 & DataPoints
主に DS 職です。同じティアの似たような DS プログラムと比べると、就職率はかなり良いです。

1. NYU Data Science 学部、研究経験多数、小規模企業の DS インターンに合格
2. UCI DS 学部、C3 AI に合格
3. インド人学生、インドでインターン1年、BCG の DS に合格
