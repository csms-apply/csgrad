# UCSD EC79



## プログラム概要
ハードウェア系の科目がかなり多いです。コア要件の1つにハードウェアの必修科目があるため、EE のバックグラウンドがまったくない場合は、この科目に余分に時間を割く計画を立てておきましょう。

EC79 はすでに専攻転換に最もやさしいトラックです。UCSD ECE は全体として UCSD MSCS より明らかに負荷が重く、授業の難易度も高いため、より多くの時間を投じる必要があります。

## 合格ラインとデータポイント
ハードルは CS75 より少し低めです。全体として専攻転換にやさしく、GPA 87以上の CS/EE の学生なら挑戦してみる価値があります。



## 就職実績とデータポイント
周りの人のうち、およそ半分がオファーを得ました。


## 生活
キャンパスの景色はとりわけ美しく、気候も快適なので、ストレスがいくらか和らぎます。冬に少し雨が多いことを除けば、一年中とても過ごしやすい天気です。学外の家賃はかなり高いですが、大学院生向けの寮は比較的手頃で、少なくとも住む場所には困りません。学校はサーフィン、ボクシング、アーチェリーなど多くのレクリエーション授業も提供しており、勉強以外の生活を充実させられます。UCSD の学生は市内の公共交通機関を無料で利用でき、週末には学校がいくつかのショッピングエリアへ無料の買い物シャトルを運行しているので、日常生活はかなり便利です。

## 授業レビュー

1. ECE 143 Programming for Data Analysis、Prof. Unpingco, Jose H.
おすすめ度：5/5
課題：毎週4-6問のプログラミング課題と、ランダムに組まれたチームでのプロジェクトがあり、データセットを選んでクリーニングし、分析してレポートを書きます。たとえばあるチームは EC サイトのユーザー消費行動のデータセットを選び、重複や誤りを取り除いてクリーニングしたうえで、購入頻度や消費の分布などを深く分析し、充実したレポートにまとめました。
負荷：軽い。課題とプロジェクトに週5-8時間。
成績：甘めです。この科目は EC93 の必修で、基本文法から Python によるデータ処理までを扱います。専攻転換者にとって非常に役立ち、授業の負担も軽く、期末試験もありません。強くおすすめします。

2. ECE 269 Linear Algebra and Application、Prof. Pal, Piya
おすすめ度：2/5
課題：宿題3回とプロジェクト3回。どちらも線形代数を深く応用する必要があります。たとえば画像処理で行列変換を使って画像を回転・拡大縮小するといった内容です。
負荷：非常に重い。週15-20時間。
成績：辛めです。EC80、82、93 の必修科目です。名前は「Linear Algebra」ですが、難易度は学部レベルをはるかに超えます。週2回の講義と1回の discussion はどれも内容がぎっしり詰まっています。試験は厳しく、一部は discussion や宿題から出るにもかかわらず平均点は30点前後です。比較すると Prof. Xie, Pentao の ECE 269 は少し易しいものの、残念ながら2022-23年度には開講されませんでした。

3. ECE 276A Sensing & Estimation Robotics、Prof. Atanasov, Nikolay A.
おすすめ度：3/5
課題：宿題3回とプロジェクト3回で、ロボットの知覚と推定が中心です。たとえばセンサーデータをもとに環境内のロボットの位置を推定する自己位置推定（localization）アルゴリズムを設計します。
負荷：重い。特に学期後半。週12-15時間ほど。
成績：普通。EC80 の必修、EC93 の選択科目です。ロボティクス分野の基礎科目で、ロボティクスで働いたり研究したりするつもりなら必須です。ただし難易度を考えると、必修でなければ慎重に選びましょう。

4. CSE 202 Algorithm Design and Analysis、Prof. Impagliazzo, Russell
おすすめ度：3/5
課題：宿題5回とプロジェクト1回。アルゴリズムの設計と解析の演習が中心で、たとえば効率的なソートアルゴリズムを設計し、その時間計算量と空間計算量を解析します。
負荷：重い。週10-12時間ほど。
成績：甘めです。この科目は、学部の Data Structures（CSE 100）や Algorithms（CSE 110）ほど実用的ではありません。

5. ECE 250 Random Processes、Prof. Siegel, Paul H.
おすすめ度：3/5
負荷：普通。週8-10時間ほど。
成績：辛めです。特定のトラックの必修ではありませんが、ほとんどのトラックで選択科目になっており、他の多くの科目でも関連内容が参照されます。中間試験2回と期末試験1回があり、採点が厳しく小さなミスでも大きく減点されます。内容は実用的ですが、慎重に選びましょう。

6. ECE 285 Intro to Mathematical Finance、Prof. Sworder, David D.
おすすめ度：4/5
課題：チームプロジェクト。あるチームは株式ポートフォリオの最適化プロジェクトに取り組み、数学的手法でリスクを最小化しリターンを最大化するには各銘柄にどう配分すべきかを分析しました。
負荷：軽い。週5-7時間ほど。
