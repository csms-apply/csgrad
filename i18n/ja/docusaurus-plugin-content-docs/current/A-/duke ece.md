# Duke ECE

## プログラム概要
Duke には CS 関連のプログラムが3つあります。1. MSCS 2. ECE 3. Game Design。MSCS は研究寄りのプログラムで、ECE は CS への専攻転換者と就職を意識したプログラムです。

全体として ECE の授業は SDE 寄りで、合格のハードルも比較的やさしめです（つまり合格しやすいので、専攻転換の出願者が多く出願します）。出願プロセスでは面接がある可能性が高く、英語のスピーキング力が試されます。

ECE には主に MS と MEng の2つのトラックがあります。違いは、MS では thesis、project、coursework-only の中から選べる点です（2026-27年度の公式サイトによると thesis は必須ではありません）。一方 MEng には thesis がなく、修了には経営大学院の科目2つとインターンが必要です。以前は MS トラックが約100人、MEng が5-10人の枠でした。公式の回答では、MS と MEng の合格ハードルは同じで、MS に合格できるなら MEng にも合格でき、その逆も同じです。入学後に相互に切り替えることもできます。

## 長所：
1. 授業の質が良いです。秋の3科目（550、551、590）と春の3科目（650、651、568）があり、実質的にすべて SDE 関連の科目です。基礎が弱い専攻転換者はこれらで基礎力をつけられます。春の3科目は負荷が比較的重く、たとえば ECE 651 SOFTWARE ENGINEERING はかなり時間がかかりますが、しっかりした基礎を築くのに役立ちます。
2. Co-op。MEng の学生は co-op を1回行うことができ、実質的に2度目のチャンスになります。秋の co-op を募集している企業には Tesla、Snowflake、TikTok などがあります。メールでの案内によると、24 fall 以降に入学するすべての MEng ECE 学生が co-op の対象です。秋の co-op を提供している学校は比較的少ないため、競争が緩く、オファーを得られる確率も高くなります。
3. 専攻転換にやさしい。Duke ECE に出願する際は MEng と MS のどちらかを選びます。専攻転換者や CS 専攻者は Software Development か Data Analytics & Machine Learning のトラックを選べます。志望理由書（personal statement）も書きやすいです（前者は SDE、後者は研究に焦点を当てます）。もちろん入学後にトラックを変更することもできます。
4. 1期の人数が比較的少なく、書類選考を通過しやすい。企業の中には、最終オファーを出す際に同じ学校からすでに何人の new grad を採用したかを考慮し、1つの学校からばかり採用しないところもあります。そのため、小規模なプログラムの学生は書類選考で有利です。



## 短所：
1. 高い。学費だけで約 $100K です（出典：学校の公式サイト）。出願時にこの学費を見て本当に驚きました。私立大学は評判どおりです。
2. 負荷が重い。前述のとおり、秋と春の3科目はどちらも負荷がかなり大きく、LeetCode に取り組む時間が削られる可能性があります。

2. Dalian University of Technology、経営学専攻、GPA 上位15%、UC Berkeley への交換留学経験あり
3. UESTC、通信工学部、GPA 3.75
4. Shenzhen University、CS 学部、GPA 3.75、Meituan、Tencent、Shopee、Ctrip でのインターン
5. Donghua University、ソフトウェア工学部、GPA 3.9
6. UESTC、ソフトウェア工学部、GPA 3.9
