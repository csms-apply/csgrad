# CMU MSE-SS


## プログラム概要

正式名称は Master of Software Engineering です。
MSE プログラム自体は、3 つのトラックからなる専門職向けのエンジニアリング修士です。

1. Scalable Systems (SS)
2. Embedded Systems (ES)
3. Professional (Pro)

SS と ES は職務経験 2 年未満の新卒向けのトラックで、Pro は職務経験 2 年以上の経験者エンジニア向けのトラックです。入学後の 3 トラックの授業の違いはプログラムのウェブサイトを参照してください。SS と ES はほぼ同じで、どちらも修了には夏のインターンと 1 学期の capstone プロジェクトが必要です。Pro は 1 学期目に SS/ES より選択科目を 12 units 多く取り、夏にインターンができず（したがって CPT もなし）、夏から始まる 2 学期にわたる studio プロジェクトを終えないと修了できません。MSE プログラムは capstone/studio プロジェクトを行う企業を紹介してくれますが、インターンは自分で探す必要があります。

授業の大半は人文系／非技術系の授業です。SDE 関連の職務経験がない、CS へ専攻を転向する人にはおすすめしません。正社員経験 3 年以上の学生におすすめです。このプログラムにはコーディングの授業がほとんどなく、授業選択の柔軟性も限られ、必修科目の質も高くありません。SCS よりは MISM に近い印象です。出願の過程で、LeetCode の問題を 2 問解くよう求めるメールが届きます。

## 合格の傾向と代表的な Data Points
学生の構成はおおよそインド人学生が半分、中国人学生が半分です。職務／インターン経験を非常に重視します。BBAT（Baidu、ByteDance、Alibaba、Tencent）のような大企業でのインターン経験があれば、プロフィールがやや弱くても合格に役立ちます。

1. CMU IS 学部、GPA 3.5
2. インド人学生、VIT 学部、GPA 3.95/4

## 就職実績と Data Points
非常に良いです。純粋に結果だけを見れば素晴らしい実績です。合格メールには、CMU MSE-SS の修了生は CMU MSCS の修了生より昇進が早いとまで書かれています（どう測ったのかはわかりませんが、そこまで言うからには根拠があるのでしょう）。私の推測では、MSE-SS が出願者のインターン経験を非常に重視していることと関係があると思います。

1. CMU IS 学部、小規模企業でインターン 2 回、Amazon のインターンに就職
2. Oregon State University 学部、Siemens と小規模企業でのインターン、Microsoft の new grad に就職
3. インド人学生、正社員 1 年、GoDaddy（ドメイン登録会社）のインターンに就職、new grad で Google に入社
4. インド人学生、MathWorks と小規模企業でのインターン、Microsoft のインターンに就職後、正社員登用
5. インド人学生、職務経験 3 年、Microsoft SDE 2 に就職（Microsoft の社内レベルでおおよそ level 60、new grad は level 59）
6. インド人学生、Samsung で 3 か月と SAP で 6 か月のインターン、正社員 2 年、Adobe のインターンに就職後、正社員登用
7. インド人学生、VIT 学部、5 か月のインターンを複数回、Armada の new grad に就職
8. University of Toronto CS 学士、学士課程中に Veeva Systems で SWE インターン、2026 年に MSE-SS 在学中に DoorDash で SWE インターン。
