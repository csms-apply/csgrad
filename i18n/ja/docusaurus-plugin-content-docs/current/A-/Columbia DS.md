# Columbia DS

## プログラム紹介

学部が CS ではなく、このプログラムを CS への転向の足がかりにしたいだけの学生には向いていません。CS、CE、さらには EE を検討してください。このプログラムは DS と ML 寄りです。全体として DS のカリキュラムはかなり充実しています。履歴書に書ける capstone プロジェクトがありますが、入学前に一部の前提科目を修了しておく必要があるため、最初の夏の就職活動にはあまり役立ちません。履修の自由度は比較的高く、学部で履修した授業は免除でき、追加の選択科目は CS と Statistics から自由に選べます。

学部が CS ではなく、このプログラムで CS に転向したい場合は、CS、CE、さらには EE を調べてみてください。

## 合格傾向と代表的なデータポイント
合格者数はかなり多いですが、名門校の出身者が多いです。通常 1 学年あたり約 200 人です。

中国本土の学部出身者とアメリカの学部出身者の比率はおよそ 40/60 です。中国本土の学生は主に Tsinghua、Peking University、SJTU、Tongji、Fudan など、トップクラスの 985 大学の出身です。アメリカの学部出身者では UCLA 出身が多く、Rutgers、UC Berkeley、CMU もいます。

1. City College of New York、Applied Mathematics 学部、GPA 3.96
2. UCSB Statistics + DS 学部、GPA 3.94
3. Boston University Math + CS 学部、GPA 3.9
4. UCLA Math 学部、GPA 3.95
5. インドの学生、GPA 9.2/10、正社員としての職歴 5 年

## 就職実績とデータポイント
普通

全体的な実績はかなり平凡です。学校はいくつかのキャリア支援を提供しています。たとえば DSI は DS の学生に、正社員とインターンの求人をまとめた週刊メール「DSI Opportunities」を送っています。学期中には企業の Resume Drops メールもあり、学生の履歴書が HR や Hiring Manager に直接届けられます。DSI は独自の career fair も開催しており、DSI と関係の深い企業が参加します。とはいえ、就職活動は最終的に個人の力次第です。同期の進路はさまざまで、大企業に進む人もいれば小さな会社に進む人もいます。

1. UCSB Statistics + DS 学部、Microsoft の DS インターンに合格
2. Boston University Math + CS 学部、学部在学中にインターン多数、CVS の DS 正社員に合格
3. トップ 30 のリベラルアーツカレッジ出身、在学中にインターン多数、JP Morgan に合格
4. インドの学生、HP で正社員 2 年、Tesla の new grad に合格
5. インドの学生、在学中に McKinsey でインターン、Stripe の DS に合格
6. インドの学生、正社員としての職歴 5 年、Capital One の Principal に合格
7. インドで CS の学士号、入学前に Morgan Stanley で正社員 1 年、2025 年に Collins Aerospace の ML インターン、2026 年から McKinsey の Data Scientist（正社員）。
