# CMU SE-SV

## プログラム概要
実はピッツバーグの本校とはかなり違います。キャンパスは建物2棟だけで、教室や自習スペースは限られており、ほとんどの授業は少数の同じ教員が繰り返し教えています。深く掘り下げた授業は多くありません。膨大な授業カタログから世界的に有名な教授の授業を自由に選び、Andyが目の前で講義してくれるような本校の体験を期待しているなら、がっかりするかもしれません。

とはいえ、立地は本当に便利です。シリコンバレーの企業リソースと卒業生ネットワークは充実しており、CMUのブランドも加わって、インターンや正社員の職は比較的見つけやすいです。社内リファラルやCareer Fairを通じて、Bay Areaの大手企業やスタートアップからオファーを得た同級生をたくさん見てきました。

このプログラムはどんな人に向いているでしょうか？
1. シリコンバレーに素早く溶け込み、就職活動に集中したい人
2. 授業の深さや教員の肩書きにあまりこだわらない人
正直に言うと、ここの授業にはかなり平凡なものもあり、教員の数も限られています。一部の必修科目には不満の声が多く聞かれます。研究や授業の厳しさよりも「単位を取って修了すること」を重視するなら、このプログラムはそれなりに合っています。
3. 自力で独学できる人、または踏み台と割り切れる人
履修の自由度が限られているため、オンライン講座やピッツバーグ本校の教材で学習を補う学生が多くいます。システム／アルゴリズム／機械学習をしっかり学びたいなら、独学が必要になることが多いです。SE-SVを1年間の踏み台（インターン、正社員、Bay Areaへの定着が目標）と考えるなら、十分に機能します。


## 合格ライン
米国の学部出身者や、985／211大学出身のGPAが高い学生が多く、難易度はECEやMSINより低めです。
GPA 3.7+で語学スコアの基準を満たしていれば十分でしょう。大手企業でのインターンを複数経験している学生なら、低めのGPAもカバーできます。語学スコアが基準に届かなかった（TOEFL 98）ものの、豊富なインターン経験のおかげで合格した例もあります。

## 授業の質
私が最も不満に感じている部分です。本校にあるCMUの伝説的な授業の多くは直接受講できません（受講できてもオンラインのみです）。SV現地で開講される授業は、質のばらつきが非常に大きいです。

Cloud ComputingやCSAPPなど、ピッツバーグキャンパスの一部のオンライン授業は内容がかなり良いです。
しかし、必修のソフトウェア工学の授業は1〜2人の教員が交代で教えることが多く、教え方もやや古いです。プロジェクトでは「大量のドキュメント作成＋プレゼン」にあまり意味を感じない学生が多く、おかしな要求にも耐えなければなりません。
すでにCSのバックグラウンドがある学生にとっては、CMUに払った約$90Kの学費が無駄になったように感じられるかもしれません。

よりハードなCS修士課程（MCDS、MSIN）には合格できなかったけれど、どうしてもBay Areaで就職したいという人なら検討する価値があります。Brown SCMCSやUT ECEなどほかのオファーがあるなら、個人的にはそちらのほうがコスパが良いかもしれないと思います。
