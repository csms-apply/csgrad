# Brown SCMCS


## プログラム概要

1学期あたり2単位・2科目で授業負担がとても軽く、就職活動や研究に使える時間が十分にあります。多くの学生は 2+2+2+2 のスケジュールで毎学期2科目ずつ均等に履修するため、負担が非常に軽く、LeetCode の対策や就職活動にぴったりです。共用のオフィススペースがあり、学生同士で一緒に LeetCode に取り組めるので、雰囲気もとても良いです。

負担が軽いことの利点は次のとおりです。アメリカに来てすぐに多くの授業を取りながら、LeetCode、behavioral 質問、プロジェクトの準備までこなすとなると、プレッシャーは相当なものになります。Brown ではこの問題を避けられます。1学期2科目だけなので、負担は極めて軽いです。

学費は安くありません。2026-27年度の公式料金では、ScM in CS は1科目 $10,977 で、8科目で学費の総額は約 $87.8K です（fees を除く）。専用のワークステーションが割り当てられます（個人的にはあまり役に立たないと感じていて、図書館のほうが好みです）。住居費は手頃で、大学が取得したアパートに住む場合、2B1B が $900、2B2B が $1,100、スタジオが $1,500 です。

このプログラムは毎年 UT ECE（SES）、GT CSE、CMU MSIN、Columbia MSCS とよく比較されますが、就職実績には差があります。結果だけを見ると、SDE インターンの獲得という点ではこれらのプログラムに及びません。



## 合格ライン

GPA：3.8以上（100点満点なら90以上。中国のトップ5大学の学部出身者はやや有利）

TOEFL：105

IELTS：Speaking 8点が絶対条件

CS 専攻であること（成績証明書に記載された専攻が Computer Science である必要があります）

中国本土の学部出身者を差別しない（UIUC MCS のように中国本土の学生をほぼ全員不合格にすることはない、という意味です）

1. Michigan State University、GPA 4.0、スタートアップの創業経験が複数
2. インド人学生、GPA 3.96/4、インドの JP Morgan で正社員として2年
3. インド人学生、GPA 3.96/4、Samsung で正社員として2年半、修士在学中に中小企業でインターン2回


## 就職実績とデータポイント

かなり厳しいです。オファーを得た人はごく少数でした（25 summer）。

以前は spring 学期に在籍したまま CPT でインターンを2回できたそうです。学校への確認が必要です。

多様性（diversity）が必ずしも有利に働くとは限りません。2025年には DEI プログラムがすでに廃止されています。CS への転向者やアメリカの学部出身者を優先して採用しているのは、今では Microsoft だけです。実力が十分にあれば、学校選びで多様性の要素は気にしなくて構いません。
