# UTSU MSCS
## プログラム概要
正式名称：Utah State University MSCS。最大の魅力は全額支給（フルファンディング）の機会があることです。学科が TA や RA の業務に対して月 $2,000 を支給しており、非常に手厚い条件です。実質的に全額支給の MS プログラムといえます。さらに UTSU MSCS は最長4年まで在籍できるため（留学生以外の場合）、仕事が見つかった時点でいつでも修了できるのも魅力です。Yale MSCS 2-year / UIUC MSCS / UW-Madison MSCS のように PhD 出願者と同じ枠で競争が激しく、合格がほぼ不可能なプログラムとは違い、このプログラムは強い研究実績のない一般的な出願者が全額支給の MS に出願するのに非常に適しています。

## TA/RA の申請
USU の大学院生の半数以上が、奨学金や grant などを含む経済的支援を受けています。早めに申請しましょう。出願システムにそのための項目があります。

## 合格傾向とデータポイント
GPA 3.0超、TOEFL 79以上または IELTS 6.5（各セクション5未満なし）。具体的な要件は公式サイトをご確認ください。CS への転向組も受け入れています。

## 就職活動
1. NIT Karnataka CS 学部、修士入学前に SAP Labs India で正社員1年、在学中はパートタイムで RA と TA、2024年の修了後に中小企業で Junior Software Developer として正社員
