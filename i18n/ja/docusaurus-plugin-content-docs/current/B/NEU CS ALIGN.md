# NEU CS Align
この記事は CS Align プログラム（CS のバックグラウンドがほぼない学生が CS へ転向するために設計されたプログラム）についてのものです。MSCS プログラムとは区別してください。

## プログラム概要
結論から言うと、シリコンバレーに残ると決めていて、伝統的ではないキャンパスを受け入れられ、LeetCode に打ち込み自力で頑張る覚悟があるなら、このプログラムは実はかなり魅力的です。NEU のブランド＋シリコンバレーという立地＋Co-op 制度は、専攻転換者にとって確かな入口を開いてくれます。ただし、充実した大学キャンパス、情報が透明な一流の教授陣、就職活動を手取り足取り支えてくれるアドバイザー、あるいはハードな授業を期待しているなら、がっかりするかもしれません。サテライトキャンパスと Boston のメインキャンパスの差は確かに存在します。

まずキャンパス環境です。シリコンバレーキャンパスは今も San Jose ダウンタウンの商業オフィスビルに入っています（WeWork のような形態）。2026年時点でも、完全に新しい独立キャンパスへの移転は済んでいません。学校は拡張計画を宣伝し続けていますが、今も「オフィスビルで授業を受ける」スタイルです。芝生も寮も大きな図書館もなく、駐車場は有料です。良い点はダウンタウンなのでとても便利なことです。近くの SJSU のキャンパスで勉強会ができ（そこの勉強の雰囲気は本当に良いです）、周辺には中華系スーパーやレストランもたくさんあります。気候は一年中快適で、夏にときどき熱波があり、冬は雨季です。住まいは比較的治安の良い 95131/95133 の中華系エリアを選ぶ人が多く、2B2B のルームシェアで1人あたり月 $1,000-1,500 程度です（今はもっと高い可能性があります）。ダウンタウンのアパートはキャンパスまで徒歩5分ですが、ホームレスが多く、あまり安全とは感じられません。住む場所に応じて、自転車、公共交通機関、車のいずれでも通えます。

このプログラムに出願する場合、CS の前提科目を2つより多く履修していてはいけない点に注意してください。2つを超えて履修している場合は、MSCS プログラムにしか出願できません。出願のコツをいくつか挙げます。できるだけ早く提出しましょう！シリコンバレーは非常に人気が高く、枠がすぐに埋まります（レビュアー注：これには異論があります。2025年から NEU の出願人気は大きく下がり、2023年のピーク時と比べておよそ半分になりました。2023年には誰もが出しておく「宝くじ」のようなプログラムでした）。出願時の経歴にデータ構造／アルゴリズムなどの CS 基礎科目を書かないでください。Align は CS のバックグラウンドがゼロであることを前提としているため、書くと不利になります。Align＋General CS＋DS/IS を同時に出願して、どれが先に結果が出るかを見ることもできます。事前に入学担当者と1対1の面談を予約して、履歴書とエッセイを見てもらうことを強くおすすめします。対応はかなり良く、連絡先は Google で簡単に見つかります。

出願時には出願料免除コード（waiver code）を探してみてください。


## 合格の傾向と代表的なデータポイント
学生の構成は非常に多様で、新卒、2つ目の修士を取る人、何年も働いてから専攻を変える人が混ざっています。中国人学生の割合が高く（課題の相談やグループプロジェクトがとても楽です）、インド人学生も多いです。雰囲気は和やかで、互いに助け合い、一緒に食事や遊びに行くこともよくあります。Align の1期あたりの人数はおよそ80-150人で、プログラムは今も拡大中です。

2025 Fall から人気が下がり、合格のハードルは目に見えて下がりました。

1. Nanjing University 経営学部出身、Alibaba でのインターン経験あり
2. UMN 統計学部出身、GPA 3.7

## 就職実績とデータポイント

中心となる価値はやはり就職活動／Co-op です。シリコンバレー最大の売りは、テック業界の中心にあるため理論上インターンの機会が豊富なことです。NEU の Co-op 制度は実際に強力で、多くの企業がこの制度を通じて Northeastern の学生を積極的に採用しています。Amazon には Align 専用の準備プログラムまであります（OA の練習を手伝ってくれますが、合格は保証されません）。しかし現実は厳しく、特に2023-2025年の不況以降はなおさらです。アドバイザーの助けは限られており、多くの場合「まず授業に集中しなさい」で終わります。就職状況としては、学生の約1/3〜1/2が比較的早くインターン／正社員の職を見つける程度で、大手企業から return offer をもらうのは難しいです。結局は本人の実力、つまり LeetCode＋プロジェクト＋履歴書次第です。入学前か1年目のうちにしっかり取り組むことを強くおすすめします（最低200-400問がスタートライン）。そうすれば3学期目にすぐインターンに挑戦できます。もっと早く始めればよかったと後悔し、co-op 中に仕事が終わってから図書館で徹夜する人がたくさんいます。

1. Nanjing University 経営学部出身、Alibaba でのインターン経験あり、CDK Global の SDE に内定
2. UMass 金融学部出身、Boston の小規模企業でインターンに内定
3. Huazhong University of Science and Technology 金融学部出身、Meta の SDE new grad に内定

4. Southwestern University of Finance and Economics 金融学部出身、NEU の金融修士も取得。Align 入学前に financial analyst として勤務、在学中に Amazon と Tesla でソフトウェア開発インターン、2024年の修了後に Amazon の Software Dev Engineer。

## 開講キャンパス

MSCS（通常の MSCS と Align 版の両方を含む）を開講しているキャンパスです。一般に、シリコンバレーと Seattle の出願需要が最も高いです。

1. Boston, MA（メインキャンパス。最も伝統的かつ総合的で、通常リソースが最も豊富。PhD への進学に向いている）
2. Seattle, WA（Seattle キャンパス。テック企業が密集しており就職機会が豊富。ときどき約25%の奨学金あり）
3. Silicon Valley, CA（San Jose／シリコンバレーキャンパス。大手テック企業に近い）
4. Oakland, CA（Oakland キャンパス。一般に奨学金が多めで、基本15%＋merit で最大25%）
5. Arlington, VA（Virginia 州 Arlington キャンパス。Washington DC に近い）
6. Miami, FL（Miami キャンパス。一部の学期のみ開講）
7. Vancouver, BC（カナダ Vancouver キャンパス。留学生に人気があり、テック産業が盛ん）
8. Portland, ME（Maine 州 Portland キャンパス。$25K の固定奨学金をもらったという報告あり）
