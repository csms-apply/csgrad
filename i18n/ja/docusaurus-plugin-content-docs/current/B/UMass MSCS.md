# UMass MSCS

## プログラム紹介
UMass には全米 1 位の学食（dining hall）があります。MSCS の授業の多くはかなり易しいので、就職活動に集中しながら気楽に通うのにとても向いています。UMass はボストンに近いマサチューセッツ州にあります。

## 合格傾向とデータポイント
1. 留学生、GPA 3.6、IELTS 8.0、職歴 4 年以上、教授と同僚からの推薦状 3 通
2. VIT CS 学部 9.0/10、JPMorganChase で正社員 3 年半、学部在学中にインターン多数
3. インドの学部出身、GPA 8.1/10
4. インドの学部出身、GPA 9.48/10
5. IIT CS 学部、GPA 9.5/10、Microsoft で正社員 1 年
6. インドの学部出身、GPA 9.5/10
7. UMass CS 学部、GPA 4.0


## 就職実績とデータポイント
以前は spring 入学の学生も就職活動に役立つよう CPT を取得できていました。就職先は主に Amazon からのオファー頼みで、Tesla もかなり多くのオファーを出していました。

1. VIT CS 学部 9.0/10、JPMorganChase で正社員 3 年半、Salesforce のインターンに合格
2. インドの学部出身、インターン経験なし、AWS に合格し正社員登用に成功
3. インドの学部出身、Barclays で正社員 3 年、PayPal の ML インターンに合格
4. インドの学部出身、正社員 2 年、Meta の SWE に合格
5. インドの学部出身、インターン経験 3 回、Microsoft のインターンに合格
6. UMass CS 学部、UMass 学内で SDE インターン、Microsoft のインターンに合格

7. IIT Hyderabad CS 学部、修士課程の前に Adobe で正社員 3 年、2025 年夏のプログラム在学中に KLA の Machine Learning Research Intern。
