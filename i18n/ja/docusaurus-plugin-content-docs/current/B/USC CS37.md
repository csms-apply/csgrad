# USC CS28

## プログラム概要
2年制のプログラムで、GPA しか見ないことで有名です。クラスの規模は非常に大きく（CS28 のほかに CS37 もあります）、1,000人近くになります。

## 合格の傾向
経歴と GPA しか見ません。推薦状は任意で、rolling 方式です。すべての学校の出願者をまとめて GPA で並べ、上から順にオファーを出していきます。985/211大学の経歴が重視されます。

インターンや研究は見られません。GPA の高い人が滑り止めとして出願するのにおすすめです。

## RA／PhD への移行の機会

非常に難しいです。USC の CS 関連プログラムはクラスの規模が非常に大きいため RA の機会を見つけるのがとても難しく、PhD への移行も困難です。

## 就職実績
平凡で、主に Amazon の採用頼みです。

1. UESTC CS 学部、GPA 3.79、Tencent で2年の正社員経験、TikTok の MLE に内定
2. Zhongnan University of Economics and Law CS 学部、GPA 3.84/4、Meituan での4か月のインターンと QD でのインターン経験あり、TikTok の intern に内定
3. インド人の同級生、1年の正社員経験、LA の小規模企業に内定
4. インド人の同級生、インターンなし、Amazon の intern に内定
5. Xidian University CS、インターンなし、小規模企業の intern に内定
6. インド人の同級生、1年の正社員経験、Amazon の intern に内定し、正社員登用にも成功
