# UCI MCS

## プログラム概要
在籍延長ができない専門職プログラムで、クォーター制で運営されています（5月にインターンを始められない＋進度が速く就職活動の時間が圧迫される＋3か月ごとに試験＋クォーター制では十分に教えられないと不満を漏らす教授もいる）。

職務経験とある程度の就職活動の準備を整えてから入学するのが理想です。つまり、米国で仕事を見つける準備がすでに万全である必要があります。MSWE プログラムのほうがいくつかの点で MCS より優れています。たとえば最初のクォーターに試験がないので負担が少なく、カリキュラムもより実務寄りです。MCS が向いているのは、渡米前にすでに LeetCode を300問以上解いている学生か、正社員の職務経験がある学生だけです。全体として MSWE には及びません。PhD を目指すなら、UCI の MSCS プログラムを検討してください。

## 合格傾向とデータポイント
GPA 3.5前後なら合格の可能性は十分あります。インド人学生は通常3年以上の職務経験を持って入学しますが、中国本土の学生はたいてい正社員経験がありません。MCS プログラムは UCI の自校の学部生を優遇しません（GPA 3.8以上の UCI CS 学部生が不合格になったという報告が複数あり、MCS の授業が学部の授業とほぼ同じで、成績要件まで同じだからだと言われています）。

1. Tianjin University EE 学部、GPA 3.56、State Grid と中小企業でのインターン
2. University of North Texas CS 学部、GPA 3.85
3. UCI CS 学部、GPA 3.98
4. Gonzaga University Math + CS 学部、GPA 3.9

## 就職実績
2022年のインターン獲得率は89%でしたが、これは主に3年以上の職務経験を持つインド人学生が多く、数字を押し上げたためです。中国人学生の獲得率はそれほど楽観的ではありません。

1. UCI CS 学部、インターン経験なし、中小企業の Android 開発者ポジションを獲得
2. Gonzaga University Math + CS 学部、Smartsheet のインターンを獲得
3. Tianjin University EE 学部、インターンなし
4. インド人の同期、Barclay Center で正社員3年、Pure Storage のインターンを獲得、新卒で Meta に入社
5. インド人の同期、正社員1年、Veeva Systems（アーバイン地元の中小企業）のインターンを獲得し、正社員登用に成功

6. National Central University CS 学部、修士在学中に中小企業で SWE インターン、2025年修了後に Matching Donors でパートタイムの Web Developer

## デメリット
クォーターが6月中旬に終わる（2026年春クォーターは6月12日に終了）ため、5月や6月上旬にインターンを始めることができません。その結果、実質的に大企業でしかインターンができません（あるインド人の同期は6月上旬開始のオファーを受けましたが、CPT が取れずにオファーが取り消されました）。
