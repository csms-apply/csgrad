# NEU MSCS
通常の MSCS プログラムです。CS Align プログラムとは区別してください（優劣があるわけではなく、CS Align は CS へ専攻を転向する人向けに設計されたプログラムです）。

## プログラム概要
NEU は CS プログラムが非常に多く、Boston、SV、Seattle などキャンパスごとにさまざまな CS プログラムを運営しています。最近開設された Oakland キャンパスは景色が良く奨学金もあるので、検討する価値があります。SV キャンパスはワンフロアに教室が 2 つしかなく質素に見えますが、自習スペースは十分です。研究に興味がある学生は、教授の多い Boston キャンパスを選ぶことが多いです。とはいえ、Boston、SV、Seattle のどのキャンパスでも、ほとんどの学生は専攻転向を目的に NEU に来ています。授業数は Boston が最も多く、次が Seattle で、SV は選択肢が限られます。

通常トラックの学生は 1 学期延長して最長 28 か月在籍できます。NEU の授業は採点が甘いものが多く、就職活動に集中するのにとても向いています。たとえば Mobile Application 5520、Computer Networks 5700（David）、Building Scalable Distributed System 6650（Prasad）などの授業があるので、就職活動の期間は楽な授業を選んで取ることができます。

## 開講キャンパス

MSCS を提供しているキャンパス（通常の MSCS と Align 版の両方を含む）：

1. Boston, MA（本キャンパス。最も伝統的かつ総合的で、全体的にリソースが最も豊富。PhD への移行に向いています）
2. Seattle, WA（Seattle キャンパス。テック企業が集まっており就職の機会が多く、ときどき約 25% の奨学金を提供）
3. Silicon Valley, CA（San Jose/Silicon Valley キャンパス。大手テック企業に近い）
4. Oakland, CA（Oakland キャンパス。全体的に奨学金が多く、基本 15%＋merit で最大 25%）
5. Arlington, VA（Virginia 州 Arlington キャンパス。Washington DC に近い）
6. Miami, FL（Miami キャンパス。一部の学期のみ開講）
7. Vancouver, BC（カナダの Vancouver キャンパス。留学生に人気の選択肢で、テック産業が盛ん）
8. Portland, ME（Maine 州 Portland キャンパス。一部の学生が固定 $25K の奨学金を受けたと報告）

## 就職実績と Data Points

NEU には NUworks という学内の就職システムがあり、履歴書をそのまま提出でき、面接に呼ばれる確率もかなり高いです。2025 年夏の就職シーズンでは、通常 100 件応募して面接は 1 件ほどでしたが、NUworks では 100 件応募すると 3〜4 件の面接を得られます。co-op 制度、軽い課題量、恵まれた立地のおかげで、NEU MSCS は就職志向の学校選びで常に人気の選択肢です。NEU MSCS には co-op の機会が 1 回含まれており、秋学期にフルタイムのインターンができます。Georgia Tech MSCS の co-op に少し似ています。NEU CS Align は co-op の機会が 2 回あるため、就職率がやや高めです。たとえば 2024 Fall に入学したある学生は Summer 2025 のインターンを見つけられませんでしたが、Fall 2025 のインターンを引き続き探すことができ（TikTok、Tesla、NVIDIA、Snowflake などから連絡が来ることを期待して）、それでもだめなら Spring 2026 まで挑戦し続けることができました（TikTok と Amazon に期待して）。最終的には LeetCode の問題演習と、Udemy/YouTube のチュートリアルに沿って作ったプロジェクトでインターンを獲得しました。夏のインターンしか認めない学校よりもはるかに多くのチャンスがあるわけです。この学生が別の学校に行っていたら、夏に失敗した時点で終わりで、すぐに new grad の就職活動に移らなければならなかったでしょう。そしてご存じのとおり、アメリカでのインターン経験なしに new grad のポジションを得るのは非常に難しいです。まさにこの点が、NEU CS/IS/Align の co-op 制度をこれほど価値あるものにしています。以前は Amazon が NEU の学生（NEU CS の学生限定）専用の co-op ポジションを設けていたこともありましたが、今は廃止され、過去の話になりました。
