# コンテンツを投稿する

## CS Grad プロジェクトは Pull Request によるコンテンツの投稿に対応しています
1. まず [CS Grad プロジェクトのリポジトリ](https://github.com/csms-apply/csgrad)を開き、Fork をクリックします

![CS Grad の GitHub リポジトリの Fork ボタン](/img/en/fork.png)

2. Create fork をクリックして、プロジェクトを自分のリポジトリに Fork します

![CS Grad の GitHub の create-fork フォーム](/img/en/createfork.png)
