# Yale MSCS 1 Year

## プログラム紹介
名門大学の CS 修士課程の多くは、Yale や UC Berkeley のように 1 年制です。2 年制を設けているところは合格が極めて難しい（Stanford MSCS / Stanford MSEE / CMU MSCS）か、そもそも存在しません。たとえば MIT EECS がそうです（MIT EECS の修士号を得る唯一の方法は、MIT EECS の PhD を中退することです）。そのため Yale は、トップ 10 の大学に行く夢をかなえたい中国の多くの CS 学生にとって人気の選択肢です。Yale のキャンパスはホグワーツのように美しく、Yale の CS 理論グループはとても強いです。

## 合格傾向と代表的なデータポイント
Yale はハードスペックを極めて重視します。コミュニティで報告されたデータポイントによると、インターンは考慮されず、トップカンファレンスの論文も考慮されません。履歴書で重要なのは GPA >= 3.8、GRE >= 328、TOEFL >= 105 の 3 つだけです。（注：2024 年秋と 2025 年秋の出願サイクルからは、GRE 325 点や 322 点での合格データポイントもあります。ただし、Yale MSCS の合否が大規模な加重スコア計算機のようなものだという本質は変わっていません。）研究経験の要件はなく、公式サイトにも「This is not a research degree, so research experience is not required.」（研究型の学位ではないため、研究経験は必要ありません）と明記されています。

中国本土出身の合格者の多くは 985 大学の出身です（2022 年には Zhejiang University だけで 20 人近くが合格）。海外の学部出身者はより多様ですが、共通点は名門大学＋高い GPA です。

## 就職実績とデータポイント
2023 年はかなり厳しい年でした（周囲のデータポイントによると、30 人以上の学生のうち就職できたのは 2 人だけ）。全体として、結果はその年の就職市場の状況に大きく左右されます。市場が良ければ結果も良くなります。ただし、同じく 1 年制の UC Berkeley EECS MEng と比べると、Yale MSCS に目立った優位性はありません。Yale MSCS に来る前に、すでに中国で十分なインターン経験や SDE の正社員経験がある人におすすめです。

2. UT CS 学部。Yale MSCS 卒業後、Google に合格
3. UT CS 学部、GPA 3.96、Microsoft 蘇州でインターン。Yale MSCS 卒業後、Databricks に合格
4. UCSD CS 学部、Nokia で 3 か月インターン。Yale MSCS 卒業後、IXL に合格
