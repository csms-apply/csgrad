# UMN MSCS

## プログラム概要
TAになれば学費が免除され、税引き後で月約$1,600の給与も出ます。UMN BSCSの学生にとっては滑り止め校（safety school）です。生活は比較的快適で、PhDへの移行を考えているなら検討する価値があります。

## 合格の傾向と代表的なデータポイント
GPAの高いC9大学出身の分野転向者＋GPAが中程度の985／有力211大学のCS専攻出身者。

## 就職実績とデータポイント
大手テック企業については、主にAmazonの採用頼みです。全体として、就職状況は良くありません。

- UMN CS学部、修士入学前にIDG CapitalでFinancial Data Analystのインターン、2022年の修士修了後にVanguardで正社員のSWE。

## PhDへの移行
指導教員が見つかればPhDに移行でき、とても良い環境です。UMNはシステム分野がかなり強いです。他校に進みたい場合も、Wisconsin、Purdue、JHUなどの有力校からオファーを得た学生がいます。ほとんどの場合はUMNに残ります。
