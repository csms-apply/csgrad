# Upenn CIS

## プログラム概要

実質的には CS のプログラムです。修士号の取得には 10 科目の修了が必要です。一般的な修了スケジュールは次のとおりです。

2 年トラック（3-3-2-2）
1.5 年トラック（3-3-4）
授業履修トラックか論文トラックを選べるため、就職活動にも PhD 出願にも柔軟に対応できます。学費はフルタイムの場合、2026-27 年度で 1 学期あたり 3 CU なら約 $29,399、4 CU なら $38,224（諸費用込み）ですが、2 年目に履修科目を減らせば安くなることもあります。

Ivy League という肩書きはとても魅力的です。中国本土の学生の合格ラインは SS ティアまで上がることがあり、米国の学部生なら S ティア程度です。ただし、就職実績は Stanford や CMU SCS レベルのプログラムとは本当に比べものになりません。

## 就職実績とデータポイント

全体として就職活動はまずまずで、主に就職市場の状況次第です。

## 授業体験
ペースが速く、学業負荷が重く、楽な授業はありません。負荷は学部の 2 倍です。特にシステム系の授業では、
ほぼすべてのチームメンバーが何日も図書館にこもり、深夜までプロジェクトに取り組むのが当たり前です。
たとえば CIS 5050 Software System では Gmail のような分散メールシステムを構築する必要があり、学期中ずっと並行処理、同期、ロードバランシングの問題をデバッグすることになります。
CIS 5530 Networked System では Layer 3 のルーティングプロトコル + Layer 7 の分散検索エンジンを実装する必要があり、
デバッグのたびに OS との戦いになります。CIS 5550 Internet and Web System は Penn で最も難しい授業の一つで、
Google Search Engine をシミュレーションします。授業のプロジェクトの域を超えた本格的なもので、履歴書に書く価値が十分にあります。
