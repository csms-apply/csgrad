# UCSD CS75

## プログラム概要


UCSD の CS75 は多くの人に好まれている、非常に人気のあるプログラムです。UC 系の大学の中では、就職に強い CS プログラムの上位 2 校に入るでしょう。

UCB には 1 年制の MEng プログラムしかなく、UCLA の MSCS は合格が極めて難しいうえ研究寄りで、就職にはあまり向いていません。そのため、就職志向の学生には SD のほうが良い選択かもしれません。

2025 年から UCSD CS75 は co-op を提供しています。素晴らしい立地＋安い学費＋TA ポジションで学費が半減＋co-op も可能と、実質的にあらゆる面でバランスの取れたプログラムです。

![cs75coop](/img/en/cs75coop.png)

プログラムの負担は極端に軽くすることもできます。私の知っている先輩は、授業に出席しなくても GPA 4.0 を取れると言っていました（CSE 258 - Recommender Systems and Web Mining のように負担の少ない授業を戦略的に選べばよいのです）。もちろん、授業の質を重視する学生は、コーディングの比重が高い授業（フルスタックのプロジェクトを作る CSE 210 - Principles of Software Engineering など）を選ぶこともできます。

UCSD は海のすぐそばの San Diego にあり、オーシャンビューの住まいもあります。学内の寮はとても安く質も良いので、北米の CS 出願者の多くにとって必ず出願すべきプログラムです。このプログラムとよく比較されるのは CMU MSIN、UIUC MCS、UT Austin SES、GT CSE などです。


## 合格の傾向と代表的な Data Points
ひとことで言うと、合否の予測が非常に難しいです。Stanford EE に合格した学生がここでは不合格になったり、あまり知られていない大学出身の学生が合格したりしています。

ただ、24 Fall のオファー保持者グループの統計を見ると、GPA 3.9+ の学生がオファー保持者の半数を占めていました。高い GPA は合格の必要条件ではあるものの、十分条件ではないと言えます。研究やインターンなど他の要素は、合否との明確な相関が見られません。Personal statement にも明確な好みはありません。筆者は就職準備について書いて合格し、友人は研究と PhD への抱負だけを書いて合格しました。【ヘアドライヤー理論】：UCSD には、合否が出願者の GPA/GRE/TOEFL、インターン、研究とは無関係で、純粋にランダムであることを示唆する data point がかなりあります。非常に優秀な出願者がすぐに不合格になるケースも多くありました（推測：書類を審査する前に不合格処理されたようです）。

## 合格発表前のミステリー
ポータルの変化が何を意味するのか、以前に私がまとめた内容です。

1. WES の成績証明書の提出依頼が表示される：合格です。北京時間の午後 4 時に表示されます（ポータルは California 時間の午前 0 時に更新され、合格が通知されます）
2. チェックリストの上の小さな文字が消えるが、チェックリスト自体は残っている：これも良い知らせです。24Fall の例では、たいてい翌週に合格通知が来ます
3. チェックリストの上の小さな文字が消えない：出願書類はまだ審査されていないので、引き続き待ちましょう


## 就職実績と Data Points

CS75 と ECE はどちらも就職にかなり有利です。CS75 は楽な授業を選べば授業の難易度を最小限に抑えられるので、就職活動の時期に自分を追い込まずに済みます。ECE には co-op があります。UCSD は NVIDIA の target school でもあります。

1. NYU DS 学部、中国の小規模企業でインターン 3 回、Google の new grad に就職
2. インド人学生、Microsoft で正社員経験 1.5 年、Qualcomm のインターンに就職
3. UIUC CS 学部、アメリカ国外の小規模企業でインターン 2 回、LA の小規模企業のインターンに就職
4. North Dakota State University CS + Statistics 学士、2022 年 AWS SDE インターン、2023 年から SDE 正社員、2026 年から SDE II。
