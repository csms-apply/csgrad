# Wisc CS PMP
## プログラム概要
Wisc MSCS は Ph.D プログラムと同じ出願者プールを共有しているため、競争が非常に激しいです。PMP プログラムは、実質的に他校の MCS プログラムに相当します。


学費は安く、州外生は 1 単位あたり $1,503.40 です。最終学期はパートタイムにして単位ごとに支払えるため、30 単位で総費用は約 $45k と、非常にお得です。

インターンの機会は 2 回（秋と春のインターンも可）、プログラム期間は 1.5〜2 年（2.5 年への延長も可能）で、Gatech MSCS によく似ています。


オンラインの PCP プログラムに出願してから PMP に移ることもできます（主に GPA が基準）。

## 合格ラインとデータポイント
出願者数は年々増えています。
22Fall：出願者約 900 人
23Fall：出願者 1,000 人超


正社員としての職歴は事実上必須で、インターン経験はカウントされません。私が出願したとき、CS PMP は全出願者に直接メールを送り、インターン経験を職歴として書かないよう案内していました。「卒業後の就職」だけが正社員の職歴として認められます。当時のフォーラムや SNS での結果を見る限り、この基準は非常に厳格に運用されていました。
SDE の正社員経験があれば合格率は約 85% です。なければ約 0.5% まで下がります。

24 Fall では、正社員経験のない留学生の学部出身者はたった 1 人だけで、それ以外はほぼ全員が中国の大手 IT 企業で数年の経験を持っていました。

1. UCI CS 学部、GPA 3.76
2. インドの学部、アメリカの修士、ニューヨークで 7 年の職歴
3. IIT 学部、AWS で 2 年、以前に Microsoft でインターン
4. インドの学部、GPA 8.3、Samsung で正社員 2 年

## 就職実績とデータポイント
学内での同級生同士のプレッシャーがなく、合格者のほぼ全員が正社員経験を持っているため、就職率は自然と高くなります。

大手 IT のインターンおよび正社員オファー：
1. Amazon（インターン + リターンオファー）
2. Pinterest（インターン + リターンオファー）
3. Facebook（インターン + リターンオファー）
4. Dell EMC（インターン + リターンオファー）
5. IIT 学部、AWS で 2 年、以前に Microsoft でインターン、SF の中小企業を獲得
6. インドの学部、GPA 8.3、Samsung で正社員 2 年、Amazon を獲得
