# Duke MSCS


## プログラム概要
CS と ECE のプログラムは役割分担がかなり明確で、CS は研究寄り、ECE はエンジニアリング寄りです。ただし、これは完全に正しいわけではありません。MSCS の学生も多くが業界に進み、とても良い就職先を得ています。
MSCS は授業選択の自由度が高いです。修了には 10 科目が必要です。プロジェクトまたは論文トラックを選ぶと CS 番号の科目は 4 つで済み、授業履修のみ（course-only）の場合は CS 科目が 6 つ必要です。
Duke CS には LeetCode 演習と面接対策のための専用授業もあり、業界の専門家が LeetCode の問題を一緒に解きながら指導してくれます。就職活動に関連する授業をもっと取りたい場合は、ECE の開講科目も検討できます。

OS / Network / Algorithm / Web Full Stack / Distributed System / Compiler / Architecture / Security など、主要な授業はすべて開講されています。
プログラムは通常 2 年間で、一般的な履修数は 3-3-3-1 です。最初の 3 学期は履修科目数にかかわらず学費は同じで、最後の学期は科目ごとに課金されます。

## 合格データポイント
過去の合格率は 15% ですが、最近は定員が拡大しています。GPA、GRE、TOEFL のスコアが重視されます。
学生は主に米国の学部出身者で、CS と DS の両方の学部バックグラウンドがいます。

1. SJTU CS 学部、学年 2 位（GPA 93+）、TOEFL 110、GRE 328
2. SJTU-UMich CS 学部（SJTU GPA 3.8、UMich GPA 3.97）
3. OSU CS 学部、GPA 3.98、TA 経験 2 年
4. University of Nottingham Ningbo CS 学部、GPA 3.97
5. インドの学部、GPA 9.28、インドで Google SDE インターン + Google 正社員 1 年
6. Vanderbilt University CS+Math 学部、GPA 3.922
7. Wellesley College CS 学部、GPA 3.78



## 就職実績とデータポイント
進路は非常に多様です。Microsoft、Adobe、Salesforce などに就職した人がいます。
学内の競争は実質ほぼありません。同時に、学校の知名度だけで FB や Google などビッグテックの書類選考ラインは十分に越えられます。
その先は本人次第です。ビッグテックの面接は、結局カメラをオンにして座って問題を解くだけですから。

22Fall の在校生は、Duke MSCS という肩書きで十分だと話しています。
結局は本人の LeetCode 演習、ネットワーキング力、そして運次第です。就職活動や LeetCode の雰囲気は、確かに UCSD CS75 や Gatech MSCS などの大規模州立大プログラムほど盛り上がってはいませんが、
「22Fall では、LeetCode や模擬面接に真剣に取り組み、積極的に社内推薦を求めた人は全員オファーを得ました。もともと PhD 進学を考えていた同級生は直前に就職へ切り替え、
研究経験だけでインターン経験がないにもかかわらず、Google に就職しました」とのことです。コストパフォーマンスでは CS75 や Gatech MSCS に及びませんが、
PhD に進むことも、就職に切り替えることもできる前例があります。コスパといえば、Duke に対する最初の反応は誰もが「高すぎる」です。Duke は授業選択が柔軟で、学費は高いものの、
3+3+4 のパターンで履修し、最後の学期は在籍だけにすれば、合計で最低約 $105k です（2026-27 年度の学費は 1 学期 $34,940 で、少なくとも 3 学期のフルタイム在籍が必要）。TA のポジションはとても見つけやすく、
1 学期あたり $6,200 が支給されます。図書館や食堂などでの学内ワークスタディの機会もあり、月約 $1,000 です。

1. UCI CS 学部、インターン経験なし、Meta SWE インターンに合格

   BotBuilt Machine Learning Intern に合格
3. Vanderbilt University CS+Math 学部、PwC と Sohu で短期インターン、Salesforce SWE インターンに合格
4. University of Edinburgh CS 学部、MLE インターン経験あり、Syngenta Software Engineer Intern に合格

## RA と PhD への転籍
受け入れてくれる教授さえ見つかれば、チャンスは大きいです。CS 学科の教授の多くは毎年 MSCS の学生から新メンバーを募集しています。
教授の同意を得られれば、PhD プログラムに転籍できます。周りにも Duke CS PhD に転籍した学生がかなりいます。

Duke MSCS はもともと研究志向のプログラムです。少人数で選抜が厳しいため研究室に入る機会が多く、
UCSD CS75 や Gatech MSCS などの大規模州立大プログラムよりも PhD への転籍がしやすいです。
（PhD への転籍に成功した 22Fall の学生の話です。彼は当時 Gatech MSCS と Cornell 本校 CS MEng のオファーも持っていました。彼のガールフレンドは CS75 に進みましたが、人が多く競争が激しくて、PhD 志望の学生の多くが諦めたそうです。）
また、Duke MSCS の 2 年間は PhD の在籍期間として正式に算入できるため、MS と PhD を合わせて 4〜5 年というのはとてもお得です。

## 授業の感想

1. CPS 510 Operating System
教授：Matthew Lentz（大学院レベルで、より抽象的）/ Danyang Zhuo（学部の OS で、説明がわかりやすい）
授業内容：UW CSE 451 に沿って OSTEP（x86）を教え、課題は MIT 6.828（xv6 RISC-V）に沿っています。両者の間にギャップがあり、自習で埋める必要があります。
課題：毎回採点スクリプトが配布され、提出前にすべてパスすれば満点です。プロジェクトのテーマは自由で、難易度はさまざまです。
試験：A4 のチートシート持ち込み可（両面）、ほとんどが記述式の短答問題で、コーディングはありません。
総評：学部で OS を履修していない場合はついていくのが大変で、授業外での学習がかなり必要です。1 学期しっかり取り組めば、得るものはとても大きいです。

2. CPS 514 Advanced Computer Networks (ECE 558)
教授：Bruce Maggs / Xiaowei Yang
授業内容：前半は従来型のネットワーク、後半は分散システムを扱います。知識ポイントが多いです。
課題：OH でたくさん質問できます。Bruce は答えを直接教えてくれるので、試験の正答率が大きく上がります。
試験：選択式で +2/-2 の採点方式のため、間違えると 2 倍減点されるので要注意です。出題内容は予測しにくいです。
プロジェクト：過去のプロジェクトが多数提供され、好きなものに取り組めます。学期中のコーディング量は少なく、学習はほぼ自主的です。
総評：教授陣は知識が豊富ですが、講義は自由なスタイルです。知識ポイントが多く、復習の負担が大きく、試験のプレッシャーも高いです。

3. CPS 590 Advanced Web App Development (Dennis Quan)
教授：Dennis Quan（強くおすすめ、業界経験が豊富）
授業内容：
TypeScript
JS のコア概念（closure、scoping、promise）
Vue + Express + MongoDB + Socket.io
自動テスト（Playwright）
ロードバランシング（nginx）、CI/CD（GitLab）、Docker、TLS
認証（authentication）、認可（authorization）、Cookie、Session
課題：課題は 5 つで、難易度が徐々に上がります。
試験：毎週小テストがあり、後半は簡単ではないので、しっかりついていく必要があります。
プロジェクト：期末プロジェクトの方向性は明確で、4 種類から選び、授業で学んだことをすべて結びつけます。
総評：論理が明快で、業界の実務に沿っています。Dennis は非常に優れた講師で、受講する価値は十分にあります。

4. CPS 512 Distributed Systems
教授：Danyang Zhuo
授業内容：毎回論文を読んでレスポンスを書く必要があり、授業内容は論文に関連しています。
プロジェクト：分散システムを自分で実装する必要があります。
総評：研究志向で、分散システムを深く学びたい学生に向いています。
