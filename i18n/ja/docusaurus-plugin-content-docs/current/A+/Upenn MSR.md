# Upenn MSR

## プログラム概要
来る前は、このプログラムを「超ハードコアで、超競争的で、ラボで昼夜を問わず追い込まれる場所」だと想像していました……
ところが来てみると、ROBO は米国で最も自由度が高く「自分で組み立てていく」ロボティクス修士課程の一つでした！ MCIT/MCIS などとのダブルディグリーも可能です。

一番の感想を一言でまとめると：
「自由度が高い＝可能性は無限、でも自分が何をしたいのかをはっきり分かっていなければならない、ということでもある。」
決まったルートはありません。学びたいことを学び、興味のある研究分野ごとにふさわしい専門家を探し、自分の興味とキャリアプランに合わせて修士の経験を完全に自分で形作れます。

フィラデルフィアの生活費：中の上で、NYC やベイエリアよりは安く、ヒューストンや中西部の都市よりは高めです。
家賃（ルームシェア）：$900-1400/月、自炊＋たまに外食：$500-800/月。日々のスケジュールは次のとおりです。
研究をしない場合：月〜金は授業＋宿題。効率よくこなせば、さまざまなイベントに参加する自由時間が十分あります。
研究をする場合：授業＋宿題＋ラボ。研究に週10〜20時間ほどかかるので、スケジュールはかなり詰まります。
ただ、Penn Engineering ではほぼ毎週さまざまな研究セミナーが開かれているので、方向性を探りたい学生は空き時間をそれで埋められます。

## 合格ラインとデータポイント
秋入学の各学年は約30人で、そのうち中国人学生は通常6〜8人です。
バックグラウンドは非常に多様で、中国のトップ大学の学部から直接出願した人、米国の学部からの進学者、数年働いてから戻ってきた人などがいます。
合格は確かに競争的ですが、目立つ「裏口」があります。まず Penn Engineering の別のプログラム（EE、SE など）に入り、ロボティクスに本当に興味があれば、ROBO への移籍は実はずっと簡単です。多くの先輩が実際にこの方法を取っています。

1. UMass 機械工学 学部、ロボティクス関連のインターン多数
2. Worcester Polytechnic Institute Robotics 学部、GPA 3.95
3. IIT Automation 学部、GPA 9.04/10、正社員経験3年
4. インドの学部、GPA 8.72/10
5. NYU CS+DS、GPA 3.87/4

## 就職実績とデータポイント

最も多いのは Computer Vision＋コーディング関連のポジション（FAANG／ビッグテックの AI 部門、自動運転、ロボティクス企業など）で、Control、Planning、Manipulation の職種に進む人も多くいます。

企業の例：Tesla、Waymo、Aurora、Boston Dynamics、Amazon Robotics、Apple、Meta Reality Labs、Google X など。よくある職種名は Robotics Engineer、Perception Engineer、Software Engineer - Robotics などです。

給与レンジ（ここ数年のデータに基づく）：初年度の報酬はおおむね $150k-220k（base + bonus + RSU）で、企業や地域によって大きく異なります。

1. Upenn EE 学部、中小企業のハードウェアインターンを獲得
2. Upenn CE 学部、Amazon のハードウェアインターンを獲得
3. IIT Automation 学部、GPA 9.04/10、正社員経験3年、Amazon の DS を獲得
4. インドの学部、GPA 8.72/10、インターン多数、SF の中小企業で CV Engineer を獲得
5. Upenn EE 学部、インターン経験あり、SpaceX SDE Test Intern を獲得
6. NYU CS+DS 学部、中小企業で DS インターン、Amazon の DS インターンを獲得
7. University of Houston CS 学士、入学前に Kyndryl でのインターンと約2年間の正社員 Software Developer 経験、修士在学中の2025年から PCASO Lab でパートタイム RA

## 著名な教授陣

GRASP Lab は全米トップクラスの研究室の一つです。
代表的な名前をいくつか挙げると：
1. Vijay Kumar（ドローンと空中ロボティクスのレジェンド）
2. George Pappas（制御と最適化の専門家）
3. Mark Yim（モジュラーロボティクスの先駆者）
4. Kostas Daniilidis（コンピュータビジョン＋ロボットの知覚）
5. Jianbo Shi（CV の古典的な第一人者）

これらの教授のもとでは、ほぼ毎年多くの修士・PhD の学生が研究しており、機会も豊富です。
研究分野が合っていて自分から積極的に連絡すれば、PhD の学生がメンターとなってラボに迎え入れてくれる可能性は非常に高いです。
