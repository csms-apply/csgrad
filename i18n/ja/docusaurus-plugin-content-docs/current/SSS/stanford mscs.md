# Stanford MSCS

## プログラム概要
最高峰の中の最高峰で、欠点のない唯一のプログラムです。立地は申し分なく（カリフォルニアの日差しと海）、学校名の威光も抜群、CS ランキングもトップクラスで、Meta と Nvidia がすぐ隣にあります（車で10分）。夏に Meta や Nvidia でインターンをしても、別に住まいを探す必要すらありません（今いる寮にそのまま住めます）。就職実績も驚異的で、私の知る同期はほぼ全員が Nvidia の面接を受けています。PhD に移りたい場合は改めて出願する必要があります。授業の質は非常に高く、CS229 Machine Learning、CS231N Deep Learning for Computer Vision、CS224N（NLP）は CS の学生ならほぼ誰もが履修したことのある有名科目です。乗馬、アーチェリー、日本語などの科目も履修でき、のんびり心身を整えることもできます。寮の環境は最高です。




## 合格傾向と代表的なデータポイント
ターゲット校出身であることが求められます。中国本土の学部出身なら清華、北京大学、華東五校（Fudan、SJTU、Zhejiang、Nanjing、USTC）を指します。カナダの出願者なら上位2校と、その他の学校の優秀な候補者です。米国の学部出身なら上位30校＋工学の強い大学＋有力なリベラルアーツカレッジです。全体として、ほぼ全員が高い GPA（3.9以上）を持っています。中国本土の学部出身の合格者はごく少なく、大多数は米国の学部出身です。かなりの割合の学生が論文などの成果を伴う研究経験を持っており、業界で数年働いてから大学に戻ってきた人もいます。

## TA/RA の機会
TA：CS の TA ポジションは非常に多いです（例：CS224 は TA が24人）。TA になると学費が免除され、給与も支給されます（$10k/quarter）。待遇はとても手厚いです。

留学生が TA になるには英語の試験に合格する必要があります。私の知る Stanford の学生（CS、EE、ICME を含む）は、ほぼ全員が TA や RA のポジションを得られています。

## 就職実績とデータポイント
