# 📌 DataPoints データベース提出ガイド

## 1. 重要なお知らせ

**DataPoints© データベースは読み取り専用のデータテーブルです。**

次の3つのサブテーブルの内容を追加・修正したい場合は：

- DataPoints
- Applicant Information
- Program List

データベースを直接編集せず、必ず該当する **収集フォーム（Form）** から提出してください。

---

## 2. 提出の手順

### Step 1️⃣ 出願者情報の提出（1回のみ）

まず **「Applicant Information Collection Form」** に個人情報を入力してください。

- ✅ 提出は1回だけで大丈夫です
- ❌ 提出後は修正できません
- 🔗 以降のすべての DataPoints の項目がこのアカウントに紐づけられます

---

### Step 2️⃣ 合格 DataPoints の提出

**「DataPoints Collection Form」** から合格データを提出してください。

- フォームに記入する際、**Applicant フィールド** で先に提出した個人情報に紐づけます
- **回数制限なしで更新・修正** ができます

---

## 3. 一覧にないプログラムの追加

出願したプログラムがまだデータベースにない場合は：

1. **「Add New Program」** フォームからプログラムを提出します
2. 承認された後
3. 以降の項目を記入する際に「Program フィールド」でそのプログラムを検索して選択できます

---

## ✅ まとめのフロー図

Applicant Information（1回）
↓
DataPoints（何度でも更新可能）
↓
Progress（何度でも更新可能）
↓
プログラムがない場合 → Add New Program

---

ご不明な点があれば、管理者までお問い合わせください。
