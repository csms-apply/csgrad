# NEU SES

## プログラム概要
正式名称は Software Engineering Systems です。非常にオーソドックスな CS プログラムです。College of Engineering は現在 MS の出願料を免除しており（Spring 2027 と Fall 2027 入学）、1 回の出願で最大 3 つのプログラムにチェックを入れられます。そのため、NEU MSCS と CS Align にチェックを入れる際に NEU SES も一緒にチェックできます。SES は Boston、Arlington、Toronto などのキャンパスで提供されています。最新の一覧は公式ウェブサイトで確認してください。

## 合格の傾向と代表的な Data Points
IS より合格しやすいです。GPA 80+（100 点満点）の出願者なら誰でも可能性があります。

## 就職実績と Data Points
全体としては平凡ですが、インド人学生が Google DeepMind からオファーを得た例があります。

- インドの information science 学部、修士課程の前に小規模企業でソフトウェアエンジニアリングの正社員、2025 年修了後、小規模企業の SWE 正社員。
