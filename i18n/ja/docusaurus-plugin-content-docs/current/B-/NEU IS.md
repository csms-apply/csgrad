# NEU IS

## プログラム概要
co-op の機会がある、CS への専攻変更向けプログラムです。MSCS に近く、I-20 には CS 関連の名称である SE（Software Engineering）が記載されます。

キャンパスは複数あります。
アメリカの伝統的な大学キャンパスでの生活を経験したい、若くて就職を急いでいない、総合的なプロフィールが強い、という人は Boston キャンパスに行きましょう。大手 IT 企業への就職が目標の人や、Boston の冬に耐えられない人は Silicon Valley キャンパスがおすすめです。2025-2026 年入学では GRE は不要で、College of Engineering は Spring 2027 と Fall 2027 入学の MS 出願料を免除しています。

通常は 2 年で卒業しますが、途中でインターンや co-op をすると約 2 年半かかることがあります。

NEU IS は本質的に専攻変更者に優しいプログラムです。カリキュラムは NEU MSCS に近い一方、合格ラインはより低めです。主な強みは次のとおりです。

1. I-20 に CS 関連の名称である SE（Software Engineering）が記載されるため、SDE の就職活動にとても有利です。名称の不一致を理由に HR にふるい落とされることがありません。
2. co-op に対応しているので秋にフルタイムでインターンができ、夏のインターンしか認めない学校に比べてオファーを得るチャンスが何回か多くなります。
3. STEM プログラムなので、卒業後は OPT と STEM OPT の延長を合わせて合計約 3 年の就労許可が得られます。

## 合格ライン
周りには、Ivy League で他専攻の修士課程を修了した人が CS へ転向するために NEU に来るケースさえ多くあります。出願時には MSCS / CS Align / IS / SES を同時にチェックできます（現在は出願料が免除されており、1 回の出願で最大 3 プログラムまで出願できます）。

とはいえ、合格ラインは高くなく、かなり入りやすいです。

## 就職実績とデータポイント
以前、2025 Summer の SDE ポジションを探す学生を指導していたとき、NEU IS/MSCS/CS Align の学生の履歴書をたくさん受け取りました。実際に大手 IT 企業（Google、Oracle、Meta、LinkedIn など）から多くの面接を受けています。

1. インドの学部、HR のインターンの後に DA へ転向、中小企業の BA ポジションを獲得
2. インドの学部、IBM で 2 年と中小企業で 2 年、Google を獲得
3. インドの学部、HR のインターン、正社員の AI Engineer ポジションを獲得
4. National Chengchi University（台湾）IS 修士で GPA 4.3/4.3、学部は不明、IBM でのインターンと Microsoft のキャンパスアンバサダー、カリフォルニアの中小企業で AI Engineer インターンのポジションを獲得
5. インドの学部、正社員 2 年、Amazon Data Engineer の新卒ポジションを獲得

## カリキュラム

- 合計 32 単位で、唯一の必修 core 科目は INFO 5100（4 単位、0 単位の INFO 5101 Lab 付き）です。Coursework オプションでは INFO restricted elective を 16 単位追加で履修します。
- 残りは選択科目です。ソフトウェア方面に進みたいなら Software Development を選びましょう。選べるトラックは次のとおりです。
  - Cyber and Information Security
  - Product Management & DevOps Leadership
  - Software Testing and Quality Assurance
  - UX Design / Software Development / Data Analytics など
- NEU の授業の多くは成績評価が比較的甘く、授業を受けながら LeetCode や就職活動に取り組むのにとても向いています。たとえば Mobile Application 5520 や Computer Networks 5700 は楽な科目として広く知られています。
