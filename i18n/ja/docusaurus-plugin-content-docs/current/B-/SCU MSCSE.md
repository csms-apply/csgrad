# SCU MSCSE

## プログラム概要
Santa Clara University の Master of Science in Computer Science and Engineering は、California 州 Santa Clara、まさにシリコンバレーの中心にあります。クォーター制（年3学期、各10週間）で、修了には46単位が必要なため、おおむね2年のプログラムです。学費は総額約 $60K と比較的手頃です（2026-27年度：$1,304/unit × 46 units、AGES などの諸費用は除く）。NEU や NYU より安いものの、その分ブランドの知名度も下がります。Bay Area の外では SCU を知っている人はほとんどいません。

キャンパス自体はかなり良いです。建物は美しく、図書館の自習スペースも十分で、ジム、プール、テニスコート、バスケットコートがあり、SF/SJ のダウンタウンよりずっと安全で、ホームレスはほぼいません。ただ食事事情は厳しく、学内の食堂は1食約 $14 で味もいまひとつ、近くにまともなレストランも少なく、車がないとさらに悲惨です。車がないのは足がないのと同じ、と3回強調しておきます。

プログラムは在籍延長が可能です。1年目にインターンが見つからなければ延長を申請できます。Master Thesis トラックを選んだ学生は、授業を終えた後も各学期に thesis を1単位登録するだけで学生ステータスを維持しながら、フルタイムでインターンができます。なかなか良い抜け道です。

## 専攻転換者へのやさしさ
正直なところ、専攻転換者にはあまりやさしくありません。修了に必要な46単位に含まれない前提科目3つ（Assembly、Logic Design、Data Structures）を追加で履修する必要があり、費用も時間もかかるうえ、単位を落とすリスクも実際にあります。専攻転換の学生の中には、Assembly を一生懸命勉強しても C 未満だった人もいます。この3科目が免除できない場合は、学校ではなく community college で履修することをおすすめします。学校のその科目の先生は教え方の質に不安があります。

CPT の制度にも落とし穴があります。クォーター制のため夏休みの開始が遅く、CPT が使えるのは6月16日からです。企業から5月下旬や6月上旬の入社を求められると、オファーが取り消される可能性があります。実際に小紅書（RED）には、これが原因でオファーを取り消された学生の投稿があります。また、留学生は Summer＋Fall の co-op を連続して行うことができず、NEU の co-op 制度とは大きな差があります。

## 授業と履修登録
MSCSE の多くの科目は負荷が重く、成績評価はくじ引きのようです。どれだけ頑張っても C をつける教授もいれば、簡単に A をくれる教授もいます。誰に当たるか次第です。3で始まる科目は例外なく重く、必修のコア科目3つ（279/210/283）も軽くはありません。新入生は在校生の後に履修登録をするため、順番が回ってくる頃には良い教授のクラスはすべて埋まっています。

絶対に避けるべき教授（特に就職活動中は）：Algorithms の N. Tran は試験が難しく採点も厳しく、CS 専攻の学生が一生懸命勉強しても B-、専攻転換の学生はほぼ C でした。Computer Architecture の K. Pahlavan はスタディガイドもカーブもなく、期末試験にスライドや課題にない内容が出ます。Distributed Systems の R. Bruce は初回の授業で「人生とはそういうものだから厳しく採点する」と宣言し、学期末には3-4人しか残りませんでした。Advanced Database の S. Jahangiri はコードを1行ずつ説明するよう求め、はっきり説明できないと F をつけて学校に報告します。

おすすめの教授：Y. Wang（Algorithms/Graphics）は板書がわかりやすく、課題や試験はほぼ LeetCode の問題なので、可能ならこの先生を選びましょう。A. Zaky（Algorithms）は採点が甘く加点のチャンスもあるため、基礎に不安がある人に向いています。Y. Cui（Computer Architecture）は試験前にスタディガイドをくれ、採点も甘く、中国語での質問にも応じてくれます。

最初のクォーターのアドバイス：難しい科目は取らず、GPA が安定しないうちは免除されていない前提科目に挑戦しないこと。楽な科目を取って GPA を3.0以上に保ちましょう（CPT の要件です）。

## 合格ラインとデータポイント
1期あたり約200-300人で、およそ半分が中国人、半分がインド人です。22Fall の期は、ほとんどが CS 専攻か近い理系分野からの部分的な専攻転換者でした。経営学から CS に転向した人は1桁でした。前提科目の要件があるため、純粋な文系からの転向者はいません。25Fall 以降は出願者が減り、合格しやすくなっています。

## 就職実績
はっきり言うと、就職活動は完全に自力です。学校のブランドは就職にほぼ何の意味もないので、「シリコンバレーの夢の学校」というミームにだまされないでください。Career Fair の参加企業はほとんどがグリーンカード保持者か市民を求めています。Handshake は NEU の NUworks とは比べものになりません。周りの就活の雰囲気もかなり受け身で、NEU のような皆で頑張る熱気には遠く及びません。

22Fall の期では、ステータスを持たない中国人留学生のうちインターンを見つけたのは10人未満でした（中国人学生は全体で100人以上）。市況の影響もありますが、SCU が就職活動で特別な優位性を与えてくれないのは明らかです。インターンを見つけた人はとても早くから応募を始め、綿密に計画していた人たちで、Amazon や GHC 経由で決まっており、学校とは関係ありませんでした。

とはいえ、ある卒業生は LinkedIn で Google の人事から直接連絡を受けて正社員の面接に進みました。SCU のブランドは Bay Area の中小企業の書類選考には十分通用し、大手テック企業でも頭ごなしに落とされることはないということです。

- インドの CE 学部出身、修士在学中に Juniper Networks で SWE インターン、その後同社で正社員の SDE 2、さらに Microsoft と Google で正社員の SWE。

## 総合的なアドバイス
NEU IS や CSA のように授業負担が軽く、co-op 制度がしっかりしていて就活文化が強いプログラムのオファーを持っているなら、NEU に行きましょう。SCU に来てはいけません。SCU が向いているのは2種類の人です。LeetCode と応募に全力を注ぎ、OPT を得る手段だけが必要な人（ひどい授業さえ避ければ大丈夫です）、そして PhD を目指す人です。少人数クラスなので教授と関係を築きやすく、Master Thesis に取り組んで論文を出せます。毎年、ここから全額奨学金付きの PhD に進む人もいます。

もしここに来ることになっても後悔しないでください。学校がだましているわけではありません。どちらかといえば情報の非対称性と期待値の調整の問題です。大切なのは、早くから LeetCode と応募を始めることです。授業が始まるのを待たないでください。
