# UIUC MSIM

## プログラム概要
授業の負担は軽めです。MSIM の学費は約 $50K です。就職活動に向いており、co-op 制度もあります。

## 合格の傾向と代表的な Data Points
CS へ専攻を転向する人を受け入れています。
1. GIS 学部、GPA 3.5、TOEFL 105 — 合格
2. 985 CS 学部、GPA 3.6、TOEFL 109、研究経験 2 回 — 合格

## 就職実績と Data Points
全体としては平凡です。

1. インド人学生、無名大学の CS 学部、正社員経験 2 年 — Amazon に就職
2. NTNU 学部、インターンなし — 小規模企業の new grad に就職

3. インドの CE 学部、修士課程中に COUNTRY Financial で DS と Technical PM のインターン、2025 年修了後、同社で Product Owner 2 の正社員。
