# CMU MSCS

## プログラム概要
SCS の看板プログラムです。授業選択が極めて柔軟で、取りたい CS の授業は事実上何でも取れます。SCS 全体のあらゆる CS 関連の授業を履修でき、MSCS の学生には履修登録の優先権があります。合格後に 15-213 CSAPP を履修する必要がありますが、後回しにして米国に着いてから取っても構いません。同級生はほとんどが中国人かインド人です。入学延期（deferral）が可能です（23 Fall のオファーレターに deferral 可能と明記されています）。通常は3学期で約8科目（認定 units 96–108）を修了し、AI / Theory / System の各トラックから少なくとも1科目ずつ含める必要があります。授業はかなり面白いです -- たとえば Deep Learning Systems では GPU プログラミングを扱い、PyTorch の簡易版を作るプロジェクトがあります。少なくとも私が通った中国本土の学部では、こうした授業はそもそも開講できませんでした。この授業の採点システムは外部の学生にも公開されています。CMU 15-445（Database）のようなほかの有名な授業もあります。早く着けば、GitHub で 3k+ star を持つ開発者の TA に会えるかもしれません。15-445 も採点システムが外部の学生に公開されていて、プロジェクトが毎年少しずつ変わるので、挑戦してみる価値があります。

## 合格傾向
GPA に極めて厳しく、米国の学部生を明らかに好みます。中国本土の出願者は事実上ターゲット校（Tsinghua、Peking + C5）しか考慮されません。この範囲外なら、出願料を無駄にしないでください。GPA、GRE、TOEFL の3つの指標すべてが優れている必要があります。以前（24 Fall）は合格率がわずか5%でした。今年（2025）は PhD の財源確保のために定員を拡大する必要があり、合格率は10%に上がりましたが、それでも非常に難しいです。

2023年は出願者2,073人のうち107人が合格し、67人が入学しました。

## New Grad の就職実績
圧倒的です。各種クオンツ企業（Citadel、Point72、Jane Street、Jump Trading）に進みます。それ以外の人も、少なくともビッグテックには合格します（ただし CMU MSCS という肩書きのおかげというより、学生自身の経歴が GitHub 3k+ stars / Point72 QR インターン / Microsoft で3年間正社員といった具合に非常に優れているからです）。
