# Caltech MSEE

## プログラム概要
LA の気候は申し分なく、学校の知名度も申し分なく、合格者数は Stanford よりはるかに少ないです。CS への転向組にとても優しく、修了に必要な135単位のうち EE の授業は54単位だけで済みます。有名な 156 Learning Systems をはじめ、多くの CS 科目が CS-EE として共同開講されているため、理論上は CS 科目だけを取って修了することも可能です。

プログラムの期間は9か月ですが、半年延長できます。
## 合格傾向

毎年の合格者は15人です。約3分の1が中国本土の学部出身者で、基本的に清華大学、北京大学、華東五校の出身です。残りは海外の学部出身者です。


## 合格データポイント

1. SYSU Physics 学部（中退）、UCI CS+EE 学部、GPA 3.98、Stanford の客員研究員
2. Purdue EE 学部、8学期連続で Dean's List、RA 1年9か月
3. NCSU EE 学部、GPA 4.0
4. NTU（台湾）EE+Finance 学部、GPA 4.18、Academia Sinica で RA 2年
5. NTU（台湾）EE 学部、GPA 4.29/4.3

6. UCSD EE 学部、2026年秋に Caltech MSEE 入学予定、入学前は Texas Instruments で正社員の Process Engineer として勤務（2025年12月〜2026年6月）

## 新卒の就職実績

SDE 職に進む人は少ないですが、進んだ人は基本的に全員ビッグテックに入っています。
