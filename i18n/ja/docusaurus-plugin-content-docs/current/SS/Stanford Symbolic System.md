# Stanford Symbolic System

## プログラム概要
研究ベースのプログラムで、位置づけとしてはMIT CSEが参考になります。Symbolic Systemsは学際的なプログラムで、学科は学生が次の分野のうち少なくとも2つに精通していることを期待しています。
コンピュータサイエンス、言語学、哲学、心理学、神経科学、数学、統計学、コミュニケーション、教育

thesisを完成させる必要があり、研究経験も求められます。推薦状は研究関係者からのものが望ましいです。

このプログラムは多様性をとても重視しており、志願者には「人文・社会科学（Humanities and Social Sciences）」への貢献を示すことが求められます。

## 合格ラインとデータポイント
外部からの合格率は5%です。

1. Stanford Symbolic System学部、GPA 3.9、Microsoftでのインターン3回
2. Rice Physics+English+DS学部、GPA 3.93、論文1本
3. Duke Kunshan DS学部、GPA 3.91、2年半のRA経験、第2著者論文2本
4. インド出身の学生、GPA 9.25、出願時点でCV系カンファレンス論文3本が採択済み
5. Vassar College Cognitive Science学部、出願時点でICCV論文1本が採択済み
