# Stanford STATS DS

## プログラム概要
Stanford DS には最高の教授陣、美しいキャンパス、印象的な同期がいます（ウォール街に疲れて学校に戻ってきた 4 年以上の経験者も多いです）。研究の質が高く、学際的な研究も多くできます。

## 合格ラインと Data Points
1 期あたり約 50 人が合格します。
ほぼ全員がアメリカの学部出身で、名門校でトップクラスの GPA（3.9+）、GRE 330+ といったプロフィールです。
1. NYU DS+Math 学部、TA＋RA 経験複数回、GPA 3.95
2. UCLA Math+Statistics 学部、GPA 3.98、DS インターン複数回
3. Georgetown University Operations Research 学部、Math 副専攻、小規模企業での DS インターン
4. Cambridge Economics 学部、First Class Honours、QD 経験 6 か月、DS インターン
5. UESTC Statistics 学部、GPA 3.95+、Harvard で研究インターン 4 か月
6. Duke Statistics 学部、GPA 3.97、MLE インターン複数回
7. UCB DS 学部、GPA 4.0、DS/MLE インターン複数回
8. UCLA DS 学部、GPA 4.0、RA 経験 2 年半
## 就職実績
大多数が MLE と DS の職種に就きます。quant に進む人は非常に少なく、その多くは ICME 側です。Jane Street や Citadel に行くケースはごくまれです。それ以外では 80% 以上が大手テック企業（FAANG）に就職し、主に DS 職で、一部は SWE に進みます。

大手テック企業よりスタートアップを好む学生もおり（Stanford は特に起業を奨励しています）、自分で会社を立ち上げたり、初期のスタートアップに加わったりします。

1. UCLA Statistics 学部、2024 年に修士修了、Apple と小規模企業での DS インターン、2024 年 QuantCo DS 正社員。

## 学内での PhD への移行

Statistics 学科には PhD に直接移行するルートがありません。PhD に移るのは本当に本当に難しいです。
