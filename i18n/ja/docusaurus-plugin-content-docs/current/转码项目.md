# CS転向プログラム

CS転向プログラムは、完全な未経験者向けのプログラム（CSの前提科目をまったく履修していない場合）と、一部未経験者向けのプログラム（CSの前提科目を一部履修している場合）に分かれます。経済・ビジネス・生物学などの学科出身で、データ構造、コンピュータ構成論、オペレーティングシステムといった前提科目を履修していない場合は、
[分野転向者が補うべき専門科目](useful_docs/转码需要补的专业课)を参考に履修計画を立ててください。

## 完全未経験からのCS転向


1. NEU CS Align
2. UPenn MCIT（名門大学出身でGPAの高い志願者を好み、GPA 3.9+なら比較的安全）
3. [UChicago MPCS](A-/uchicago%20mpcs.md)
4. USC CS37
5. NEU ISB
6. [UIUC MSIM](B-/UIUC%20MSIM.md)
7. Columbia CS Bridge
8. NYU Tandon MSCS Bridge
9. [JHU MSECS](A-/jhu%20msecs.md)
10. CMU MITS
