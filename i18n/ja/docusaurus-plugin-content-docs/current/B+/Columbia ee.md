# Columbia MSEE

## プログラム概要

自炊＋外食（70% / 30%）で、1年半の総費用は約80万人民元です（特に節約した生活ではありません）。小紅書（RED）で見かける「ニューヨークでは年間100万人民元かかる」という話はまったくのでたらめで、実際の調査に基づいたものではありません。ニューヨークで年間100万人民元使える人は、UCSD でも同じだけ使えます。ニューヨークは文化や娯楽が豊富な素晴らしい街です。

## 授業選択
CS の科目を多く履修できるため、CS へのキャリアチェンジに向いています。

3学期で計10科目、うち EE 科目が5科目以上、6000番台以上の科目が5科目以上必要です。理論上、残りはすべて CS 科目で埋められます。CE よりソフト寄りの構成にできます。CE にはハードな必修科目がありますが、EE なら純粋に CS 科目だけを取ることもできます。

1. COMS4111 Intro to Databases. Donald 先生の授業で、リレーショナルデータベースの SQL からインデックスまで扱い、非リレーショナルデータベースとして MongoDB と Neo4j も扱います。課題は約5つで、すべて Jupyter notebook でコーディングし、Python の SQLAlchemy を練習したり、MongoDB や Neo4j の API に接続して NoSQL の演習を行ったりします。中間・期末試験は持ち帰り形式で、A を取るのはとても簡単です。

2. COMS6156 Topic in Software Development: Cloud Computing
これも Donald 先生の授業で、ソフトウェア開発プロセス、AWS の各コンポーネント、マイクロサービスの概念を扱います。講義はすべて概念中心で、宿題も試験もなく、5〜7人の大きなグループプロジェクトが1つあるだけです。プロジェクトではマイクロサービス構成の Web アプリを作り、すべて AWS にデプロイします。主な要件は RDS、Lambda、EC2、Elastic Beanstalk、Cloud API、S3、CloudFront などです。真剣に取り組めば、特に AWS とサーバーレスの潮流について多くを学べます。基本要件を満たせば A がもらえます。

3. EECS6893 Big Data Analytics
Ching-Yung Lin 先生の授業で、彼は AI 企業の CEO でもあります。CEO の講義なので概念が多く細部は少ないため、自分で学ぶ必要があります。この授業は範囲が広く、Hadoop、Spark、Machine Learning、Air Flow、d3.js をすべて扱い、各トピックにプログラミング課題があります。非常に時間がかかり、最終プロジェクトにもかなりの労力が必要です。クラスの約半数が A を取ります。

4. ELEN6770 Cloud Computing & Network Virtualization
2人の講師が前半と後半を分担して教え、どちらも Bell Labs 出身です。比較的楽です。課題2つと中間・期末試験があります。成績はおおよそ半分が A（A-）、半分が B（B+）です。

5. CSOR4231 Analysis of Algorithms.
Eleni 先生は素晴らしく、授業の質も高く、講義中に計算を手書きで示してくれます。この授業はアルゴリズムの正当性の証明と計算量解析が中心で、数学の比重が大きく、プログラミングはありません。課題＋中間・期末試験があります。
6. COMS4705 Natural Language Processing
Daniel 先生の授業で、内容は比較的基礎的、スライドが詳しく体系的にまとまっています。課題＋中間・期末試験があります。
7. ELEN6889 Large-Scale Stream Processing
インド系の先生が教えていますが、インド訛りはわずかで、評判は良いです。講義がとても上手で、Spark や Apache Beam などのストリーム処理の応用を扱います。
8. ELEN6883 Intro to Blockchain
Chong Li 先生が担当し、秋学期には6885も開講しています。どちらも楽に A が取れる科目です。Bitcoin、NFT など、ブロックチェーンに関する幅広いテーマを扱います。


## 合格ライン
合格ラインは優しめです。985大学出身で GPA 3.4 で合格したデータポイントもありますが、だからといってこのプログラムが悪いわけではありません。Columbia の肩書きがあれば、どの企業でも面接までは進めます。Peking University CS 出身者もここに来ています。先輩は中国に帰国しても米国で就職活動をしても、Columbia だからといって「楽なプログラム」と言われたことは一度もなく、みんなすごいと思ってくれたそうです。合格ラインを気にするのは出願シーズン中の出願者だけで、それ以外は誰も気にしません。（世界は広く、実力のある人は活躍できます。学歴より実力が大事です。）

1. HKUST EE、First Class Honours
2. Shanghai University EE 学部、GPA 86
3. UESTC EE 学部、GPA 89
4. Xidian University CS 学部、GPA 3.84、その後 Columbia EE 内で PhD への移行に成功
5. Utah EE + Math 学部、GPA 3.95
## 就職実績
Meta インターンと Amazon インターンの実績があります。書類選考の通過は簡単で、その先は完全に本人次第です。Bloomberg も Columbia から採用しています。Columbia は Bloomberg の社内システムで ROI の高い学校と評価されており、わざわざ採用と面接に来ます（2022年には大量に採用しました）。

1. SUSTech EE 学部、テキサスでハードウェアの新卒ポジションを獲得
2. Shanghai University EE 学部、中国の中小企業でインターン経験、米国の中小企業でプロダクトマネージャーのポジションを獲得

3. HUST 電子情報工学 学部、2025年卒業、2026年7月に XPENG に正社員の Machine Learning Engineer として入社
