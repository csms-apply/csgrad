# Rice MCS

## プログラム概要
MCS プログラムはここ数年で規模が大きくなりました。COVID 期間中、21 Fall の入学者は300人まで急増し、22 Fall には100人未満に戻りました。修了要件は30単位＋concentration 科目2つ＋必修インターンです（具体的な要件は毎年変わる可能性があります）。学費は1学期 $33,392 と中程度です（2026-27年度）。最終学期はパートタイムにして単位ごとの課金にできます。費用を抑えるなら、4+4+1 方式で3学期で修了でき（パートタイムは1単位 $3,710、総額約 $78,000）、3+3+3+1 で4学期かけることもできます。2学期で駆け抜けることも可能ですが、実際にそうする人はいません。Rice では 601 のような無料の英語授業や、OISS が提供する無料の英語授業も受けられます。

大学院生は自分専用の座席とロッカーを予約できます（そう、1年間ずっと自分専用です）。図書館の1階には利用できるパソコンもあり、席に困ることはありません。大学院1年生には RGA、RVA、RVT などの住居が用意されており、ほとんどの人が入居できます。キャンパスと住居の間には無料のシャトルが走っています。Houston は現在全米第5の都市で、グルメや娯楽が豊富で、NBA の Rockets の試合もあります。中華料理が豊富で安く、中国系の住民も多いです。また数ブロックにわたる大きな Chinatown があります。ほとんどが四川料理で、日本料理、韓国料理、ベトナム料理もたくさんあります。中華料理の配達も毎日利用できます（1食約 $11-12）。

Rice MCS は USC CS28、UCI MCS/MSWE、Duke MECE、NYU Tandon MSCS、NEU MSCS-General とよく比較され、いずれも就職には比較的有利です。Paycom は Texas の学生（Rice を含む）をかなり多く採用しています。滑り止め（safety-net）企業と呼ぶ人もいますが、実際に多くの学生を採用しています。

## 合格ラインとデータポイント
ほとんどが中国本土の985/211大学の学部出身（GPA 約88）、米国の学部出身者は GPA 3.6以上です。

## 就職実績
25 Summer では、統計上、周りの学生の約40%がインターンを見つけました。Paycom は Texas の学生だけを採用する滑り止め企業です（昨年は Rice MCS の学生を15人採用）。しっかり準備すれば合格の可能性は高く、面接はすべて過去問からの出題です（アルゴリズム問題は全員が過去問そのままでした）。Paycom は 25 Summer に10人以上を採用しました。2022 Fall には、台湾出身の学生の約90%がインターンを見つけました。

25 Summer には4人が Meta に、約10人が Amazon に決まりました。
