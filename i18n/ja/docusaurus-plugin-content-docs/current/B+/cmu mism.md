# CMU MISM
## プログラム概要
中国国内の大手企業でのインターン経験や正社員としての SDE 経験がすでにあり、CMU の肩書きを得て、米国に着いた初日から LeetCode を解き、インターンに応募し、履歴書をばらまくことを目標にしている学生にしか向いていません。

**Heinz で高度な SCS の授業を受けながら CMU で学びたい人には向いていません** -- MISM の core はほぼすべてビジネスの授業で、学期ごとに取れる SCS の授業数にも制限があります。学科長もこれを勧めていません（Heinz は cross-registration について SCS スクールに費用を支払わなければならないためです）。SCS の授業を取ろうとすると、あらゆる問題にぶつかります。

MISM には12か月トラックと16か月トラックがあり、後者のほうがインターンを見つけやすいです。学期ごとに54 credits が必要なので、作業量は少なくありません（楽な授業に多くのエネルギーを取られはしますが）。楽な授業とハードな授業の割合は自分で調整する必要があります。修了するには、連続する3学期の間、毎学期ちょうど54 credits の大学院レベルの授業を履修しなければなりません。多く取ることは認められず、少なければ学費の返金も修了もありません。

BIDA または general トラックを選びつつ、良い SCS/INI の授業をたくさん取りたいなら、経済学、会計、統計の授業を免除してもらい、SCS と INI の授業に回す単位を確保できることが重要な前提条件です -- そうでなければ来ないでください。

まとめると、もう一度言いますが、**CMU の肩書きが欲しく、米国に着いた初日から LeetCode を解き、インターンに応募し、履歴書をばらまくつもりの学生**にしか向いていません。

## MISM Core
この core は別途紹介する価値があります -- 高度な CS の授業は多くなく、ビジネスの授業が多いことがわかります。このプログラムを検討しているなら覚悟してください。SCS の授業を取りたい学生、特に学部で免除の対象となる同等のビジネスの授業を受けていない学生には合いません。赤で示されている授業が CS の授業で、Java OOP（学部1学期目の授業）のようなものも含まれています。ビジネスの授業の数は CS の授業よりはるかに多いです。

## 就職実績
