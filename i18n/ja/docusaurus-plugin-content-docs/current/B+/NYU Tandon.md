# NYU Tandon MSCS

## プログラム概要
NYU COURANT の MSCS と区別することが重要です -- COURANT の MSCS は非常にアカデミック志向が強く、Tandon の MSCS は非常に就職志向が強いです。Tandon には建物が数棟しかなく、CMU の SV キャンパスに少し似ています。NYU Tandon は Brooklyn にあります。2年のプログラムで費用も安くなく、約110万人民元を予算として見込んでおく必要があります。1年6か月で早期修了することも、修了を遅らせることもできます。

最終学期に co-op があるのが良い点です。

## 合格ライン & DataPoints
中国人出願者の選考を担当するディレクターが中国人で、中国の大学ランキング（985/211）を非常に重視しているため、中国のトップ大学出身の学生を優先して合格させています。

GPA 3.3 の Fudan の学生の多くが、最終的に NYU Tandon に来ています。

## 就職実績 & DataPoints
良くはなく、かなり平凡です。

1. 海外の学部、Amazon でインターン、JP Morgan の new grad に合格
2. インドの学部、4か月のインターン2回、Tesla に合格

3. インドのデータサイエンス学部、修士入学前に SAP でインターン、2026年の修了後に Blue Yonder で Software Engineer の正社員。
