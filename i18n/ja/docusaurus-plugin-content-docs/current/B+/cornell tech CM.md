# Cornell Tech CM

現実をお伝えするために書きます -- このプログラムは、ネットで語られているよりも実際にはずっとイマイチです。

まさに世界の中心です。学校が島にあるので外に出るのはそれほど便利ではありませんが、キャンパス近くの地下鉄に乗れば、30分以内にニューヨークの主要な観光地や娯楽施設のどこへでも行けます。米国の CS 関連プログラムの中で総費用が最も高い部類かもしれません -- 奨学金なしだと2年間の総費用は $220K+ と見込まれます。学校の規模が小さいので、大規模州立大学に比べて研究の競争はずっと緩やかですが、PhD 進学の状況ははっきりしません。ほとんどの学生が寮に住んでいるので、キャンパスライフは悪くありません -- ボードゲームや人狼ゲーム（マフィア）で集まりやすいです。就職実績は平凡で、事実上どの大手テック企業のターゲット校でもありません。学生は全体的に普通の人たちですが、面白い経歴を持っています。

B+ 評価の理由：
1. 高いです（$220K+）。奨学金をもらっても大した額にはなりません。50% の奨学金を受けた唯一の例は米国グリーンカード保持者で、中国籍の学生がその水準の支援を受けるのは基本的に難しいです。
2. 就職実績が芳しくありません。24 Fall に入学した複数の学生が、就職市場がとても厳しかったと話しています。
3. Cornell というブランドだけで面接の機会を増やすのは難しいです。

## 住まい
部屋のタイプにこだわらなければ、ほとんどの学生は寮に入れるはずです。優先順位はおおむね 2年生 > MBA > 1年生 です。見たところ、一人暮らしをしたい新入生は 1B1B と標準間取りの Studio を優先して希望するとよいでしょう。1B1B が取れなかった場合、Studio を提示される可能性が高いからです。1B1B が取れれば、理論上はほかの人と内部で部屋を交換することもできます。標準 Studio は23の居住フロアに各フロア約6部屋あるので、たいてい空きがあります。変わった間取りの Studio も2種類（各フロアに1部屋ずつ）ありますが、取るのが難しく完全に運次第なので、個人的には狙う価値はないと思います。住居の希望は優先順に5つまで書けます。寮にまったく入れない可能性もあるので、保険として 3B2B/3B1B を入れておくことをおすすめします。CT の寮では共用スペース（common area）に住むことは認められていません。月額費用は 1B1B が約 $3K、Studio が約 $2.3K、2B が約 $2K、3B が約 $1.8K で、マンハッタン近くとしては非常にコスパが良いです。ただし 3B は寝室が本当に狭いので、個人的にはおすすめしません。コスパと快適さでの個人的なランキングは、1B1B（マンハッタン近くで $3K ならコスパは良いです。とはいえ月 $3K はやはり高いですが）> 標準 Studio > その他の Studio > 2B1B > 2B2B > 3B です。建物には共用の洗濯機と乾燥機があり（靴の乾燥機は見かけませんでした）、無料のジムもあります。月 $30 で50メートル先のスポーツセンターに入会でき、プールがあって設備も素晴らしいそうです。学校の寮に住んでいない友人は、島の反対側にある Octagon に住んでいることもあります。島内には無料バスがありますが、授業まで歩くと20分かかってあまり便利ではないので、キックボードの購入を検討してみてください。個人的には、寮に入れなかった場合を除いて、ほかの場所に住む必要はないと思います。みんな寮に住んでいて、交流イベントもすべてそこで行われるからです。

## 履修登録
1学期目に開講される授業はほとんどが ML Engineering 寄りで、SDE 向けの授業はごくわずかです。そのため CM は CS へのキャリアチェンジにはあまり向いておらず、すでに CS のバックグラウンドがある学生に向いています。
1. Applied ML：中間試験あり、期末試験なし、Project と Final Project あり。難易度 2/5 -- Andrew Ng の ML 講座を受けたことがあれば楽に乗り切れます。作業量 2/5、課題もプロジェクトも負担は大きくありません。ほぼ全員が取る授業なので、必修と考えてよいでしょう。A を取るのはとても簡単です。

2. MLE：中間試験あり、期末試験なし、Project あり。難易度 4/5 -- 小さな PyTorch をゼロから自作する内容で、履歴書に書ける価値のあるプロジェクトだそうです。後半になると内容が深くなりすぎて、MLE 志望でない学生には本当につらいです。中間試験はカーブ（相対評価）がありますが、個人的にはかなり難しく感じました。作業量 2/5～5/5 -- Project は手を抜いて簡単にこなせますが、真剣に学ぼうとすると時間がかかります。受講者は多いですが、難易度を踏まえて慎重に検討してください。

3. Applied Algo：中間試験なし、期末試験なし、Assignment 5つのみ。難易度 2/5～4/5 -- 試験がないので、この授業にどう向き合うかは完全に自分次第です。後半の課題の一部は、真面目に取り組むと本当に手ごわいです。作業量 2/5～4/5、どのように授業を乗り切りたいかで完全に変わります。手を抜くなら今学期で一番楽な授業で、真剣に勉強するなら個人的には MLE より少し簡単だと思います。ただし扱うアルゴリズムは LeetCode とはほとんど関係がなく、あまり実用的とは思えないマイナーなアルゴリズムが多いです。それでも A を取るのは難しくないので、多くの人が受講しています。

4. HCI：中間試験なし、期末試験なし、毎回の授業で宿題、継続的な Project あり。UI/UX の授業なので、予備知識ゼロでも大丈夫です。フロントエンドや UI の経験が少しでもあれば、まったく難しくありません。授業時間はすべてチームワークの課題で、教授は講義をせず、講義は録画を事前に見てくる形式です（見なくても授業参加にはあまり影響しません）。難易度 2/5 -- 教授がとても寛大で、UI/UX の経験がまったくない人でも、宿題をやりさえすればほぼ満点がもらえます。UI/UX とフロントエンドの経験がある立場から見ると、教授がカリキュラムと課題にかなり力を入れていることがわかりました。学ぼうと思えば学べます（SDE 向けではなく、PM や UI/UX 向けです）。作業量 2.5/5 -- 毎週2時間のチーム課題があり、2人組の Project は通常4～6時間かかり、学期あたり Project は約5つです。普通に出席して授業の課題をこなしていれば A が取れます。

5. Psychology は CM の必修科目です。かなりハードだそうです -- 毎回出席確認と小テストがあり、ほかの人の話では採点も厳しいとのことです。CM の学生でなければ、わざわざ取る必要はありません。

6. Business Foundation は1単位です。MBA の授業を取りたい MBA 以外の学生は、この授業を修了する必要があります。非常に厳しいらしく、この授業を取った友人は全員途中で履修を取り消しました。学部でビジネス系の教養科目を履修していれば、この授業は免除され、直接 MBA の授業を取れます。

## 合格ライン
バックグラウンドは非常に多様です。新卒の場合、私が調べた限りでは、ほぼ全員が 211/985 大学、米国の学部、またはジョイントプログラムの出身で、985/211 以外の大学の CS 専攻者は基本的にいません。CS 専攻者が多数派で、その次が DS です。GPA の要求水準は予想より高く、私の知っているほとんどの人が 3.7+ です。起業経験があると基準が下がるようです。全学生の約1/6は数年間働いてから出願した人だと推定され、社会人が CM に出願する場合は基準が低めのようで、ビジネス/DS のバックグラウンドの人もいます。

2. Princeton University、Cum laude で卒業
3. UW HCI 学部、GPA 3.9
4. National Cheng Kung University CS、GPA 3.99
5. Syracuse University DA 学部、GPA 3.95
6. Queen's University Math 学部、GPA 4.0
7. 米国の学部 top 100、Math 学部、GPA 4.0
8. NTU CS + Business 学部、GPA 3.97
9. Lehigh University、GPA 3.8
10. NYU Shanghai CS 学部、GPA 3.8

## 就職活動
CM の学生は66人です。HT と UT はそれぞれ20人未満で、ほかのプログラムは調べていません。印象としては中国人が約30%、インド人が約30%、その他が40%と、かなり多様で、「中国人留学生ばかり」という感じではありません。

就職活動の情報は 25 Summer Intern を探した中国本土の学生に限られ、25 NG やほかの地域についてはわかりません。2025年3月16日時点で、25 Summer のインターンを獲得した中国人学生は多くても10人程度と推定され、中国人学生の約30～40%にあたります。サンプルが少なすぎるので、主に個人の実力次第です。とはいえ、公式の就職率90%とは桁違いの差があります。CT ではニューヨークでのキャリアフェアが事実上ありません -- Cornell の本キャンパスがある Ithaca のキャリアフェアに行くこともできますが、そこにも大手企業はほとんど来ません。要するに、キャリアフェアは事実上飾りです。ニューヨークという立地も、就職活動では何の利点にもなっていません -- 今はみんなオンラインで面接するからです。

CT は Cornell の学位を授与するので、おおむね Cornell と見なせます。しかし Cornell は大手テック企業のターゲット校ではないようです -- 私の知り合いの中で、Meta、Google、Apple、Uber などの有名ビッグテックに就職した人はごくわずかです。大口スポンサーである Bloomberg は面接の機会をくれますし、学校担当の HR も比較的積極的です。2～3か月音沙汰がなくなる一部の DataPoints と比べると、CT の次のステップはたいてい7～30日以内に進みます。10月には学校から履歴書を一括で集めて対面面接に来ましたが、現時点で 25 Summer のインターンのオファーをもらった中国人学生はいません。Paycom が Rice から採用している度合いと比べると、はるかに及びません。

まだ Summer のインターンを探している人は、おそらく今年の Amazon の大量採用に期待しているのでしょうが、それは CT とは関係ありません（笑）。まとめると、学校は就職活動にほぼ何の助けにもならず、Cornell という肩書きは、就職市場では一部の工学系に強い学校ほどの価値がないかもしれません。

1. SCU から米国の学部に編入、小規模企業で4か月インターン、Meta の new grad に合格

2. NTU 経営学部卒、CM 入学前に ShopBack で2年間正社員として勤務、在学中に TikTok で SWE インターン、2025年卒業後に Amazon SDE II の正社員。
