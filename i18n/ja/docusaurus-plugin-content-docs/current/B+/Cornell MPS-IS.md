# Cornell MPS-IS

## プログラム概要
CS への専攻転向に活用でき、CS 学科の授業も取れます。履修登録の優先度は CS の学生ほど高くはありませんが、他の学部（school）の学生よりは高いです。permission number を使って授業に入ることができます。入学を延期すればインターン用の CPT を得られます。IS school には楽な授業がかなり多いので、1 学期目に楽な授業をいくつか取り、その後は就職活動に全力を注ぐのに向いています。

アメリカの学部出身であれば、1 学期延期して春学期に入学し、CPT を得ることができます。詳しくは [Spring 入学で CPT を得る方法](../useful_docs/Spring%20入学如何拿CPT.md)を参照してください。CPT 承認の具体的な詳細は、必ず学校に改めて確認してください。

## 合格ラインと Data Points
学部の専攻はかなり多様で、経営、デザイン、データ、CS などさまざまな背景の学生がいます。

1. Fudan University 学部、Physics、GPA 3.5
2. NYU 学部、GPA 3.84、CS GPA 3.97、Amazon Ireland で SDE として 9 か月勤務
3. Renmin University CS 学部、GPA 3.6、TOEFL 102、Meituan での DS インターン経験
4. SCU Math 学部、GPA 3.85、Huawei で SDE 正社員 2 年
## 就職実績
あまり楽観的ではありません。主な理由は、CS へ専攻を転向しようとする学生が多く合格しているからです。一部の CS の授業は課題量が多く、LeetCode の問題演習に十分な時間を確保しにくいです。

- Fudan physics 学部、在学中に Middleby の Data Scientist Intern、2024 年修了後 Amazon SDE 正社員。
