# NEU IS

## 프로그램 개요
co-op 기회를 제공하는 CS 전공 전환 프로그램입니다. MSCS와 비슷하고, I-20에는 CS 관련 직함인 SE(Software Engineering)가 표기됩니다.

캠퍼스가 여러 곳입니다.
전통적인 미국 대학 캠퍼스 생활을 경험하고 싶고, 젊어서 취업을 서두르지 않으며, 종합 프로필이 강하다면 Boston 캠퍼스로 가세요. 빅테크 취업이 목표이거나 Boston의 겨울을 견디기 힘들다면 Silicon Valley 캠퍼스로 오세요. 2025-2026 입학에는 GRE가 필요 없고, College of Engineering은 Spring 2027과 Fall 2027 입학의 MS 지원비를 면제했습니다.

보통 졸업까지 2년이 걸리지만, 중간에 인턴십이나 co-op을 하면 약 2년 반이 걸릴 수 있습니다.

NEU IS는 본질적으로 전공 전환자 친화적인 프로그램입니다. 커리큘럼은 NEU MSCS와 비슷하지만 합격선은 더 낮습니다. 핵심 장점은 다음과 같습니다.

1. I-20에 CS 관련 직함인 SE(Software Engineering)가 표기되어 SDE 구직에 매우 유리합니다. 직함 불일치 때문에 HR에서 걸러지지 않습니다.
2. co-op을 지원하므로 가을에 풀타임 인턴을 할 수 있고, 여름 인턴만 허용하는 학교보다 오퍼를 받을 기회가 몇 번 더 생깁니다.
3. STEM 프로그램이라 졸업 후 OPT와 STEM OPT 연장을 받아 총 약 3년의 근로 허가를 얻을 수 있습니다.

## 합격선
다른 전공을 한 Ivy League 학생이 CS로 전환하려고 NEU에 오는 경우도 많습니다. 지원할 때 MSCS / CS Align / IS / SES를 동시에 체크할 수 있습니다(현재 지원비가 면제되며, 한 번의 지원으로 최대 3개 프로그램을 커버합니다).

다만 합격선은 높지 않고 꽤 우호적입니다.

## 취업 결과와 데이터 포인트
예전에 2025 Summer SDE 포지션을 찾는 학생들을 멘토링할 때 NEU IS/MSCS/CS Align 학생들의 이력서를 많이 받았습니다. 정말로 빅테크(Google, Oracle, Meta, LinkedIn 등)에서 면접을 많이 받습니다.

1. 인도 학부, HR 인턴 후 DA로 전환, 중소기업 BA 포지션 획득
2. 인도 학부, IBM 2년과 중소기업 2년, Google 획득
3. 인도 학부, HR 인턴, 정규직 AI Engineer 포지션 획득
4. National Chengchi University(대만) IS 석사 GPA 4.3/4.3, 학부는 알 수 없음, IBM 인턴과 Microsoft 캠퍼스 앰배서더, 캘리포니아 중소기업 AI Engineer 인턴 포지션 획득
5. 인도 학부, 정규직 2년, Amazon Data Engineer 신입 포지션 획득

## 커리큘럼

- 총 32학점이며, 유일한 필수 core 과목은 INFO 5100(4학점, 0학점짜리 INFO 5101 Lab 포함)입니다. Coursework 옵션은 INFO restricted elective 16학점을 추가로 이수합니다.
- 나머지는 선택 과목이며, 소프트웨어로 전환하려면 Software Development를 고르세요. 선택 가능한 트랙은 다음과 같습니다.
  - Cyber and Information Security
  - Product Management & DevOps Leadership
  - Software Testing and Quality Assurance
  - UX Design / Software Development / Data Analytics 등
- NEU 수업 대부분은 학점이 후한 편이라 수업을 들으면서 LeetCode를 풀고 구직하기에 매우 적합합니다. 예를 들어 Mobile Application 5520과 Computer Networks 5700은 쉬운 과목으로 널리 알려져 있습니다.
