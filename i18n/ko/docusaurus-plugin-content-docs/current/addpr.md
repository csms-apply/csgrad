# 콘텐츠 기여하기

## CS Grad 프로젝트는 Pull Request를 통한 콘텐츠 기여를 지원합니다
1. 먼저 [CS Grad 프로젝트 저장소](https://github.com/csms-apply/csgrad)로 이동하여 Fork를 클릭합니다

![CS Grad GitHub 저장소의 fork 버튼](/img/en/fork.png)

2. Create fork를 클릭하여 프로젝트를 내 저장소로 fork합니다

![CS Grad용 GitHub create-fork 양식](/img/en/createfork.png)
