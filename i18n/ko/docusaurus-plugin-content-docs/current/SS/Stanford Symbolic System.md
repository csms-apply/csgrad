# Stanford Symbolic System

## 프로그램 개요
연구 기반 프로그램입니다. 포지셔닝은 MIT CSE를 참고하세요. Symbolic Systems는 학제 간 프로그램으로, 학과는 학생이 다음 분야 중 최소 두 개에 대한 지식을 갖추기를 기대합니다.
컴퓨터과학, 언어학, 철학, 심리학, 신경과학, 수학, 통계학, 커뮤니케이션, 교육

논문(thesis)을 완성해야 하고 연구 경험이 있어야 합니다. 추천서도 가급적 연구 중심이 좋습니다.

이 프로그램은 다양성을 크게 중시하며, 지원자가 "인문사회과학"에 기여한 바를 보여 주기를 기대합니다.
