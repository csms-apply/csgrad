# Stanford STATS DS

## 프로그램 개요
Stanford DS에는 최고의 교수진, 아름다운 캠퍼스, 인상적인 동기들이 있습니다(월스트리트에 지쳐 학교로 돌아온 4년 이상 경력자도 많습니다). 연구 품질이 뛰어나고 학제 간 연구를 많이 할 수 있습니다.

## 합격 기준선 및 Data Points
기수마다 약 50명을 합격시킵니다.
거의 모두 미국 학부 출신이고, 명문교 최상위 GPA(3.9+), GRE 330+ 같은 프로필입니다.
1. NYU DS+Math 학부, TA + RA 경험 여러 번, GPA 3.95
2. UCLA Math+Statistics 학부, GPA 3.98, DS 인턴 여러 번
3. Georgetown University Operations Research 학부, Math 부전공, 소규모 회사 DS 인턴
4. Cambridge Economics 학부, First Class Honours, QD 경력 6개월, DS 인턴
5. UESTC Statistics 학부, GPA 3.95+, Harvard 연구 인턴 4개월
6. Duke Statistics 학부, GPA 3.97, MLE 인턴 여러 번
7. UCB DS 학부, GPA 4.0, DS/MLE 인턴 여러 번
8. UCLA DS 학부, GPA 4.0, RA 경력 2년 반
## 취업 결과
대다수가 MLE와 DS 직무로 갑니다. quant로 가는 사람은 매우 적고, 대부분 ICME 쪽입니다. Jane Street나 Citadel에 가는 경우는 극히 드뭅니다. 그 외에는 80% 이상이 빅테크(FAANG)에 취업하며 주로 DS 직무이고 일부는 SWE로 갑니다.

일부 학생은 빅테크보다 스타트업을 선호하며(Stanford는 특히 창업을 장려합니다), 직접 회사를 세우거나 초기 스타트업에 합류합니다.

1. UCLA Statistics 학부, 2024년 석사 졸업, Apple과 소규모 회사 DS 인턴, 2024년 QuantCo DS 정규직.
