# CMU MSCS

## 프로그램 개요
SCS의 대표 프로그램입니다. 수업 선택이 극도로 유연해서 원하는 CS 수업은 사실상 무엇이든 들을 수 있습니다. SCS 전체의 모든 CS 관련 수업을 들을 수 있으며 MSCS 학생이 수강 신청 우선권을 갖습니다. 합격 후 15-213 CSAPP를 들어야 하는데, 미루었다가 미국에 도착한 뒤에 들어도 됩니다. 동기들은 대부분 중국인 아니면 인도인입니다. 입학 연기(deferral)가 가능합니다(23 Fall 오퍼 레터에 deferral이 가능하다고 명시되어 있습니다). 보통 3학기에 걸쳐 약 8과목(인정 units 96–108)을 이수하며, AI / Theory / System 트랙에서 각각 최소 한 과목을 포함해야 합니다. 수업이 꽤 흥미롭습니다 -- 예를 들어 Deep Learning Systems는 GPU 프로그래밍을 다루고 PyTorch의 간소화 버전을 만드는 프로젝트가 있습니다. 적어도 제가 다닌 중국 본토 학부에서는 이런 수업이 아예 개설될 수 없었습니다. 이 수업의 채점 시스템도 외부 학생에게 공개되어 있습니다. CMU 15-445(Database) 같은 다른 유명 수업도 있습니다. 일찍 도착하면 GitHub 3k+ star 개발자인 TA를 만날 수도 있습니다. 15-445도 채점 시스템이 외부 학생에게 공개되어 있고, 프로젝트가 해마다 조금씩 바뀌니 도전해 볼 만합니다.

## 합격 선호
GPA에 극도로 엄격하며 미국 학부생을 분명히 선호합니다. 중국 본토 지원자는 사실상 타깃 스쿨(Tsinghua, Peking + C5)만 고려됩니다. 이 범위 밖이라면 지원비를 낭비하지 마세요. GPA, GRE, TOEFL 세 지표 모두 뛰어나야 합니다. 예전(24 Fall)에는 합격률이 5%에 불과했습니다. 올해(2025)는 PhD 재원 마련을 위한 정원 확대 필요로 합격률이 10%로 올랐지만 여전히 매우 어렵습니다.

2023년에는 지원자 2,073명 중 107명이 합격했고 67명이 등록했습니다.
