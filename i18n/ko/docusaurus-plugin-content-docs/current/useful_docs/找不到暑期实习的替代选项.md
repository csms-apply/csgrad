# 2025년 미국 SWE 여름 인턴십을 못 구했을 때의 대안

올해 미국 SWE 여름 인턴십을 구하지 못했다면 중국 내 인턴십 기회를 살펴볼 수 있습니다.
예를 들어 Microsoft China, Optiver, Alibaba Cloud, Tencent WXG, NVIDIA, Google Shanghai 등이 이미 채용을 시작했습니다.

1. Microsoft: 국내(중국) 채용이 이미 시작되었습니다. 제가 멘토링한 학생들의 데이터 포인트에 따르면 미국 유학 배경이 있거나 중국 상위 대학(Hua-5 수준 이상) 출신을 선호하는 경향이 있습니다. 제가 아는 Microsoft Suzhou 인턴 학생들의 배경은 1) Tsinghua 학부 + GT 석사 2) Xi'an Jiaotong 학부 + Duke 석사 3) Shanghai Jiaotong 학부 + 석사 4) Tongji 학부 + 석사 등이었습니다. 학력을 매우 중시합니다. 1차 면접관이 "hire"를 주면 총 2라운드뿐이고, 그렇지 않으면 3라운드입니다.
2. GSoC: Google이 주최하는 오픈소스 프로그램으로 인지도가 매우 높고 경쟁이 매우 치열합니다. 보수가 높습니다. 미국 수준의 보수를 받으려면 CPT를 사용해야 하며, 보수는 주로 소셜 활동(social presence), PR, 프로젝트 제안서(proposal)로 평가됩니다. CPT가 없으면 중국 수준의 보수만 받을 수 있습니다. 이력서에서 비중이 큽니다.
3. Open Source Summer (OSPP): 중국과학원(Chinese Academy of Sciences)이 주최하며 인지도가 역시 높습니다. GSoC보다 경쟁은 덜하지만 프로젝트 제안서를 꼼꼼하게 작성해야 합니다. 누가 프로젝트를 맡을지는 주로 제안서로 결정됩니다.
4. Alibaba Cloud: Alibaba Cloud는 보통 거의 모든 대기업보다 먼저 채용을 시작합니다(올해는 아니었고 WXG가 먼저였습니다). 예년에는 Gateway 팀, Luoshen Networking 팀 등 여러 팀이 춘절 직후 채용을 시작했습니다. 985 또는 우수한 211 대학(예: BUPT, Xidian) 학부 출신을 엄격하게 요구합니다. 충족하지 못하면 오퍼를 받기 매우 어렵습니다. 미국에 있는 학생은 춘절 이후 Boss Zhipin과 Nowcoder를 확인해 보세요. 이 플랫폼에서 채용합니다. 적합하다고 판단하면 면접 일정을 일찍 잡고 오퍼도 일찍 보냅니다. 여러 팀의 면접을 동시에 보고 가장 잘 맞는다고 생각하는 팀을 고를 수도 있습니다. Alibaba Cloud 여름 인턴십의 return 비율은 매우 높습니다.
5. WXG (WeChat): 여름 인턴십은 라운드가 많고 기술 스택은 C++입니다. 1차 면접은 보통 알고리즘 문제 4개입니다. 통과하면 이후 모든 라운드에서 프로젝트에 대해 집요하게 파고들기 때문에 이력서의 모든 세부 사항을 알고 있어야 합니다. 알고리즘 문제를 풀 수 있는 것은 첫걸음일 뿐이고, 핵심은 기술적 세부 사항을 이해하고 명확하게 아는 것입니다.
