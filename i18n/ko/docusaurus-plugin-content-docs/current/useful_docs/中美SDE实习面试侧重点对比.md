# SDE 인턴십 면접 중점 비교: 미국 vs. 중국


## 미국:
평가 항목:
1. 운
2. 알고리즘 문제
3. 행동 면접(BQ)
4. 프로젝트 세부 사항

여름 인턴십 지원 일정:
보통 입학 전년도 8월부터 이듬해 3월까지입니다. 과정이 매우 길어서 넉 달, 다섯 달씩 걸리는 경우도 있습니다(예: Google). 면접 후 결과를 받기까지 최소 2주는 기다리는 것이 일반적입니다.

위 평가 항목은 중요도가 높은 순서대로 나열한 것입니다. 미국 SDE 면접에서는 운과 알고리즘 문제의 비중이 가장 큽니다. 운은 HR이 내 이력서를 보고 면접을 제안하는지를 결정합니다. 알고리즘 문제 숙련도는 합격 여부를 결정합니다. 면접 알고리즘 난이도는 대체로 중국과 비슷한 수준입니다. 중국 SDE 면접에 비해 프로젝트 세부 사항에는 훨씬 덜 집중하며, 보통 "가장 자랑스러운 프로젝트는 무엇인가요?" 같은 행동 면접 질문으로 확인하고 깊은 후속 질문은 하지 않습니다. 면접 전체의 초점은 알고리즘 문제입니다. 일반적인 흐름은 문제 다시 말하기 - 예시 따라가 보기 - 코드 작성 - 시간 복잡도 분석입니다. 면접이 조용해지면 안 되고, 코딩하면서 계속 말해야 합니다. 내부 리퍼럴이 면접 기회를 얻는 데 도움이 됩니다(저도 내부 리퍼럴로 소규모 회사 면접을 하나 얻었습니다). BQ는 매우 중요합니다. Amazon 같은 일부 회사에서는 오퍼 여부를 직접 좌우할 수도 있습니다. YouTube 영상이나 포럼 자료에 나오는 LP(Leadership Principles) 프레임워크로 BQ를 공부할 수 있습니다.




## 중국:
평가 항목:
1. 인턴십 경험
2. 프로젝트
3. CS 기초(OS, Computer Networks, MySQL, Redis)
4. 알고리즘 문제

여름 인턴십 지원 일정:
보통 같은 해 3월부터 5월까지입니다. 준비가 되었을 때 지원하면 됩니다. 중국의 면접 절차는 매우 빠르게 진행되며, 대체로 비교적 빨리(2주 이내) 시작하기를 기대합니다.

위 평가 항목은 중요도가 높은 순서대로 나열한 것이지만, 알고리즘 문제를 풀지 못하면 자동 탈락입니다. 면접 시간의 대부분은 인턴십 경험과 프로젝트가 차지합니다. 면접은 보통 기술 면접 3회 + HR 면접 1회이며, 기술 면접이 2회인 경우도 있습니다. 미국에 비해 기술 평가가 더 깊고 비즈니스 세부 사항에 대한 질문이 많습니다. 예를 들어 인턴십 경험이 검색/광고/추천 분야였다면 cold start 문제, 대규모 데이터를 어떻게 저장하는지, 실시간성을 어떻게 보장하는지 등을 물을 수 있습니다. 행동 면접 질문은 기본적으로 하지 않습니다. 다만 Alibaba 계열 회사 면접은 예외로, 그쪽 HR은 권한 범위가 커서 지원자를 직접 탈락시킬 수 있습니다. 알고리즘 파트에서는 보통 코딩하면서 설명할 필요 없이 최적해를 작성하기만 하면 됩니다. 내부 리퍼럴은 면접 기회를 얻는 데 도움이 되지 않습니다.
