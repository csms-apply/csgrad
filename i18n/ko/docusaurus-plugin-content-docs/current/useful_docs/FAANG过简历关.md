# FAANG 서류 통과하기

저는 운 좋게도 2025년 여름 인턴십 구직 중에 모든 FAANG 회사에서 면접 기회를 얻었고, 참여한 면접은 모두 통과했습니다(여기서는 Netflix 대신 NVIDIA를 넣었습니다). FAANG의 서류 심사를 통과하고 virtual onsite를 받는 방법은 다음과 같습니다.

Facebook (Meta): HR reach-out과 내부 리퍼럴에 크게 의존합니다. 제가 아는 Meta 합격자는 두 부류입니다. 첫 번째는 HR이 먼저 연락을 준 사람이고, 두 번째는 포지션이 열리자마자 선배/동문에게 바로 내부 리퍼럴을 부탁한 사람입니다. "no referral, no Meta"라는 말이 있습니다. Meta의 내부 리퍼럴 정책은 리퍼럴 지원서를 14일 안에 처리하도록 요구합니다. Meta 인턴십 내부 리퍼럴을 구하려면 포지션이 열리는 즉시 움직여야 합니다. 2024년 9월 말에 Meta는 포지션을 열고 인턴 리퍼럴 제출 기간을 며칠만 준 뒤 채널을 닫았습니다.

Apple: 이력서 매칭에 크게 좌우됩니다. 팀이 지원자가 자기 팀 업무와 맞는다고 판단해야만 면접을 잡습니다. 예를 들어 저는 전에 Edge의 extensions를 작업한 적이 있고 이 팀은 Safari의 extensions를 담당했기 때문에 면접을 잡아 주었습니다.

Amazon: 내부 리퍼럴은 별로 소용없고, 포지션이 열리는 첫날 지원하는 편이 더 효과적입니다. GitHub의 intern repository를 보면 Amazon이 포지션을 열었는지 확인할 수 있습니다. OA는 매우 쉽습니다. 어려운 부분은 OA를 받는 것과 BQ 파트입니다. 코딩 파트는 항상 쉬웠습니다. BQ 파트는 Soroush가 질문을 정리한 YouTube 영상이나 포럼에 공유된 자료를 참고하면 됩니다. 이상적으로는 BQ 답변 하나가 LP(Leadership Principles)를 두세 개 짚어야 합니다.

Netflix: 면접 기회를 얻은 사람을 거의 본 적이 없지만 보상은 매우 높습니다. 인턴 급여가 시간당 약 $110입니다.

Google: 내부 리퍼럴이 도움이 되지만 꽤 운에 좌우되기도 합니다. 제 개인 사례를 들면, 2024년 6월에 Google 인턴십에 대량으로 지원했지만 답이 없었습니다. 10월에 선배에게 강한 리퍼럴을 부탁하고 다시 지원했더니 OA를 받았습니다.

프로젝트, 이력서, 면접을 준비하는 방법은 제 프로필 페이지에 고정된 인턴십 경험 공유 글을 참고하세요. 면접/이력서 코칭이 필요하면 편하게 연락 주세요.
