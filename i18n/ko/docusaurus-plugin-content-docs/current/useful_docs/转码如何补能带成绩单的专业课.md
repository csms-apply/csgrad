# 성적증명서가 나오는 CS 선수 과목 이수 방법
[어떤 CS 선수 과목을 들어야 하는지](转码需要补的专业课.md) 이해했다면, 다음 단계는 실제로 어떻게 수강할지 알아내는 것입니다.
핵심 원칙이 하나 있습니다. 성적증명서가 나오지 않는 MOOC를 듣는 것은 CS 선수 과목을 이수한 것으로 인정되지 않습니다. MOOC는 성적증명서가 없고, 지원하는 학교는 여러분이 정말 그 수업을 들었는지
알 방법이 없습니다. 시험이 있고, 학점을 주며, 공식 성적증명서를 발급하는 프로그램을 찾아야 합니다.

## 공식 성적증명서를 발급하는 기관
1. WGU (실무형 수업, SDE 지향이 매우 강함)
2. University of the People (제 생각에 가장 가성비 좋은 학교로, 전 분야의 수업을 제공)
3. ASU Online
4. University of Colorado Boulder Post-Bacc–Applied Computer Science

위 기관은 모두 온라인 프로그램이라 중국 학생이 원격으로 수강하고 공식 성적증명서를 받기에 편리합니다.
## University of the People

요약: 정말 부담 없는 "국민 대학"으로, 여기서 가장 저렴한 옵션이며 수업당 $140에 불과합니다. Databases 1,
Communications and Networking, Software Engineering 1, Data Structures, Discrete Mathematics,
College Algebra, Introduction to Statistics 같은 기초 수업을 제공합니다. 전공 전환자가 선수 과목을 채우기에는 충분하고도 남습니다.


![University of the People 컴퓨터공학 학위 비용](/img/en/1.png)

## WGU
WGU도 훌륭한 선택지로, Web Development Foundations, Linux Foundations,
Java Frameworks, Data Structures and Algorithms I, Software Engineering, Network and Security - Foundations, Operating Systems for Computer Scientists처럼 매우 실용적인 수업이 있습니다.
이쪽도 추천합니다.

![WGU 컴퓨터공학 수업 목록](/img/en/WGUcourses.png)

## ASU Online
학비는 학기당 $8,451로 받아들일 만한 수준입니다. Data Structures, Operating Systems, Compilers 등 필수적인 수업을 제공하지만 조금 비싸기 때문에 강하게 추천하지는 않습니다.

![Arizona State University 예상 학비](/img/en/2.png)
![Arizona State University 온라인 컴퓨터공학 수업](/img/en/3.png)



## University of Colorado Boulder
Computer Systems, Algorithms, Machine Learning, Software Development Methods and Tools,
Computer Science 2: Data Structures, Discrete Structures, Principles of Programming Languages를 제공합니다.
대면 수업도 있고 두 번째 학사 학위 과정도 제공하므로, 이미 미국에 있는 학생은 대면 수강을 고려해 볼 수 있습니다.
