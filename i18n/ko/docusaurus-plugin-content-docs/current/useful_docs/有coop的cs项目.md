# Co-op이 있는 CS 프로그램

Gatech MSCS

Gatech MS CSE — MSCS와는 별개의 학위이므로 MSCS 프로그램으로 transfer할 필요가 없습니다. co-op은 GT 전체의 Graduate Co-op Program이며 CSE 학생도 참여할 수 있습니다

Duke ECE MEng — 2024년 Fall부터 co-op을 제공한다고 프로그램이 발표했습니다

JHU MSECS (아는 사람이 많지 않지만, 한 친구가 JHU에 이메일로 문의해 co-op이 가능하다는 확인을 받았습니다)

UCSD ECE / CS75 (ECE는 co-op 가능, CS75도 2025년부터 co-op을 제공합니다)

NYU Tandon MSCS (봄학기에 co-op 가능)

UT Austin ECE (SES) — co-op 가능하며 졸업을 연장할 수 있습니다

UIUC MCS (본교, Chicago, 심지어 Spring 입학도 동일하며, 미국 학부 출신이 아니면 1년 후 co-op 신청 가능)

UIUC ECE

UW EE PMP (졸업을 연장하지 않고 가을에 풀타임 co-op 가능)

TAMU MCS

NEU MSCS

NEU CS Align

NEU IS
