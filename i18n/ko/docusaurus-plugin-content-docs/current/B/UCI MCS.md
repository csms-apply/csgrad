# UCI MCS

## 프로그램 개요
연장이 불가능한 전문 프로그램이며 quarter 시스템으로 운영됩니다(5월에 인턴을 시작할 수 없음 + 빠른 진도가 구직 시간을 압박함 + 3개월마다 시험 + quarter 시스템에서는 효과적으로 가르칠 수 없다고 불평하는 교수도 있음).

경력과 어느 정도의 구직 준비를 갖추고 입학하는 것이 가장 좋습니다. 다시 말해 미국에서 일자리를 구할 준비가 이미 완전히 되어 있어야 합니다. MSWE 프로그램이 MCS보다 여러 면에서 낫습니다. 예를 들어 첫 quarter에 시험이 없어 부담이 적고 커리큘럼이 더 실무 지향적입니다. MCS는 미국에 오기 전에 이미 LeetCode 300문제 이상을 푼 학생이나 정규직 경력이 있는 학생에게만 적합합니다. 전반적으로 MSWE만 못합니다. PhD를 하고 싶다면 UCI MSCS 프로그램을 알아보세요.

## 입학 선호도와 데이터 포인트
GPA 3.5 안팎이면 합격 가능성이 좋습니다. 인도 학생은 보통 3년 이상 경력을 갖고 오고, 중국 본토 학생은 대체로 정규직 경력이 없습니다. MCS 프로그램은 UCI 자교 학부생을 선호하지 않습니다(GPA 3.8+의 UCI CS 학부생이 탈락했다는 보고가 여러 건 있으며, MCS 수업이 학부 수업과 거의 같고 성적 요건까지 같기 때문이라고 합니다).

1. Tianjin University EE 학부, GPA 3.56, State Grid와 중소기업 인턴
2. University of North Texas CS 학부, GPA 3.85
3. UCI CS 학부, GPA 3.98
4. Gonzaga University Math + CS 학부, GPA 3.9

## 취업 결과
2022년 인턴 취업률은 89%였는데, 주로 경력 3년 이상인 인도 학생이 많아 수치를 끌어올렸기 때문입니다. 중국 학생의 취업률은 이렇게 낙관적이지 않습니다.

1. UCI CS 학부, 인턴 경험 없음, 중소기업 Android developer 포지션 획득
2. Gonzaga University Math + CS 학부, Smartsheet 인턴 획득
3. Tianjin University EE 학부, 인턴 경험 없음
4. 인도 동기, Barclay Center 정규직 3년, Pure Storage 인턴 획득, 신입으로 Meta 입사
5. 인도 동기, 정규직 1년, Veeva Systems 인턴(어바인 지역 중소기업) 획득 후 정규직 전환 성공

6. National Central University CS 학부, 석사 중 중소기업 SWE 인턴, 2025년 졸업 후 Matching Donors에서 파트타임 Web Developer

## 단점
Quarter가 6월 중순에 끝나므로(2026 Spring quarter는 6월 12일에 종료) 5월이나 6월 초에 인턴을 시작할 수 없습니다. 그 결과 사실상 대기업에서만 인턴을 할 수 있습니다(한 인도 동기는 6월 초 시작 오퍼를 받았지만 CPT를 받지 못해 오퍼가 취소되었습니다).
