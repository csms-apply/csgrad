# USC CS28

## 프로그램 개요
2년 과정이며 GPA만 본다는 것으로 유명합니다. 기수 규모가 엄청나게 커서(CS28과 CS37 합산) 거의 천 명에 가깝습니다.

## 합격
배경과 GPA만 봅니다. 추천서는 선택 사항입니다. Rolling admissions입니다. 모든 학교의 모든 지원자를 한데 모아 GPA로 순위를 매기고 위에서부터 아래로 오퍼를 보냅니다. 985/211 대학 배경을 중시합니다.

인턴십과 연구는 고려하지 않습니다. GPA가 높은 지원자의 안전 학교(safety school)로 추천합니다.

## RA / PhD 전환 기회

매우 어렵습니다. USC CS 관련 프로그램은 기수 규모가 엄청나게 커서 RA 기회를 찾기 매우 어렵고, PhD로 전환하기도 매우 어렵습니다.
