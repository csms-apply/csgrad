# CMU MSAII

## 프로그램 개요
SCS 산하의 대표 AI 프로그램이며 취업 지향입니다. 연구를 하고 싶다면 SCS MSR이나 MSML을 보세요. 프로그램이 매우 유연하고 비전공자 CS 전환에 우호적이며, 다양한 배경의 전환 DataPoints가 많습니다. 학과장은 스펙이 뛰어난 지원자를 선호합니다 -- GPA, GRE, TOEFL이 높을수록 좋습니다(TOEFL 105+, GRE 330+, 최상위 GPA). 업무량이 적은 쉬운 수업이 많고, 선택과목 8개 자리를 모두 하드코어 SCS 시스템 수업으로 채울 수 있습니다 -- CC, ACC, OS, Storage 모두 가능합니다. Coding Bootcamp라는 LeetCode 훈련 수업이 있어서 SDE 직무를 구하는 데 매우 우호적입니다.


## 합격 기준 & DataPoints
TOEFL 105+ GRE 330+ 최상위 GPA는 사실상 필수입니다. 같은 학교 동기들로부터 오는 peer pressure가 있을 수 있습니다.

1. Rutgers CS 학부, GPA 3.984
2. Illinois Wesleyan University Biology 학부, GPA 3.78, Duke PhD에 합격했으나 반년 만에 중퇴
3. 인도 Telecom 학부, GPA 8.09/10, Adobe 인턴십, Amex 애널리스트 정규직 3년
4. Tsinghua 건축학 학부, 석차 1등, GPA 3.87, 경제학 부전공
5. UVA CS + Physics 학부, GPA 3.91
