# 📌 DataPoints 데이터베이스 제출 가이드

## 1. 중요 안내

**DataPoints© 데이터베이스는 읽기 전용 데이터 테이블입니다.**

다음 3개 하위 테이블의 내용을 추가하거나 수정하려면:

- DataPoints
- Applicant Information
- Program List

데이터베이스를 직접 수정하지 말고 반드시 해당 **수집 폼(Form)**을 통해 제출해 주세요.

---

## 2. 제출 절차

### Step 1️⃣ 지원자 정보 제출 (1회만)

먼저 **"Applicant Information Collection Form"**에 개인 정보를 입력해 주세요.

- ✅ 한 번만 제출하면 됩니다
- ❌ 제출 후에는 수정할 수 없습니다
- 🔗 이후의 모든 DataPoints 항목이 이 계정에 연결됩니다

---

### Step 2️⃣ 합격 DataPoints 제출

**"DataPoints Collection Form"**에서 합격 데이터를 제출하세요.

- 폼을 작성할 때 **Applicant 필드**를 통해 앞서 제출한 개인 정보에 연결합니다
- **횟수 제한 없이 업데이트와 수정**이 가능합니다

---

## 3. 목록에 없는 프로그램 추가

지원한 프로그램이 아직 데이터베이스에 없다면:

1. **"Add New Program"** 폼으로 프로그램을 제출합니다
2. 승인된 후에
3. 이후 항목을 작성할 때 "Program 필드"에서 해당 프로그램을 검색해 선택할 수 있습니다

---

## ✅ 요약 흐름도

Applicant Information (1회)
↓
DataPoints (여러 번 업데이트 가능)
↓
Progress (여러 번 업데이트 가능)
↓
프로그램이 없는 경우 → Add New Program
