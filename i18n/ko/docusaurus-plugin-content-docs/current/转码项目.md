# 전공 전환 프로그램

전공 전환(비전공자 CS 전환) 프로그램은 완전 제로 배경 프로그램(CS 선수 과목을 전혀 듣지 않은 경우)과 부분 제로 배경 프로그램(CS 선수 과목을 일부 들은 경우)으로 나뉩니다. 경제/경영/생물학 배경이어서 Data Structures, Computer Organization, Operating Systems 같은 선수 과목을 듣지 않았다면
[전공 전환자를 위한 선수 과목](useful_docs/转码需要补的专业课)을 참고해 수강 계획을 세우세요.

## 완전 제로 배경 전공 전환


1. NEU CS Align
2. UPenn MCIT (명문대 출신 높은 GPA를 선호하며 GPA 3.9+면 비교적 안전)
3. [UChicago MPCS](A-/uchicago%20mpcs.md)
4. USC CS37
5. NEU ISB
6. [UIUC MSIM](B-/UIUC%20MSIM.md)
7. Columbia CS Bridge
8. NYU Tandon MSCS Bridge
9. [JHU MSECS](A-/jhu%20msecs.md)
10. CMU MITS

7. [Emory MSCS](B/Emory%20MSCS.md)
