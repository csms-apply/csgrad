# Columbia MSEE

## 프로그램 개요

집에서 요리 + 외식(70% / 30%) 기준으로 1년 반 총비용은 약 80만 RMB입니다(특별히 아끼는 생활은 아닙니다). 샤오홍슈에서 뉴욕에서 1년에 100만 RMB를 쓴다는 말은 완전한 헛소리이고 실제 조사에 근거한 것이 아닙니다. 뉴욕에서 1년에 100만 RMB를 쓸 수 있는 사람은 UCSD에서도 똑같이 쓸 수 있습니다. 뉴욕은 문화와 오락거리가 풍부한 훌륭한 도시입니다.

## 수업 선택
CS 과목을 많이 들을 수 있어서 CS로 전공을 바꾸려는 사람에게 적합합니다.

3개 학기 동안 총 10과목을 들어야 하고, 최소 5과목은 EE 과목, 최소 5과목은 6000번대 이상이어야 합니다. 이론상 나머지는 모두 CS 과목으로 채울 수 있습니다. CE보다 유연할 수 있습니다. CE는 필수 하드코어 과목이 있지만 EE는 순수 CS 과목만 들을 수도 있습니다.

1. COMS4111 Intro to Databases. Donald 교수의 수업으로, 관계형 데이터베이스의 SQL부터 인덱싱까지 다루고 비관계형 데이터베이스는 MongoDB와 Neo4j를 다룹니다. 과제는 약 5개이고 모두 Jupyter notebook으로 코딩하며, Python의 SQLAlchemy를 연습하거나 MongoDB와 Neo4j API에 연결해 NoSQL 실습을 합니다. 중간고사와 기말고사는 take-home이고 A 받기가 매우 쉽습니다.

2. COMS6156 Topic in Software Development: Cloud Computing-baidu 1point3acres
역시 Donald 교수의 수업으로, 소프트웨어 개발 프로세스, AWS 구성 요소, 마이크로서비스 개념을 다룹니다. 강의는 모두 개념 위주이고 숙제와 시험은 없으며, 5-7명이 하는 큰 그룹 프로젝트 하나뿐입니다. 프로젝트는 마이크로서비스 웹 앱을 만들어 전부 AWS에 배포해야 합니다. 주요 요구 사항은 RDS, Lambda, EC2, Elastic Beanstalk, Cloud API, S3, CloudFront 등입니다. 열심히 하면 특히 AWS와 serverless 트렌드에 대해 많이 배울 수 있습니다. 기본 요건만 충족해도 A를 받습니다.

3. EECS6893 Big Data Analytics
Ching-Yung Lin 교수의 수업이며, 그는 AI 회사 CEO이기도 합니다. CEO가 가르치다 보니 개념은 많고 세부 내용은 적어서 스스로 공부해야 합니다. 이 수업은 범위가 넓어서 Hadoop, Spark, Machine Learning, Air Flow, d3.js를 모두 다루고 각 주제마다 프로그래밍 과제가 있습니다. 시간이 매우 많이 들고, 기말 프로젝트도 노력이 많이 필요합니다. 절반 정도가 A를 받습니다.

4. ELEN6770 Cloud Computing & Network Virtualization
두 명의 강사가 전반부와 후반부를 나눠 가르치며, 둘 다 Bell Labs 출신입니다. 비교적 쉽습니다. 과제 2개, 중간고사와 기말고사가 있습니다. 성적은 대략 절반이 A(A-), 절반이 B(B+)입니다.

5. CSOR4231 Analysis of Algorithms.
Eleni 교수님이 훌륭하고 수업의 질이 높으며, 강의 중에 계산 과정을 손으로 직접 씁니다. 이 수업은 알고리즘의 정확성 증명과 복잡도 분석에 초점을 맞추며, 수학 비중이 크고 프로그래밍은 없습니다. 과제 + 중간고사와 기말고사가 있습니다.
6. COMS4705 Natural Language Processing
Daniel 교수의 수업으로, 내용은 비교적 기초적이고 슬라이드가 자세하며 체계적으로 구성되어 있습니다. 과제 + 중간고사와 기말고사가 있습니다.
7. ELEN6889 Large-Scale Stream Processing
인도계 미국인 교수가 가르치는데 인도 억양이 약간 있을 뿐이고 평이 좋습니다. 교수의 강의가 매우 훌륭하며 Spark, Apache Beam 같은 스트림 처리 응용을 다룹니다.
8. ELEN6883 Intro to Blockchain
Chong Li 교수가 가르치며, 가을에는 6885 과목도 개설합니다. 둘 다 쉽게 A를 받을 수 있는 과목입니다. Bitcoin, NFT 등 블록체인 관련 폭넓은 주제를 다룹니다.


## 합격선
합격선이 우호적입니다. 985 대학 GPA 3.4로 합격한 데이터 포인트도 있지만, 그렇다고 이 프로그램이 나쁘다는 뜻은 아닙니다. Columbia라는 이름만으로 어느 회사에서나 면접을 볼 수 있습니다. Peking University CS 출신도 이곳에 옵니다. 중국으로 돌아가든 미국에서 구직하든 Columbia 출신이라고 무시당한 사람은 없고, 모두가 대단하다고 생각합니다. 합격선은 아무도 신경 쓰지 않고, 지원 시즌의 지원자들만 신경 씁니다. (세상은 넓고, 능력 있는 사람은 잘됩니다. 학벌보다 능력이 중요합니다.)

1. HKUST EE, First Class Honours
2. Shanghai University EE 학부, GPA 86
3. UESTC EE 학부, GPA 89
4. Xidian University CS 학부, GPA 3.84, 이후 Columbia EE 내 PhD로 전환 성공
5. Utah EE + Math 학부, GPA 3.95

2. Shanghai University EE 학부, 중국 중소기업 인턴 경험, 미국 중소기업 product manager 포지션 획득
