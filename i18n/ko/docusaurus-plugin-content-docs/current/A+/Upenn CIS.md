# Upenn CIS

## 프로그램 소개

사실상 CS 프로그램입니다. 석사 학위를 받으려면 10과목을 이수해야 합니다. 일반적인 졸업 일정은 다음과 같습니다.

2년 트랙 (3-3-2-2)
1.5년 트랙 (3-3-4)
수강형 트랙 또는 논문형 트랙을 선택할 수 있어 취업 준비와 PhD 지원 모두에 유연합니다. 학비는 풀타임 기준 2026-27년에 한 학기당 3 CU면 약 $29,399, 4 CU면 $38,224(fee 포함)이지만, 2학년에 수강 과목이 줄면 더 낮아질 수 있습니다.

Ivy League라는 타이틀은 매우 매력적입니다. 중국 본토 학생의 합격 기준은 SS 티어까지 올라갈 수 있고, 미국 학부생은 S 티어 정도입니다. 다만 취업 결과는 Stanford나 CMU SCS 수준의 프로그램과는 정말 비교할 수 없습니다.

## 수업 경험
속도가 빠르고 업무량이 많으며 쉬운 수업이 없습니다. 업무량은 학부의 두 배입니다. 특히 시스템 수업은
거의 모든 팀원이 며칠씩 도서관에서 지내고, 자정까지 프로젝트를 하는 것이 일상입니다.
예를 들어 CIS 5050 Software System은 Gmail과 비슷한 분산 이메일 시스템을 만들어야 하고, 한 학기 내내 동시성, 동기화, 로드 밸런싱 문제를 디버깅합니다.
CIS 5530 Networked System은 Layer 3 라우팅 프로토콜 + Layer 7 분산 검색 엔진을 구현해야 하며,
디버깅할 때마다 OS와의 싸움입니다. CIS 5550 Internet and Web System은 Penn에서 가장 어려운 수업 중 하나입니다.
Google Search Engine을 시뮬레이션합니다. 단순한 수업 프로젝트를 넘어 정말 하드코어하고 이력서에 쓸 만합니다.
