# Wisc CS PMP
## 프로그램 개요
Wisc MSCS는 Ph.D 프로그램과 같은 지원자 풀을 공유하기 때문에 경쟁이 극도로 치열합니다. PMP 프로그램은 본질적으로 다른 학교의 MCS 프로그램과 동등합니다.


학비가 저렴합니다. 비거주자 기준 학점당 $1,503.40입니다. 마지막 학기는 파트타임으로 해서 학점 단위로 낼 수 있어서 30학점 기준 총비용이 약 $45k이며 매우 좋은 조건입니다.

인턴 기회가 두 번(fall과 spring 인턴 허용), 프로그램 기간은 1.5-2년(2.5년으로 연장도 가능)이며 Gatech MSCS와 매우 비슷합니다.


온라인 PCP 프로그램에 지원한 뒤 PMP로 전환할 수 있습니다(주로 GPA 기준).

## 합격선과 데이터 포인트
지원자 수가 해마다 늘고 있습니다.
22Fall: 지원자 약 900명
23Fall: 지원자 1,000명 초과


정규직 경력은 사실상 필수입니다. 인턴 경험은 인정되지 않습니다. 제가 지원했을 때 CS PMP가 모든 지원자에게 직접 이메일을 보내 인턴 경험을 근무 경력으로 적지 말라고 안내했고, "졸업 후 취업"만 정규직 경력으로 인정했습니다. 당시 포럼과 SNS의 결과를 보면 이 기준이 매우 엄격하게 적용되었습니다.
SDE 정규직 경력이 있으면 합격 확률이 약 85%입니다. 없으면 약 0.5%로 떨어집니다.

24 Fall에는 정규직 경력이 없는 국제 학부생이 단 한 명뿐이었고, 나머지는 기본적으로 중국 대형 IT 기업에서 몇 년씩 일한 경력이 있었습니다.

1. UCI CS 학부, GPA 3.76
2. 인도 학부, 미국 석사, 뉴욕에서 7년 근무
3. IIT 학부, AWS 2년, 이전에 Microsoft 인턴
4. 인도 학부, GPA 8.3, Samsung 정규직 2년

## 취업 결과와 데이터 포인트
학교 내 동료 간 압박이 없고 합격자 거의 모두가 정규직 경력이 있어서 취업률이 자연스럽게 높습니다.

빅테크 인턴 및 정규직 오퍼:
1. Amazon (인턴 + 리턴 오퍼)
2. Pinterest (인턴 + 리턴 오퍼)
3. Facebook (인턴 + 리턴 오퍼)
4. Dell EMC (인턴 + 리턴 오퍼)
5. IIT 학부, AWS 2년, 이전에 Microsoft 인턴, SF 중소기업 획득
6. 인도 학부, GPA 8.3, Samsung 정규직 2년, Amazon 획득
