# Upenn MSR

## 프로그램 개요
오기 전에는 이 프로그램을 "엄청 하드코어하고, 엄청 경쟁적이고, 연구실에서 밤낮없이 갈아 넣는 곳"이라고 상상했습니다...
그런데 와서 보니, ROBO는 미국에서 가장 유연하고 "스스로 설계해 가는" 로보틱스 석사 프로그램 중 하나였습니다! MCIT/MCIS 등과 복수로 다닐 수도 있습니다.

제가 느낀 가장 큰 점을 한 문장으로 말하면:
"자유도가 높으면 가능성은 무한하지만, 내가 무엇을 원하는지 아주 분명히 알아야 한다는 뜻이기도 하다."
정해진 경로가 없습니다. 하고 싶은 공부를 하고, 관심 있는 연구 방향마다 맞는 전문가를 찾고, 자신의 관심사와 커리어 계획에 맞춰 석사 경험을 완전히 직접 만들어 갈 수 있습니다.

필라델피아 생활비: 중상 수준으로, NYC/베이 에어리어보다 낮고 Houston/중서부 도시보다 높습니다.
월세(룸 셰어): $900-1400/월, 집에서 요리 + 가끔 외식: $500-800/월. 일과는 이렇습니다.
연구를 안 하는 경우: 월~금 수업 + 숙제. 효율적으로 하면 여러 행사에 참여할 자유 시간이 충분합니다.
연구를 하는 경우: 수업 + 숙제 + 랩. 연구에 주당 10-20시간 정도 들어서 일정이 꽤 빡빡합니다.
하지만 Penn Engineering에는 거의 매주 다양한 연구 세미나가 열려서, 방향을 탐색하고 싶은 학생은 여유 시간을 채울 수 있습니다.

## 합격선과 데이터 포인트
가을 입학 기수마다 약 30명이고, 보통 중국 학생은 6-8명입니다.
배경이 매우 다양합니다. 중국 상위 학부에서 바로 지원한 사람, 미국 학부 편입생, 몇 년간 일하다 돌아온 사람 등이 있습니다.
입학은 확실히 경쟁이 치열하지만 눈에 띄는 "뒷문"이 있습니다. 먼저 다른 Penn Engineering 프로그램(EE, SE 등)에 들어간 뒤 로보틱스에 진짜 관심이 있다면 ROBO로 옮기는 것이 훨씬 쉽습니다. 많은 선배가 실제로 그렇게 했습니다.

1. UMass Mechanical Engineering 학부, 로보틱스 관련 인턴 다수
2. Worcester Polytechnic Institute Robotics 학부, GPA 3.95
3. IIT Automation 학부, GPA 9.04/10, 정규직 경력 3년
4. 인도 학부, GPA 8.72/10
5. NYU CS+DS, GPA 3.87/4

## 취업 결과와 데이터 포인트

가장 흔한 방향은 Computer Vision + Coding 관련 포지션(FAANG/빅테크 AI 부서, 자율주행, 로보틱스 회사 등)이고, Control, Planning, Manipulation 직무로 가는 사람도 많습니다.

회사 유형: Tesla, Waymo, Aurora, Boston Dynamics, Amazon Robotics, Apple, Meta Reality Labs, Google X 등. 흔한 직함은 Robotics Engineer, Perception Engineer, Software Engineer - Robotics 등입니다.

연봉 범위(최근 몇 년 데이터 기준): 초봉은 보통 $150k-220k(base + bonus + RSU) 사이이며, 회사와 지역에 따라 크게 다릅니다.

1. Upenn EE 학부, 중소기업 하드웨어 인턴 획득
2. Upenn CE 학부, Amazon 하드웨어 인턴 획득
3. IIT Automation 학부, GPA 9.04/10, 정규직 경력 3년, Amazon DS 획득
4. 인도 학부, GPA 8.72/10, 인턴 다수, SF 중소기업 CV Engineer 획득
5. Upenn EE 학부, 인턴 경험, SpaceX SDE Test Intern 획득
6. NYU CS+DS 학부, 중소기업 DS 인턴, Amazon DS 인턴 획득
7. University of Houston CS 학사, 입학 전 Kyndryl 인턴과 약 2년의 Software Developer 정규직 근무, 석사 중 2025년부터 PCASO Lab에서 파트타임 RA

5. Jianbo Shi (CV의 고전적 인물)

연구 방향이 맞고 먼저 적극적으로 연락하면, PhD 학생이 멘토가 되어 랩에 들어가게 해 줄 확률이 매우 높습니다.
