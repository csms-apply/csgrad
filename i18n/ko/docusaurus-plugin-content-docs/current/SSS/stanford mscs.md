# Stanford MSCS

## 프로그램 개요
최고 중의 최고이며, 단점이 없는 유일한 프로그램입니다. 위치는 비할 데 없이 좋고(캘리포니아의 햇살과 바다), 학교 이름도 대단하며, CS 랭킹도 최상위이고, Meta와 Nvidia가 바로 옆입니다(차로 10분). 여름에 Meta나 Nvidia에서 인턴을 해도 따로 집을 구할 필요가 없습니다(지내던 기숙사에 그대로 있으면 됩니다). 취업 결과도 놀랍습니다. 제가 아는 동기들은 거의 모두 Nvidia 면접을 봤습니다. PhD로 전환하려면 다시 지원해야 합니다. 수업의 질이 훌륭합니다. CS229 Machine Learning, CS231N Deep Learning for Computer Vision, CS224N(NLP)은 CS 학생이라면 거의 다 들어 본 유명 과목입니다. 승마, 양궁, 일본어 같은 교양 수업도 들으면서 균형 잡힌 생활을 할 수 있습니다. 기숙사 환경은 최고입니다.




## 입학 선호도와 대표 데이터 포인트

## TA/RA 기회
TA: CS TA 자리가 매우 많습니다(예: CS224는 TA가 24명). TA를 하면 학비가 면제되고 급여도 받으며($10k/quarter) 대우가 매우 후합니다.

국제 학생은 TA를 하려면 영어 시험을 통과해야 합니다. 제가 아는 Stanford 학생들(CS, EE, ICME 모두)은 전원 TA나 RA 자리를 구할 수 있었습니다.
