# UMN MSCS

## 프로그램 개요
TA 자리를 얻으면 학비가 면제되고 세후 월 약 $1,600의 급여를 받습니다. UMN MSCS는 UMN BSCS 학생의 안정권(safety school) 역할을 합니다. 생활이 꽤 편안합니다. PhD로 편입하는 것을 고려한다면 살펴볼 만합니다.

## 합격 선호도와 대표 데이터 포인트
높은 GPA의 C9 대학(전공 전환자) + CS 전공에 GPA가 보통인 985/상위 211 대학.

## 취업 결과와 데이터 포인트
빅테크는 주로 Amazon 채용에 의존합니다. 전반적으로 취업 성과는 좋지 않습니다.

- UMN CS 학부, 석사 전 IDG Capital Financial Data Analyst 인턴십, 2022년 졸업 후 Vanguard SWE 정규직.

## PhD 편입
지도교수를 찾으면 PhD 프로그램으로 편입할 수 있고, 이는 아주 좋은 조건입니다. UMN 시스템은 연구에 꽤 강합니다. 다른 학교로 가고 싶다면 Wisconsin, Purdue, JHU 같은 강한 프로그램에서 오퍼를 받은 학생도 있습니다. 대부분은 UMN에 남습니다.
