# 📌 DataPoints Database Submission Guide

## 1. Important Notice

**The DataPoints© database is a read-only data table.**

To add or update content in the following 3 sub-tables:

- DataPoints
- Applicant Information
- Program List

Please be sure to submit through the corresponding **collection form (Form)**, rather than modifying the database directly.

---

## 2. Submission Process

### Step 1️⃣ Submit Applicant Information (One-Time Only)

Please first fill in your personal information in the **"Applicant Information Collection Form"**.

- ✅ Only needs to be submitted once
- ❌ Cannot be modified after submission
- 🔗 All subsequent DataPoints entries will be linked to this account

---

### Step 2️⃣ Submit Admission DataPoints

Submit your admission data in the **"DataPoints Collection Form"**.

- During the form, link to your previously submitted personal information via the **Applicant field**
- Supports **unlimited updates and modifications**

---

## 3. Adding Unlisted Programs

If the program you applied to is not yet in the database:

1. Submit the program through the **"Add New Program"** form
2. After approval
3. You can then search for and select that program in the "Program field" when filling out future entries

---

## ✅ Summary Flowchart

Applicant Information (one-time)
