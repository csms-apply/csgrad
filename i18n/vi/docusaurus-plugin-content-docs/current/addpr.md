# Đóng góp nội dung

## Dự án CS Grad nhận đóng góp nội dung qua Pull Request
1. Trước tiên, vào [kho mã dự án CS Grad](https://github.com/csms-apply/csgrad) và bấm Fork

![Nút fork trên kho mã GitHub của CS Grad](/img/en/fork.png)

2. Bấm Create fork để fork dự án về kho mã của bạn

![Biểu mẫu tạo fork trên GitHub cho CS Grad](/img/en/createfork.png)
