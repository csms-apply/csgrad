## 選課和 wld {#选课和-wld}

CS28 是老叫法，2024 fall 起普通 MSCS 無論文方向改成了 32 學分，比原來多一門課。

570 算法比較值得上，偏理論和證明，不是刷題課。571 Web 適合補開發項目，2020—2022 年的課程版本有 Web 和手機端作業，後期 wld 不算小。402 OS 偏硬核，想學系統可以上。585 DB、572 搜索相對適合搭配找工，但 DB 的內容工作以後也用得上，不能只按水課看。

同一個課號換老師，體驗可能差很多。570 的講法、作業是否計分都有過不同版本；系統課和輕 load 課搭配出來，完全是兩種讀法。

## 找工

找工氛圍濃，投簡歷、內推、刷題主要靠自己。學校有 career fair 和 Handshake，有人能從招聘會拿到面試，但 LA 的位置本身不會多送幾個面試。2022 年的 ng 行情和 2025 年差得很大，老的“大廠 offer 隨便拿”不能當現在的預期。

## 生活

LA 吃喝玩樂確實多，不過有車和無車的體驗差別很大。住學校附近、自己做飯，不買車也能過；想經常跑華人區和周邊玩，有車方便不少。這個項目的生活上限蠻高，花費也能跟著上去。

## CPT（2026-10-11 更新）

USC 現在要求實踐是項目全體學生必修，選修實習課不夠。普通 MSCS 未見全體必修實習要求，597/598 不計學位，舊的 CPT 實習安排不能直接照搬。
