## 選課和 wld {#选课和-wld}

CS28 是老叫法了，2024 fall 起普通 MSCS 無論文方向改成了 32 學分，比以前多一門課。

570 算法挺值得上，偏理論和證明，不是刷題課。571 Web 適合補開發項目，2020—2022 年那版有 Web 和手機端作業，後半段 wld 不小。402 OS 偏硬核，想學系統可以上。585 DB、572 搜索相對好搭配找工，不過 DB 的內容工作以後真用得上，別隻當水課。

同一個課號換個老師，體驗能差很多，570 的講法、作業計不計分都有過不同版本。系統課為主的課表和輕 load 的找工課表，讀下來完全是兩種路數。

## 找工

找工氛圍很濃，但投簡歷、找內推、刷題基本靠自己。學校有 career fair 和 Handshake，有人能從招聘會拿到面試，不過人在 LA 並不會多送你幾個面試。2022 年和 2025 年的 ng 行情差很多，以前那種“大廠 offer 隨便拿”的說法，放到現在不能當預期。

## 生活

LA 吃喝玩樂是真的多，但有車沒車體驗差很多。住學校附近、自己做飯，不買車也過得下去；想常跑華人區、周邊到處玩，有車方便太多。生活上限挺高，花銷也會跟著往上走。

## CPT（2026-10-11 更新）

USC 現在要求實踐訓練是項目全體學生的必修，選修實習課不夠。普通 MSCS 沒看到全體必修實習的要求，597/598 也不計入學位學分，以前那套 CPT 實習安排沒法直接照搬。
