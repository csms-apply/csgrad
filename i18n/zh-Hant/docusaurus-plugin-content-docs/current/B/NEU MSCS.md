# NEU MSCS
本項目是general mscs項目，需要和cs align 項目區分（沒有好壞之分，但是cs align 項目是給轉碼同學開的）
# 項目介紹 {#项目介绍}
neu 開設大量的cs項目，同時不同的校區也開設大量的cs項目，比如boston、sv、seattle....最近有開了一個okaland校區，風景不錯還給獎，可以衝一下。
SV的校園是隻有一層樓，兩間教室，聽起來比較寒酸，但自習的空間很多。一般想來搞research的都去boston校區，因為教授多。不過一般來neu的同學也都是為了轉碼來的，boston、sv、seattle的都有，boston開的課程比較多。seattle其次，sv的比較有限。

general的學生可以延期一學期到28個月，neu 多數課程給分比較水，比較適合找工作,比如Mobile Application 5520 ，Computer Networks 5700 David，Building Scalable Distributed System 6650 Prasad，找工時候可以選點水課

# 開設的校區 {#开设的校区}

開設 MSCS（包括常規 MSCS 和 Align 版本）的校區：

1. Boston, MA（主校區，最傳統、最全面，通常資源最豐富，適合轉Phd）
2. Seattle, WA（西雅圖校區，科技公司密集，就業機會強，偶爾有 25% 左右獎學金）
3. Silicon Valley, CA（聖何塞/硅谷校區，靠近科技巨頭）
4. Oakland, CA（奧克蘭校區，一般給比較多的獎學金，baseline 15% + merit up to 25%）
5. Arlington, VA（弗吉尼亞阿靈頓校區，靠近華盛頓DC）
6. Miami, FL（邁阿密校區，部分學期開放）
7. Vancouver, BC（加拿大溫哥華校區，國際學生熱門選擇，科技行業發達）
8. Portland, ME（緬因州波特蘭校區，有些學生反饋 $25k 固定獎）

# 找工情況和dp {#找工情况和dp}

neu 內部有個找工系統叫NUworks，可以直接在上面投簡歷，拿到面試幾率挺大, 正常來講25 summer 找工季投100份能有1個面試就不錯了，NUworks上投100份可能能有3-4個面試，coop、低workload和友好的地理位置使得neu mscs一直是找工向選校的hot choice。neu mscs 也是有一個coop的，就是可以秋季時候去full time實習，有點類似gatech mscs的coop，neu cs align 的coop次數更多，是兩個，因此上岸率更高一點。舉個例子24Fall入學的xx找25Summer實習失敗，他可以繼續找25Fall的實習(指望tt、tesla、nvidia、snowflake撈人)，結果又失敗了，可以繼續找26Spring（接著指望tt和amazon撈人）的實習，最終終於靠著刷題和跟著udemy/youtube上模仿的項目上岸了，這樣獲得實習的機會比只能Summer實習的機會大很多，但是假如他去了別的學校，summer掛了就是真的掛了，就得準備找ng了，但是眾所周知，沒有美國🇺🇸intern 找ng是地獄難度，所以這就體現出來了neu cs/is/align的coop有多麼友好了。往年還有amazon針對neu 開的coop崗位（neu cs student only），不過目前已經取消了，變成時代的眼淚了。
