# Emory MSCS

## 項目介紹 {#项目介绍}
Emory MSCS 項目由計算機科學系（隸屬 Laney 研究生院）開設，學制通常為 2 年（秋春兩個學年）。大部分學生在兩年內完成學業，背景優秀且進度快的學生有機會在 1.5 年（3 個學期）內畢業。

項目分為 CS Track 和 BMI Track。Emory 以生物化學和醫療科技見長，因此對 生物信息、生物計算、臨床技術 感興趣的同學來說是一個不錯的選擇。CS 方向的研究機會主要集中在 醫療相關的 ML/AI 和 NLP 領域。項目整體延續了 Emory 小規模、精英化培養 的特色，較低的師生比使碩士生更容易找到心儀的研究機會，並與教授建立緊密聯繫。此外，小班制教學對國內本科背景的學生較為友好，有助於平穩過渡。


## 課程介紹 {#课程介绍}
Emory MSCS 課程選擇較為受限，每學期開設的課程較少，官網列出的部分課程實際上並不提供。碩士生通常與本科生和 PhD 研究生同堂上課，整體課程壓力不大，但課程內容相對傳統，較少涉及前沿工業級項目。

CS Track 設有 Coursework、Project 和 Thesis 三種選項，但必修課僅 3-4 門，選課範圍相對有限。

## 找工情況和dp {#找工情况和dp}
Emory不算是招工氛圍濃重的學校，很多Master學生會在找工和讀博之間猶豫。Emory的Career Center和Career Fair基本沒有作用。絕大多數中國學生會把MSCS項目作為申請phd的跳板，相當部分會畢業後留在Emory讀博。

## 性價比 {#性价比}
項目學費約為每年5w美元，所有被MSCS項目錄取的學生自動獲得部分學費獎學金（30%-50%)。 亞特蘭大整體消費不高，每月房租預算可以控制在1000-2000。
相比東西海岸的學校，性價比較高。
