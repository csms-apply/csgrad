# 🇺🇸SWE找工友好型學校/項目 {#swe找工友好型学校项目}

因為筆者親臨了國內秋招和美國找實習，之前也輔導過一些學生找🇺🇸實習，以下是一些身邊的個人觀察到的找工友好型的學校/項目dp（只針對是否對找工友好，和bar 無關，同時也有考慮到樣本觀察是否足夠多，比如mit cs找工肯定很好，但我不認識幾個mit cs本，因此沒有列進去）

1. Gatech mscsga/cse: 個人觀感gatech 上岸率不錯，觀察到的mscs 的同學找工上岸率都不錯，無論是meta 還是amazon 都很多上岸的
2. stanford cs/ee：認識不少沒實習也上岸的，f，我認識的S 的同學裡面基本都能拿到nv 面試，還有朋友收到系裡群發的nv招人郵件，投遞了過去三十分鐘約面試，堪比國內約面效率。
3. Uw ee pmp/hci: 這個項目是我覺得嚴重被低估的項目，雖然在open cs上排名b-的項目，但是我覺得就業友好度可以排到A+，首先身邊的朋友在這個項目的基本沒感受到ee 和cs有什麼找工區別，很多ee pmp的基本都能拿到meta 、amazon面試，而且ee pmp可以coop，23年amazon 幾乎撈了10% 的uw ee pmp的人。並且uw ee pmp 的coop 是不延畢的（比如說是24 fall入學，可以25 年 8-11 月去實習，不延畢），非常適合找工作。可以選擇全軟課，不修硬件課。 Uw hci比較難申請，但是也可以有六個月的實習，只需要在校內修10個學分即可。
4. Ucsd：cs75和ece都比較找工友好，cs75課程難度可以選很容易的課程，找工學期不給自己上壓力。ece 有coop。同時ucsd 也是nv 的target school
5. Neu：找工友好，無論是cs align 還是mscs還是is，都可以coop，也是linkedin 的target school。
6. Cmu：身邊觀察到的dp感覺hr 不是很care 學院，只要是cmu的默認學cs，商學院的上岸大廠的也很多，ini/scs上岸率也不錯，問了朋友上岸率大概能有2/3。雪花/db等廠會在cmu 定向撈人，假如上過db課，會到時候收集簡歷約人面試，25 ini和scs ng 很多上岸db和雪花的
7. ut Austin ece/mscs：ece 就業也很友好，主要體現在可以延畢，且有coop，可以學期中全職實習，peer pressure幾乎沒有，ece ses track一屆也就不到十個人，23 fall summer 7個人 幾乎全員上岸
