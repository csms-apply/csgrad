# USC CS37：轉碼項目就讀體驗參考 {#usc-cs37转码项目就读体验参考}

USC 的 [Computer Science for Scientists and Engineers](https://www.cs.usc.edu/academic-programs/masters/scientists-and-engineers/) 面向理工背景、計算機基礎有限的申請者。下文沿用往屆學生的 CS37 稱呼，與普通 CS 碩士的 CS28 體驗分開閱讀。

## 補基礎的價值，取決於你怎麼用課程 {#补基础的价值取决于你怎么用课程}

2021 年春季入學者在臨畢業時，認可部分基礎課，但也認為選課空間和職業支持有限。2022 年秋季入學者的畢業回顧則提醒：數據庫等知識可能在工作後才顯出價值，不宜把所有能輕鬆通過的課都當作可以跳過的內容。

對於轉碼申請者，更實際的做法是先列出編程、數據結構、算法、系統和數據庫的缺口，再對應課程補齊。項目經歷應當能講清楚設計、實現和調試過程，而不只是列出課程名。

## 時間更長，也需要承擔相應成本 {#时间更长也需要承担相应成本}

2025 年的分享把較長的在校時間視為再次尋找實習的緩衝，也提到沒有企業實習時嘗試了校內研究。不過，這些都是個人路徑；帖子中的熟人就業比例不能當作整個項目的就業率，歷史上的實習次數也不是每個人的資格保證。

決定前應核對：補基礎課的先修順序、自己的最早實習時間、完整學程的學費與生活費，以及沒有 TA/RA 或實習收入時是否仍能負擔。2023 年帖子提及的 honors 和助教經歷，也不意味著達到某個 GPA 就自動有工作。
