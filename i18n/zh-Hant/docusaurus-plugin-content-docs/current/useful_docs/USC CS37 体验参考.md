# USC CS37：轉碼項目就讀體驗參考 {#usc-cs37转码项目就读体验参考}

## 項目介紹 {#项目介绍}

CS37 就是 Scientists and Engineers，專門給理工背景想轉碼的人補 CS 基礎。37 學分裡有 4 學分是 455x 編程課，第一學期必修，不算進其餘 33 個學位學分。比普通 MSCS 多花時間和學費，換來的是一條更明確的補基礎路線。不設 thesis。

## 選課和 wld {#选课和-wld}

455x 之後接 402 OS，基礎課裡還有 450 網絡或 457 計算機組成，570 算法也是必修。402、450、570 這幾門對轉碼挺有用。想做應用開發可以選 571 Web；585 DB 看著不難，內容在實際開發裡是真用得上。

課表整體可以排得比較輕，但補基礎的必修佔掉不少學分，選修沒有整個 CS 課程目錄看上去那麼自由。2021—2022 年入學時流行的那些輕 load 組合，也得看具體老師和課程版本。

## 找工和校內崗位 {#找工和校内岗位}

項目求職導向很強，海投、刷題和實習經歷比較關鍵，career fair 作用有限。除了公司實習，校內 lab 也有寫代碼的機會，RA 信息會通過學校郵件發出來。TA、RA 得有崗位才有錢，2023 年有過 honors 轉 TA 的經驗，但不是 GPA 到線就會自動給工作。

## 生活和 CPT

LA 生活挺舒服，Koreatown、華人區吃飯選擇多，週末也不愁沒地方去。住學校附近、DTLA 還是更遠的地方各有取捨，通勤和有沒有車對體驗影響很大。缺點就是貴，37 學分的學費之外，還要多扛一段時間的生活費。

截至 2026-10-11，USC 只認可全體學生必修的實踐訓練。CS37 沒看到這項畢業要求，597/598 也不計入學位學分，所以“兩次 CPT 實習”不能再當成這個項目的固定福利。
