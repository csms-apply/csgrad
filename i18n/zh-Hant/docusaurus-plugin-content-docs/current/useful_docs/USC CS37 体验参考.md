# USC CS37：轉碼項目就讀體驗參考 {#usc-cs37转码项目就读体验参考}

## 項目介紹 {#项目介绍}

Scientists and Engineers，給理工背景轉碼的人補 CS 基礎。37 學分裡面有 4 學分的 455x 編程課，第一學期必修，不算進其餘 33 個學位學分。比普通 MSCS 多花時間和學費，補基礎的路線也更明確。不設 thesis。

## 選課和 wld {#选课和-wld}

455x 後面接 402 OS，基礎要求還有 450 網絡或 457 計算機組成，570 算法也是必修。402、450、570 這幾門對轉碼比較有用。想做應用開發可以選 571 Web，585 DB 看著不難，內容在實際開發裡用得上。

整體可以選出比較輕的課表，不過補基礎的必修佔了不少學分，選修沒有整個 CS 目錄看起來那麼自由。2021—2022 年入學時流行的輕 load 組合，也要看具體老師和課程版本。

## 找工和校內崗位 {#找工和校内岗位}

求職導向挺強，海投、刷題和實習經歷比較重要，career fair 作用有限。企業實習之外，校內 lab 也有寫代碼的機會，RA 信息會通過學校郵件發出來。TA、RA 有崗位才有錢，2023 年的 honors 轉 TA 經驗不能理解成 GPA 到線就自動發工作。

## 生活和 CPT

LA 生活蠻舒服，Koreatown、華人區吃飯選擇多，週末也不缺地方去。學校附近、DTLA 和更遠的住處各有取捨，通勤和有沒有車對體驗影響很大。缺點就是貴，37 學分的學費之外還要負擔更長時間的生活費。

截至 2026-10-11，USC 只認可全體學生必修的實踐。CS37 未見這項畢業要求，597/598 不計學位，不能再把“兩次 CPT 實習”當成項目固定福利。
