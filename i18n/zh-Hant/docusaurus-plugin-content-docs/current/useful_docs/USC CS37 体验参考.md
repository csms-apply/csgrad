# USC CS37：轉碼項目就讀體驗參考 {#usc-cs37转码项目就读体验参考}

## 補基礎，先把幾門課的順序排明白 {#补基础先把几门课的顺序排明白}

CS37 的全名是 Computer Science for Scientists and Engineers，面向理工背景、CS 基礎有限的學生。37 學分裡包含第一學期要上的 CSCI 455x 編程課，它的 4 學分不計入其餘 33 個學位學分。之後有 CSCI 402 操作系統、EE 450 網絡或 EE 457 計算機組成，再加 CSCI 570 算法。對轉碼的人，這幾門課會佔掉相當一部分時間，選修空間沒有看到 CS 課程目錄時想像得那麼大。

455x 要先完成，402 再往後排。入學前能把編程練熟一點，開學後就少一項需要同時應付的事。課程通過以後，想在面試裡解釋代碼為什麼這樣寫，還需要自己補數據結構、做練習。

## 找工選課，也有值得認真上的部分 {#找工选课也有值得认真上的部分}

2021—2022 年入學批次的體驗裡，整體課業可以給求職留出時間，但具體收穫很依賴選課。CSCI 571 Web Technologies 適合缺應用項目的人；CSCI 585 Database Systems 的內容，也值得結合實際開發去學。能用數據庫做完作業，和能解釋查詢、數據組織、系統取捨，差得還挺遠。

對剛轉碼的人，可以先圍繞一個方向把項目做完整。準備 SDE，就把代碼、測試和調試過程講清楚；喜歡系統，再繼續學網絡和操作系統。每門課都淺嘗一下，最後簡歷上課號很多，面試裡還是不知道該講哪個項目。

## 多一點在校時間，也要多算一點錢 {#多一点在校时间也要多算一点钱}

較長的學程能讓補基礎、做項目和投遞分開安排。沒有企業實習時，校內實驗室也是可以嘗試的去處，編程能力可能正好能幫上科研項目。學校郵件裡的崗位信息值得看，有興趣的老師可以提前聯繫，講清楚自己做過什麼、每週能投入多少時間。

TA、RA 要有具體崗位，不能先當成學費減免寫進預算。2023 年前後的 honors、助教經驗也不是今天照著 GPA 就能兌換的路線。CS37 本身就要修更多學分，再加住宿和生活費，經濟上最好能承擔完整學程。

LA 的吃飯和週末出行選擇很多，Koreatown、華人區和校園附近的生活半徑卻不一樣。租住 DTLA、學校附近還是更遠的地方，要連著通勤一起考慮。找工忙的時候，住得方便、能穩定做飯休息，往往比周末能去多少地方更影響每天的狀態。

## CPT 按現在的規則安排 {#cpt-按现在的规则安排}

截至 2026 年 10 月 11 日，USC OIS 要求實踐是項目全體學生的必修內容，普通選修實習不符合條件。CS37 的公開課程要求沒有列出全體必修實習，ENGR 597/598 也不計學位，因此不能再把“學程長，可以做兩次 CPT 實習”當作既定優勢。
