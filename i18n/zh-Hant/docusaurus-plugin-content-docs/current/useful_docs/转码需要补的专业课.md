# 轉碼需要補的專業課 {#转码需要补的专业课}

最近有一些同學私信諮詢我轉碼/找實習的一些事情，發現他們本科期間的專業一般是數學/統計/ee等專業，然後想研究生期間轉碼。最好能拿一個CS學位(mscs、mcs... etc)。

接下來本文將從轉專業申請mscs(以UIUC本科的課表為例子)的角度來聊一下需要補的專業課。


## 語言篇 {#语言篇}
眾所周知，每一門計算機系的同學基本都會至少一門機器可以執行的語言，比如C++、C、java等等，那麼在轉碼時候，可以先去修一下C++/java的課程
java課程：CS 125 - Intro to Computer Science

## 專業課程 {#专业课程}
計算機繫有很多專業課，比如數據庫、計算機網絡、操作系統、計算機體系結構、數據結構、並行計算、軟件工程、機器學習 etc，接下來我將從申請角度聊一下哪些課是必須修且很有用的課程

一句話總結版本：數據庫+計算機網絡+操作系統+數據結構/算法課

數據結構：CS 225 - Data Structures（學完能熟練刷算法題）
數據庫：CS 411 - Database Systems(學完能熟練使用MySQL並且清楚MySQL的index等知識點或者自己從0搭建一個db)
計算機網絡：CS 438 - Communication Networks(學完能理解在瀏覽器導航一個網址背後發生了什麼)
操作系統：CS 423 - Operating Systems Design(學完能掌握進程和線程的區別，以及能熟練處理C++和內存相關的bug)

學有餘力版本：(以下為optional，有空就上，沒空就算了)
計算機體系結構：CS 233 - Computer Architecture（學完了能理解計算機CPU和其餘各個部分怎麼交互的）
軟件工程：CS 427 - Software Engineering I(能搭建一個真正上線的項目)
編譯器：CS 426 - Compiler Construction（做一個簡單的編譯器）
CS 425 - Distributed Systems（實現一個分佈式k-v存儲結構）
