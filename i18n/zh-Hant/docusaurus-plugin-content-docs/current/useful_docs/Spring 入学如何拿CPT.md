# Spring 入學如何拿CPT？ {#spring-入学如何拿cpt}

這麼做的前提得是美本，CPT的核心要求是必須完成至少一個學年（兩個學期）的全日制學習。
因此如果你申請的是一些春季入學的一年制項目，或者把Fall的offer defer 到了Spring，比如Cornell CS MENG或者Yale MSCS 1 year, 但是你是美本，
之前在美國連續讀過至少一學期（應該所有美本都滿足這個要求），然後加上在研究生學校入學的一個學期，就滿足了
一個學年（兩個學期）的要求。

需要注意的是，你的本科和碩士的 I-20 不能更換，否則無法申請 CPT。正確的做法是 將 I-20 從本科院校轉到碩士院校。但是，這會帶來一個額外的問題：I-20 轉學的要求是本科 F-1 身份結束時間與碩士 F-1 身份開始時間的間隔不能超過 5 個月。

那麼，如果你的本科在 5 月畢業，而春季入學的碩士項目在 1 月開學，間隔超過 5 個月，該怎麼辦？
解決方案是：

1. 利用 F-1 的 Grace Period（60 天寬限期），即本科畢業後，你的 F-1 身份仍然有效兩個月。

2. 在寬限期結束前啟動本科 OPT（即使之後不會使用它），OPT 最少可以持續 3 個月。

3. 這樣，你的 F-1 身份可持續到 10 月份，而 10 月到次年 1 月之間僅有 3 個月間隔，符合 I-20 轉學的要求。

## 我不想這麼折騰，還有別的方法嗎？ {#我不想这么折腾还有别的方法吗}
有。
1. 美本本科學校延畢一學期
2. 去一個便宜的學校（比如uiuc或者gt）讀一學期然後轉學
3. 去day1cpt學校讀一學期然後轉學
4. 找個unpaid公司掛靠自己的opt(opt期間也是f1身份)
