# Dartmouth CS 與 Digital Arts：就讀體驗參考 {#dartmouth-cs-与-digital-arts就读体验参考}

## 項目介紹 {#项目介绍}

普通 MSCS 和 Digital Arts 是兩條不同路徑。現在普通 MSCS 是兩年、7 個 term，可以選 coursework 或 thesis；Digital Arts 要寫論文。想學圖形、交互、動畫，CSDA 蠻有特色，純找工的話沒有那麼省心，藝術課和論文也要花時間。

## 選課和 wld {#选课和-wld}

3D Modeling 要做角色模型，Animation 做動畫短片，AR/VR 有設計和開發合作，喜歡這些方向會學得很有意思。圖形課還有不少數學和編程，並不是玩玩軟件就能過。2026–2027 的課表裡，Animation 在秋季，3D Modeling 和 Rendering Algorithms 在冬季。

2021–2023 年的 CSDA 課程選擇偏少，OS、compiler 這些基礎硬課佔了不少位置，算法課要寫數學證明。課少就很難繞開 wld 大的課，想輕鬆上課、剩下時間全刷題，沒那麼容易。

## 找工和生活

小項目沒有很濃的抱團刷題氛圍，找工信息主要靠自己找。2022 年碰上大廠 freeze，偏僻位置加上課業壓力，純找工體驗並不好。圖形方向的課程和研究更有吸引力，但不能把 CSDA 直接當成普通 MSCS 來選。

Hanover 是真小鎮，冬天冷，吃飯選擇少，住遠了又沒車會很麻煩。喜歡 hiking、ski 的人會舒服一些，喜歡熱鬧大城市的容易憋壞。夏秋景色很好，放假本科生走了以後又會很冷清，生活和紐約、波士頓完全兩種感覺。

## CPT（2026-10-11 更新）

COSC295 仍在研究生實習課程名單裡，但未找到 CS、CSDA 全體學生必修實習的要求。OVIS 目前保留課程申請路徑，需要系裡簽字說明學業關聯，拿到 CPT I-20 才能開始。不能據此保證獲批，實際辦理仍需 OVIS 確認。
