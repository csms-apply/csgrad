# Dartmouth CS 與 Digital Arts：就讀體驗參考 {#dartmouth-cs-与-digital-arts就读体验参考}

## 項目介紹 {#项目介绍}

普通 MSCS 和 Digital Arts（CSDA）是兩條不同的路。普通 MSCS 現在是兩年、7 個 term，可以選 coursework 或 thesis；Digital Arts 必須寫論文。想學圖形、交互、動畫的話，CSDA 很有特色；純衝找工就沒那麼省心，藝術課和論文都要佔不少時間。

## 選課和 wld {#选课和-wld}

3D Modeling 要做角色模型，Animation 做動畫短片，AR/VR 是設計和開發一起合作，喜歡這些方向會學得很有意思。不過圖形課裡數學和編程都不少，不是會玩幾個軟件就能過的。2026–2027 的課表裡，Animation 在秋季，3D Modeling 和 Rendering Algorithms 在冬季。

2021–2023 年 CSDA 能選的課偏少，OS、compiler 這類基礎硬課佔了不少位置，算法課還要寫數學證明。課少就很難繞開 wld 大的課，當時想輕鬆上課、剩下時間全拿去刷題，沒那麼容易。

## 找工和生活

項目小，沒有那種大家抱團刷題的氛圍，找工信息主要靠自己挖。2022 年趕上大廠 freeze，位置偏、課業壓力又大，純找工的體驗並不好。圖形方向的課程和研究才是這裡更吸引人的地方，但別把 CSDA 直接當普通 MSCS 來選。

Hanover 是真小鎮，冬天冷，吃飯選擇少，住得遠又沒車會很麻煩。喜歡 hiking、ski 的人會挺舒服，喜歡熱鬧大城市的容易憋壞。夏秋景色很好，放假本科生一走又冷清得很，生活跟紐約、波士頓完全是兩種感覺。

## CPT（2026-10-11 更新）

COSC295 還在研究生實習課程名單裡，但沒找到 CS、CSDA 全體學生必修實習的要求。OVIS 目前保留了按課程申請的路徑，需要系裡簽字說明實習和學業的關聯，拿到 CPT I-20 之後才能開始。這不代表一定能批，實際辦理還要 OVIS 確認。
