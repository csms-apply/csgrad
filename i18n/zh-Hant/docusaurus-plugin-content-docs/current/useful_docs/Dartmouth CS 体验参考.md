# Dartmouth CS 與 Digital Arts：就讀體驗參考 {#dartmouth-cs-与-digital-arts就读体验参考}

Dartmouth 的 [CS 研究生項目](https://web.cs.dartmouth.edu/graduate/overview) 包含普通計算機科學與 Digital Arts 方向。[Digital Arts 的課程說明](https://digitalarts.cs.dartmouth.edu/academics) 涉及計算機圖形、交互及藝術實踐等內容。申請前先確認自己看的是哪條培養路徑，再比較課程與導師。

## 小規模項目，需要更具體的匹配 {#小规模项目需要更具体的匹配}

一位 2021 年入學的 CSDA 學生，從第一學期一直更新到畢業後。對選校最有參考價值的線索是：課程作業佔用時間較多、可選課範圍影響學習計劃，小鎮居住和交通也會顯著影響體驗。作者對圖形與數字藝術相關訓練有肯定，同時對求職信息和社交支持提出了擔憂。後期回顧又更認可這段獨特生活經歷的價值。

因此，不宜把原帖壓縮成一句“推薦”或“不推薦”。尤其不能把一位 CSDA 學生的體驗，直接套到所有 CS 學生身上。

## 選校時具體比較什麼 {#选校时具体比较什么}

- **研究匹配**：先找仍在招學生、研究方向吻合的導師，再看項目名氣；不要依靠多年前的教師名單判斷。
- **課程安排**：把想學的內容對應到近期實際開課記錄，確認論文、項目和求職準備能否同時推進。
- **生活與預算**：看具體房源到校園的通勤，以及假期生活安排。用自己的獎學金通知計算費用，不把帖子中的獎學金比例或住宿價格當作現價。
