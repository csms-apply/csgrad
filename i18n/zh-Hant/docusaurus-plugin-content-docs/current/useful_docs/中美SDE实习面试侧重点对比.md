# 中美SDE實習面試側重點對比 {#中美sde实习面试侧重点对比}


## 美國🇺🇸： {#美国}
考察內容：
1. 運氣
2. 算法題
3. Bq
4. 項目細節

暑期實習投遞時間
一般是入學前一年的8月份到次年的3月份，流程很長，四五個月的也有(google等)，經常出現面試完等結果半個月起步😇

以上考察內容重要性依次遞減，美國SDE面試運氣和算法題佔大頭，運氣決定了能不能有HR看到簡歷撈麵試🥲，算法題熟不熟練決定了能否過關，面試算法題的難度一般跟國內持平。相比國內SDE面試，對項目細節的考察不是很多，一般是結合bq進行考察，比如"what’s your proudest project"，不會深究細問。整場面試的重點在於算法題上，一般流程是：複述題目-walk through an example- 寫代碼- 分析時間複雜度，不能讓面試冷場，需要邊寫邊說。內推可能會有幫助撈麵試（我有個小廠面試就是內推拿的面試），BQ很重要，對於有些廠（比如🍌廠）可能直接決定了能否拿到offer，可以參照youtube lp原則複習bq




## 國內 {#国内}
考察內容：
1. 實習經歷
2. 項目
3. CS基礎知識（os、計算機網絡、mysql、redis）
4. 算法題

暑期實習投遞時間
一般是當年的3-5月份😂，準備好了即可投遞，國內面試流程處理的很快，一般期望能比較快的入職（兩週內入職）

以上考察內容重要性依次遞減，但是算法題做不出來必掛。實習經歷和項目經歷會佔據面試的大半部分時間，面試輪數一般是3輪技術+1輪hr，也有可能是2輪技術面。同時面試考察技術內容比🇺🇸相比更深入，問很多業務細節。諸如如果實習經歷是在搜廣推領域，可能會問冷啟動問題、大規模數據怎麼存儲的問題、怎麼保證實時性等問題。bq等問題基本不會涉及，除非是阿里系的公司面試，HR的scope很大，能直接把候選人否掉。算法部分一般是不需要邊寫邊講，只需要確保寫出最優解，內推不會對拿面試有幫助
