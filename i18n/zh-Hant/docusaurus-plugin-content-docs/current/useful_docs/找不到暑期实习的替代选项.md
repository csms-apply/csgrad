# 25 summer找不到🇺🇸swe intern的替代選項 {#25-summer找不到swe-intern的替代选项}

如果今年沒找到美國swe暑期實習可以關注一下國內的實習機會
比如微軟中國、optiver、阿里雲、騰訊wxg、nvidia、google 上海等，這些都已經開崗了

1. 微軟：國內已經開始招聘了，按照之前輔導的dp來看，比較偏好有美國留學背景的或者國內top 學校的（華5以上的）。之前在微軟蘇州實習的同學的bg有：1. 清華本gt 碩2. 西交本科duke碩 3.上海交大本碩 4. 同濟本碩等，比較吃學歷，面試如果第一輪面試官給了hire就只有兩輪，如果不是hire就是三輪。
2. Gsoc: 谷歌辦的開源項目，認可度很高，也很卷。開的薪水很高，如果想拿美國的pay需要使用cpt，薪資篩選主要看social和pr和項目計劃書。如果不使用cpt就只能拿中國的pay。寫在簡歷上認可度很高，
3. 開源之夏：中科院舉辦的，認可度也很高，競爭沒有gsoc那麼激烈，不過也需要認真打磨項目計劃書，選誰作為這個項目的owner主要看計劃書
4. 阿里雲：阿里雲是所有大廠中幾乎開的最早的（今年不是，今年是wxg），阿里雲往年來看是春節過後不同的組比如網關組、洛shen網絡就開始招聘了，強制要求本科是985或者強211(北郵西電)，如果不是的話很難拿到offer。美國的同學們可以在中國新年過了之後關注一下boss直聘和牛客網，他們會在這些平臺上撈人，如果覺得合適會【提前】約你面試，【提前】發offer，你也可以【同時】面試多個組，然後選自己覺得最合適的組去實習。阿里雲的暑期實習return 率非常高
5. Wxg: 暑期實習輪數很多，技術棧是cpp。一面一般是四道算法題，然後過了之後每輪都會拷打項目，需要對簡歷上的每個細節都很清楚，能做對算法題只是第一步，主要是技術細節要懂要清楚。
