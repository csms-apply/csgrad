# 貢獻內容 {#贡献内容}

## CS Grad項目支持使用PR方式進行內容貢獻 {#cs-grad项目支持使用pr方式进行内容贡献}
1. 首先來到[CS Grad 項目倉庫](https://github.com/csms-apply/csgrad)，點擊fork

![](/img/fork.png)

2. 點擊Create fork，將項目fork到自己的倉庫

![](/img/createfork.png)
