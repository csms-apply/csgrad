# NYU DS

## 項目介紹 {#项目介绍}
很適合cs/ds/math本科的同學來這裡讀MS然後增強research bg然後轉phd的，可以去ins關注
nyucds，可以看到它們很重視research。不怎麼適合轉碼，適合找ds工作。
有不少在本系轉博的，找research的同學，錄取後就可以去跟教授發郵件了，很多項目summer就可以進組了



課程硬核，對數學要求比較高，因此招數學系的同學很多。來的同學基本都是為了讀博/找ds工作的，安心學兩年學到的東西基本能匹配任何一家ds崗位了。（不過在LLM橫行的年代，ds也都得會ml/dl等必備技能了），能很好的學習到當一名Data Scientist所需要的知識,career fair來的比較多的，也都是紐約金融業的公司比較多
