# CMU SE-SV

# 項目概述 {#项目概述}
跟匹茲堡本部其實挺不一樣的：校區就兩棟樓，上課和自習空間都很有限，課程也大多由幾位教授反覆講，不少課內容編排不算深入。如果你想要本部那種課程任選、教授大牛雲集，andy站你前面講課的場面，可能會有點落差。
不過這裡地理位置確實方便，硅谷的公司資源和校友網絡不少，再加上CMU這塊招牌，找實習和全職還是相對容易的。我見過許多同學都能通過內推或Career Fair，拿到灣區大公司或初創的offer。
什麼樣的人適合來呢？
1. 想快速融入硅谷，重點放在找工
2. 對課程深度和教授資歷沒那麼苛求
說實話，這裡部分課質量挺一般的，教授規模也有限，有些必修課更是讓人吐槽。如果你更在意“拿學分畢業”，而不太糾結科研或課程難度，這邊的項目比較合適。
3. 能獨立自學，或者只把它當跳板
因為選課自由度受限，很多同學會自己利用匹茲堡本部的在線課程或資料補課，真正想學系統/算法/機器學習，往往得靠自學。如果你把SE-SV當成一年的跳板，爭取實習—全職—留灣區，這還OK。

## 課程質量 {#课程质量}
這部分是我覺得最sb的地方。CMU本部的神課多半不太能直接選到（或者就算能選，也是網課），SV本地自己開的課則良莠不齊。

有些匹茲堡校區開的網課，例如Cloud Computing、CSAPP之類的，含金量還可以。
但必修的軟工課，常常由一兩個教授來回教，講法比較陳舊，做項目時不少人覺得“寫一堆文檔+presentation”意義不大，還要忍受奇怪的要求；
對於本身就有CS背景的人來說，多少會覺得給cmu 交的接近九萬刀學費白瞎了。
如果你沒拿到其他更硬核的CS碩士(mcds、msin)項目、又很想在灣區找工作，可以考慮來；如果你手裡有別的比如brown scmcs、ut ece，個人感覺那邊的性價比可能更好。
