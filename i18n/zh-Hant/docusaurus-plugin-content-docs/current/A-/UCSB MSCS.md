# UCSB MSCS

## 項目介紹 {#项目介绍}
MSCS 項目時長一般是 2 年，但最長能延期到 4 年，學校給發的 I20 上時間都體現出來,找工友好，留得青山在不怕沒柴燒，
生活非常舒適，ucsb非常美，在大海邊非常爽，陽光大沙灘。在這裡讀博或者MS會讀過非常開心的5年或者2年。

算是 UCSB MSCS 項目的小劣勢。學校臨海，風景太美了，周邊小鎮也特別靜謐，在這很難感受到那種 “卷” 的氛圍，大家都按自己節奏學習生活。碩士項目裡大部分同學都想畢業找工作，但整體刷題投簡歷的氛圍，跟 CMU NEU 那些學校比不太行，大家也很少討論這個事兒，就平常見面聊天，偶爾問問情況，所以找工作全靠自己自覺
