# Duke ECE

## 項目介紹 {#项目介绍}
Duke 一共有三個cs相關的項目，1. Mscs 2. Ece 3. Game design。其中mscs是一個偏向科研型的項目，ece是偏向轉碼+找工作的項目。

總體上來看，ece課程更SDE導向，且bar更友好（翻譯：更容易申請，並且也有很多轉碼的同學來申請，申請時候大概率會有面試，是考口語的。

ECE總共有兩個大類，一個是MS，一個是MENG👋。區別就是前者需要寫thesis，後者不需要，並且meng需要上兩門商學院的課，並且要有實習才能畢業。往年來看第一個ms的hc是100個，meng是5-10個🤣。官方回覆是說meng和ms的bar是一樣的，如果錄了ms，meng也可以錄，如果錄了meng，ms也可以錄。這倆入學後可以互相轉✅

## Pros：
1. 項目的課程質量比較好。有秋季三件套（550，551，590）和春季三件套（650，651，568），基本都是SDE相關的課。如果是轉碼且基礎相對比較薄弱的同學可以補一下基礎。春季三件套的wld相對比較大，比如ECE 651 SOFTWARE ENGINEERING，會花很多時間，但是同樣能幫忙打好基礎。
2. coop。meng可以coop 一次，有coop就是有一張復活卡，秋季招coop的公司有Tesla、snowflake、tiktok等🍾。從郵件上來看，24fall之後的meng ece都是可以coop的，秋季能有coop的學校相對較少，因此競爭少一點，上岸概率更大。
3. 可以轉碼。申請Duke ece時候會讓你填寫是想申請meng還是ms, 轉碼/cs科班同學可以選Software Development👊和Data Analytics & Machine Learning track。文書也比較好寫一點（前者寫sde文書，後者寫做科研的文書）。當然track進入學校後都可以互相轉的
4. 人相對比較少，過簡歷關相對容易。有些公司在最後發offer時候會參考一下已經招了這個學校的ng的人數，必然不可能說全都招一個學校的。因此人數少的學校在過簡歷時候會有優勢。



## Cons：
1. 貴，單學費就將近十萬刀（來源：學校官網）了。當時我申請時候看到這個學費真的嚇了一大跳，不愧是私立。
2. Wld比較大。如前文所言，春季+秋季三件套都是wld比較大的，因此可能會影響刷題時間
