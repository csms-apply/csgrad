# Columbia DS

## 項目介紹 {#项目介绍}

對於本科不是 cs，單純想通過它轉碼的同學來說，不太合適，建議考慮 CS、CE 甚至 EE 專業。它更側重於ds和ml。項目整體ds課程設置較為全面，有一個capstone project作為實操項目, 可以放在簡歷上, 但是必須修完一些課程後才能上, 所以對第一年暑假實習找工作幫助不大.選課相對自由， 本科上過的課可以申請waive， 多餘的選修可以在cs 和統計自由選課

本科不是cs想通過這個項目轉碼的請出門右轉CS CE甚至EE

## 找工
一般


整體表現較為一般。學校雖然會提供一些就業資源，比如 DSI 每週會給 DS 學生髮 DSI Opportunities 郵件，總結全職和實習崗位信息，學期中也會有公司 Resume Drops 郵件，學生簡歷能直接推到 HR/Hiring Manager 手中。DSI 還會舉辦自己的 career fair，來的公司和 DSI 關係緊密。但找工作最終還是主要依靠個人自身的實力。身邊同學的就業方向多樣，有進入大廠的，也有選擇小廠
