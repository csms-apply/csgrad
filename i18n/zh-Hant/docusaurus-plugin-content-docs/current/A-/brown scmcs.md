# Brown SCMCS



## 項目介紹 {#项目介绍}

每學期兩學分，兩門課，wld很小，可以有很多時間用來找工作/搞科研。大部分人的選課是2+2+2+2，每個學期均勻的上兩門課，這樣子wld很小，很適合刷題找工作。有辦公室，大家可以一起刷題，氛圍很好

wld小的好處是如果剛來到美國就上很多的課，還得準備刷題、bq、項目，壓力會很大。brown 避免了這個問題，每個學期只上兩門課wld極其小。

學費不便宜，兩年7w多美金，有工位（不過我覺得沒啥用，還是喜歡去圖書館）。住宿便宜，如果住學校收購的公寓，價格是900刀2b1b，1100刀2b2b，1500 Studio

這個項目每年都會被拿來和ut ece(ses), gt cse, cmu msin, columbia mscs拿來一塊對比，但是找工的情況確實有所不同，如果單純唯結果論來看，從找sde intern 結果上來看不如這幾個項目。
