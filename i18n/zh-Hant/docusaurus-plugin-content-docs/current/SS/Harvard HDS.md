# Harvard HDS


完完全全就是一個DS program, 只是必修課是在Biostatistics下開的，不會生物也能學，Capstone一般是和Harvard附屬的幾家醫院，比如Dana Farber Cancer Institute等等做一個semester long DS program

選課超級自由，MIT Harvard 其他學院的課隨便選

## 錄取bar和標準 {#录取bar和标准}
每年15-20人，陸本清北華5，美本則主要來自 UCB、UCLA、UIUC、UMich、UPenn、UChicago, UCSD這種名校和 U Toronto
1. University of Colorado Denver， economics+math本科，gpa3.99，多段證券公司實習，北大一年RA
2. Mount Holyoke College 統計本科，gpa 3.9，本校半年RA
3. uiuc統計+經濟本科，gpa4.0
4. usc本科gpa3.95, 多段ds intern
5. 多大ai本科，gpa3.9, 多段RA經歷
6. Wake Forest University本科，cs+統計本科，多段ds intern
7. 香港城市大學應用數學本科， gpa 4.01, 多段ds intern
8. uncc economics+統計本科，gpa4.0

## 找工情況 {#找工情况}
一直是100%（Intern+FT), 前幾屆去向不完全統計包括Goldman Sachs, Facebook, Verily, Wayfair, Aetna, Microsoft AI, Google, BCG 等等

1. 北外工商管理本科，2020年HDS碩士畢業，MilliporeSigma ds intern，2020年上岸Aetna ds全職，2026年轉google ds全職。

## 轉博情況 {#转博情况}
身邊讀博幾乎沒有，全是找工，但是科研資源很豐富，可以聯繫上哈佛附屬醫院相關教授做科研

科研實習機會很多，學院和波士頓的各大醫院，研究機構都有合作
