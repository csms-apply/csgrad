# CMU MSCS

# 項目介紹 {#项目介绍}
scs王牌項目，選課非常靈活，基本可以選到所有想上的cs課，整個scs所有計算機相關的課程，mscs項目隨意選且有優先權，錄取後需要上15213 csapp這門課，不過也可以不上，來美國之後再上。同學基本要麼是中國人，要麼是印度人。允許defer（23 fall offer上明確說了可以defer）。需要三個學期上九門課，其中包含至少一門 AI / Theory / System 方向的課程即可，課程還是比較很有意思，比如Deep Learning System，課程內容主要是GPU programming ，proj 是造一個簡易版本的pytorch，這種課至少我本科所在的陸本是開不出來的。這門課的評測系統也對校外的同學開放，還有一些比較出名的課比如cmu 15445(db)等，如果來的早可能碰到某github 3k star+ 大佬當你ta，當然15445也是對校外同學開放評測的， 每年的proj 都有一些變化，可以做做

# 錄取偏好 {#录取偏好}
對 GPA 要求極為嚴格，且明顯偏好美本。對於陸本申請，基本僅招收 Target School（清北 + 華五），在這範圍外就別捐申請費了，並且三維成績（GPA、GRE、TOEFL）都需極為頂。往年(24 fall)錄取率僅 5%，今年(2025)由於需要擴招以為 PhD 提供fund，錄取率提升至 10%, 但是依然很難。

2023年收到了2073份申請，錄取了107個，來了67個
