
# UIUC MCS

## 項目介紹 {#项目介绍}


UIUC 總共有兩個CS項目項目，一個是MSCS，另外一個是MCS。這兩個項目的區別是前者免學費，主要是做科研的，錄取難度極大。後者是授課型的，一般學生都去上課+找工作，不免學費，錄取難度相對MSCS較小（注：此處僅指對美本難度較小）。UIUC 在玉米地裡，房租相對便宜一點。MCS課程質量很好，有水課也有很多硬核代碼課,cs ranking排名第五✅，項目時長是3個學期，有coop，可以學期中全職實習，如果summer 給了return offer可以直接轉正，不用去coop(coop會延畢一學期)，項目很靈活。2024年開了chicago校區，錄取難度較小，因此申請者可以選擇自主申請主校區或者chicago分校區。

2023 Fall 開始，學校給予學生第三個學期 Full-Time internship，相當於 COOP，從以前的 3 個學期強制畢業到可以延到 4 個學期畢業，
