# CMU MSMITE


## 項目介紹 {#项目介绍}
項目全稱是 Master of Science in Mobile and IoT Engineering ，並不是cs tile，不過問題也不大，因為找工主要看個人經歷和簡歷匹配度。網申時候也只能填專業cs。
msmite 第一年在匹茲堡，第二年在sv，還是很不錯的，能體驗兩個不同的地方，選課很自由，可水可選硬課，給你充分的自由度去發展。同時也可以做一個學期的practicum，會和一些企業比如nasa、adobe合作，可以寫到簡歷上。
找工情況不錯，詳情參考官方報告（真實數據應該比那個好，因為ini有個傻逼的制度就是如果你上報了offer就不能改offer了，如果你收到了更好的offer也不能去，因此有的同學就等所有offer塵埃落定了再上報），Top Employers: NVIDIA, amazon, apple, tiktok

## 選課情況 {#选课情况}
22fall給MSMITE的degree specific core加入了scs學院的課：
Distributed Systems，Advanced Cloud Computing (ACC), Cloud Computing(CC)，
選這3門課再也不佔用24 units的electives額度，可以把攢下來的學分選scs別的課程（比如15445）

1. 15213：大名鼎鼎的csapp, 幾乎所有system 課程的prerequisite，可以暑假或者第一學期上，中等workload，絕大部分SDE向的同學都會選，甚至連hci的同學都得選這門課
2. 15440：Distributed Systems，找工實用，注意不要選ini學院下面的ds，那個教學質量沒有scs的ds好
3. 14776：經管水課，上課做作業就能拿A，事情多但是工作量不大。後文會給出怎麼平衡wld的課表
4. 15619：Cloud Computing:老牌神課，workload很大，評價兩極分化，lab涵蓋的技術很多，也有很多同學網上吐槽這門課就是花了很多時間和力氣最後依然拿了個proj 0分
5. 18709/15719：Advanced CC:cc的減wld版本，找工學期可以上acc而不是cc給自己更多刷題準備面試的時間
6. 10714：Deep Learning Systems：實現一個pytorch，課程很實用，如果上了這門課應該比較對口nvidia
