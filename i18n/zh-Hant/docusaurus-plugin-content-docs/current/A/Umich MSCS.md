# UMich MSCS/MSCSE

## 項目介紹 {#项目介绍}

當TA免學費+$3000/m stipend，很爽，很多umich或者密院的同學就在本校讀了，
項目比較靈活，可以一年也可以兩年/一年半，什麼時候找到ng什麼時候畢業。
400level的課實戰性都挺強的, workload不少但都很有用，年輕的lecturer通常比教授教的好很多。500level對找工作沒啥用, 但是workload一般小，可以找工學期選幾門500開頭的，
畢業需要上一門硬件課。

地理位置不好，容易抑鬱，CS課程大部分都在北校，建議有買車打算的同學前往。學校設施整體很不錯。

## MS vs MSE
UMich提供兩個CS碩士學位：**MS（科學碩士）**和**MSE（工程碩士）**。兩者僅在名稱上有所區別，學位要求完全相同：  
- 本科擁有工程學士學位（BSE）的同學可以申請MS或MSE。  
- 非工程學士學位（如BS、BA）的同學只能申請MS。

## 錄取bar和dp {#录取bar和dp}

### 針對本校生 {#针对本校生}
對於UMich本科生，推薦通過**SUGS（Sequential Undergraduate/Graduate Studies）**項目申請碩士學位：
- **項目優勢**  
  - 本科和碩士部分課程可重疊（最多15學分），節省時間與費用。
  - 通常1-1.5年可完成碩士學位。
  
- **SUGS申請要求**  
  - 累計GPA達到**3.6以上**。
  - 申請前需完成以下課程，併成績達到B+以上：
    - EECS 281  
    - EECS 270/370  
  - 至少完成4門高級CS課程（如EECS 370、EECS 376），成績達到B+以上。
  - 主修方向為DS、CS、CE、EE，或CS相關輔修。
### 針對外校生 {#针对外校生}
錄取難度較高，建議如下：
- 外校申請名額有限，錄取數量較少，大部分名額優先提供給UMich本科SUGS學生。
- 建議外校申請者具備以下條件：
  - GPA和科研表現突出。  
  - 出色的選課背景,成績，和推薦信。

不建議外校學生盲目申請，除非對UMich極其嚮往且申請條件非常優秀！！
