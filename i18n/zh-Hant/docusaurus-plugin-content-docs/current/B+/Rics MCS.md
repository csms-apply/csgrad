# Rice MCS

## 項目介紹 {#项目介绍}
MCS 項目規模這幾年有所增長，疫情期間 21Fall 一度擴招到 300 人，22Fall 恢復到 100 人以內。學位要求 30 學分 + 2 門方向課 + 必須實習（具體要求每年可能調整）。學費適中，一學期 $26,000+，最後一學期可以 part-time，按學分收費，省錢的話可以 4+4+1 模式三學期畢業（約 $61,000），也可以 3+3+3+1 四學期畢業。當然也可以兩學期速通畢業，不過一般沒人這麼幹。Rice還提供免費的英文課，就像601，或者是OISS開的免費英文課之類的

研究生可以預訂自己的座位和儲物櫃（沒錯一整年都屬於你一個人），圖書館一樓也有電腦可以隨便用，不缺座位。並且給第一年的研究生提供住宿，分為RGA、RVA和RVT，基本都能住上。也有提供免費shuttle往返於校園和宿舍。同時休斯頓是目前美國第五大城市，有很多吃的玩的，包括看NBA 火箭隊，中餐很多很實惠，華人很多。每天都有中餐外賣(十一二刀/頓)。中國城很大，好幾個街區，川菜比較多，日料韓料越南菜也很多。

經常和Rice MCS、USC CS28、UCI MCS/MSWE、DUKE MECE、NYU Tandon MSCS、NEU MSCS-General這些項目一塊比較，都比較適合找工。 paycom 會撈不少德州的學生（rice也在其中），有人說是保底廠，確實招了一些。
