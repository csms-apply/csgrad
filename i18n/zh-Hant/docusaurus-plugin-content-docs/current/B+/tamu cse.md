# TAMU CSE
## 項目綜述 {#项目综述}
**TLDR: 一句話總結，小gatech mscs**

**gatech 可以延長到三年畢業，tamu cse同樣可以**

**gt 可以coop，tamu cse同樣秋季實習**

**gatech 可以TA/RA免學費，tamu cse同樣可以TA/RA免學費**

**gatech 學費低廉，tamu也 13000 一學期**

Texas A&M University CSE下有若干項目：MCS、MSCS、Meng CE、MSCE、MSAI。這些項目的最大的特點是較為靈活便宜，下屬若干項目可以隨意轉換，且可以隨意實習、隨意調整項目時長。
- 學位靈活：典型例子是Meng CE轉MCS，以及MCS轉MSCS。只要進入了CSE部門，就可以自行選擇做科研發論文，或專攻找工。
具體操作而言，學校裡很多同學選擇中途放棄找工去做科研發論文，或者科研失敗選擇中途轉非thesis degree以開始找工作。
同時也有少量同時找工+科研的同學（雖然很難成功）。
- 學制靈活：項目學制較為靈活，可以1.5到3年畢業，因此可以有一到兩個暑假用來實習。同時還可以春秋全職coop，也可以part time校外實習。
- 經濟靈活：非thesis degree一學期大概學費13000，thesis degree學位則一般有半獎（如有有RA/TA則可以完全cover學費）。學費以外，德州物件和房租很便宜（租房比我在北京字節時候租房子便宜）。

## 課程情況 {#课程情况}
由於Texas本土文化特性，TAMU的Master學生比較受學校重視，並不是完全的現金奶牛，待遇基本和本科生、PhD持平。
但也因此，部門不太會開各種有利於找工的課程。例如軟件開發、cloud computing一類對找工有幫助的課程是極少的。
相反，學校科研氛圍極其濃厚，很多老師喜歡講授較為硬核的科研內容。系頭也很喜歡讓老師開貼近research的硬課（雖然肯定比不上CMU這類學校的硬課硬）。
這可能是一個潛在缺點，可能課程會佔用過多時間影響找工。
不過同時，這方面也可以被視為優點，因為很容易通過課程找到做research的機會，同時很多老師都非常樂意招收MS學生並接受轉PhD。

## ng找工情況： {#ng找工情况}
TAMU雖然有諸多優點，其工程學院也是全美國較有聲譽的。但是其CSE單項並不頂級，且學校本科生極多，因此對於找工並無加成，甚至可以說有些劣勢。以下是一些典型案例：
- 某四段國內實習的mcs同學（2BAT+2外企），項目期間做了兩段高質量實習（夏季+秋季），最後上岸了某FLAG公司
- 某國內工作三年的mcs同學（BAT），實習上岸亞麻，上岸黑車
- 某國內三段實習的mcs同學（1BAT+2外企），上岸Meta
- 某國內三段實習mcs的同學（1小廠+1外企+1BAT），最後上岸某中廠
- 某一年國內小廠實習經驗的mcs同學，上岸TikTok
- 印度本科，Qualcomm印度三年全職，上岸美國Qualcomm intern
- 印度本科，多段web developer 實習，上岸小廠ds

以上是一些比較好的案例，但是對於運氣不好且經驗不足的同學(沒有很多工業界經驗)，由於TAMU的本身沒有加成，普遍有找工困難的問題（沒有面試）。

- IIT (BHU) 電子工程本科，讀 MSCS 前有 Wells Fargo 兩年全職，2025 年畢業時上岸 Amazon Applied Scientist I 全職。
