# Cornell Tech CM

來勸退了，這個項目比地裡說的其實差很多。

真正的宇宙中心，雖然學校在小島上雖然出島不太方便，但學校旁邊的地鐵基本可以30min內直達紐約任何主流景點和娛樂場所。有著可能是全美最貴的CS相關的總開銷，不拿獎學金的話兩年總開銷估計22w刀起步。學校很小，科研競爭相比於公立大校小很多，不過讀博情況不清楚。同學基本上都是住宿舍，所以校園生活還可以，可以和大家打打桌遊打打狼人殺都很方便。找工情況一般，基本不是任何大廠的Target School。同學基本也都是正常人，大家的背景也都很有意思。

評級B+的原因是因為
1. 價格貴（22w+刀），即便給獎也不會cover多少，唯一知道的一位給了一半獎學金的同學是美國綠卡，中國國籍同學基本拿不到這麼高的獎
2. 找工情況並不理想，多位24 fall 入學的同學均反饋找工情況很不樂觀
3. 很難靠cornell 的牌子拿到更多的面試

## 關於住宿 {#关于住宿}
如果不挑房型的話大部分同學應該都能排到宿舍。排宿舍優先級應該是：二年級>MBA>一年級。根據觀察來看，新入學的同學如果想一個人住可以優先排1b1b和住正常戶型的Studio，因為1b1b排不上貌似會優先給Studio，如果排上了1b1b理論上也可以在內部和其他換房間。正常戶型Studio一層大概有6間，一共23層住人的樓，所以Studio一般都能排上。還有兩種奇怪佈局的Studio，一層各一間，所以很難排，能不能排上全看運氣，個人感覺沒必要了。選宿舍可以選五個志願，優先級排序，建議可以選一個3b2b/3b1b作為保底，因為確實可能運氣不好完全排不到宿舍。CT的宿舍客廳不允許住人，1b1b 3k，Studio 2.3k一個月左右，2b 2k左右，3b 1.8k左右，在曼哈頓附近絕對是性價比極高的。不過我個人不推薦3b，因為3b的臥室真的特別小，就性價比和舒適度來說，我個人推薦：1b1b（3k在曼哈頓旁邊的1b性價比很高了，雖然3k一個月也很貴）>正常房型Studio>其他Studio>2b1b>2b2b>3b。大樓有公共洗衣房和烘乾機，暫時沒見過烘鞋的，也有免費健身房，但是可以30刀每月在隔壁50米體育館開一個會員，可以游泳據說設施特別齊全。不住學校宿舍的朋友也有住島另外一邊Octgan的（應該沒拼錯），島上有免費的環島巴士，不過來上課的話走路20分鐘沒那麼方便，可以考慮買scooter。個人感覺如果不是沒排到宿舍的話，沒必要住其他地方了，因為平時約個牌局或者大家一起吃飯娛樂的話，基本上所有人都住宿舍，娛樂活動也能在宿舍開展。

## 選課情況 {#选课情况}
上學期能選的課基本上都是MLE方向，很少SDE方向，所以其實CM不太適合轉碼，更適合有CS基礎的朋友。
1. Applied ML：有期中沒期末，有Project，有Final Project。難度2/5，上過吳恩達的ML課基本上可以無痛完成這門課，workload 2/5，作業和項目難度都不大。基本上大家都會報，可以作為必選項，很好拿A

2. MLE：有期中沒期末，有Project。難度4/5，手搓一個小的pytorch，據說是可以寫進簡歷的項目，後期有點太深入對於非MLE選手屬實痛苦，期中考試會curve，不過個人感覺挺難的。workload 2/5-5/5，Project屬於想水很好水過去，但是認真學也很花時間的那種。報的人也很多，但考慮確實比較難，酌情考慮吧。

3. Applied Algo：沒期中沒期末，純五個Assignment。難度2/5-4/5，因為沒有考試，所以想怎麼完成這個課純看個人意願，後面有幾個部分的作業認真寫還是有些難度的。workload 2/5-4/5，純看你想怎麼通過這個課了，要水過去的話這是上學期最水的課，如果認真學的話我個人覺得應該比MLE簡單一些。但是這個課講的算法和Leetcode基本不太沾邊，看起來有很多奇奇怪怪的算法，似乎不太實用，不過拿A不難，報的人也很多。

4. HCI：沒期中沒期末，每節課都有Homework，有日常Project。是UI/UX的課程，零基礎也沒啥問題，如果稍微有一些前端或者UI基礎這個課基本沒有任何難度。這個課的課堂是純Team Work作業，老師不上課，課程是提前錄製需要在課前看完（當然不看完其實也完全不影響上課）。難度2/5，老師很寬容，作業基本上只要做了就是滿分，對於0 UI/UX基礎也是如此。lz之前有UI/UX和前端經驗，能感覺到老師的課程和作業設計挺用心的，如果想學的話可以學到一些東西（不是針對SDE方向，而是PM和UI/UX方向）。workload 2.5/5，每週定期2h的Team work作業，Project兩人小組一般4-6小時以內能搞定，一學期5個左右Project。一般只要出勤了上課正常完成作業都有A。

5. 心理學是CM必修，據說很折磨人，每次上課都有考勤和quiz，並且聽身邊的人說給分很低，不是CM專業的就不要湊這個熱鬧了。

6. Business Foundation一學分，非MBA學生想上MBA的課程需要學這個，據說要求很嚴，身邊選了這個課的朋友好像都退課了，如果本科上過商科通識課可以waive這門，直接選MBA的課。

## 找工
CM 66人，HT和UT大概都不到20個人，其他專業沒了解過。觀感中國人大概30%，印度人30%，其他40%，人種還算多樣，不會出現全是中國人的那種感覺。

找工情況僅限於中國大陸 25 Summer Intern，對25NG和其他地區完全不瞭解。截止2025年3月16日，25 Summer Intern中國人上岸的估計最多十個，佔比中國人裡的30%到40%左右，因為樣本量太少了，所以主要還是看個人實力。不過和官方90%的找工差了幾百個量級。CT紐約的Career Fair幾乎是沒有的，當然可以去伊薩卡參加Cornell本部的CF，不過基本也沒有任何大公司，總之Career Fair基本就是擺設。紐約的地理位置也沒帶來什麼找工的優點，反正這年頭大家都是online面試。

CT拿Cornell的文憑，所以大致可以看做Cornell。好像對於大科技廠來說Cornell不算target school，身邊認識的朋友反正Meta、Google、Apple、Uber等等知名大廠基本上寥寥無幾。大金主Bloomberg 倒是會給面試機會，負責我們學校的HR也還算積極，相比於見過的部分dp動輒ghost兩三個月，一般CT的next step都能在7-30天完成。十月份從學校收了一波簡歷，還會來學校onsite 面試，不過25 Summer至今也沒見過國人拿Intern offer的，相比paycom撈rice的程度來比還是差很多。

還在找Summer Intern的大家應該都在指著今年Amazon大放水了，但是這和CT也沒啥關係了lol。總之學校基本提供不了什麼找工的幫助，Cornell的Title在招工市場上可能不如一些理工強校。
