# NWU MSCS

## 項目評價 {#项目评价}
Evanston風景美，治安好，學校有錢，設施也不錯，密歇根湖很漂亮很好看。

項目時長4個quarter/一年半。有三個track：thesis，project和course。thesis和project需要自己找一個導師寫paper/做項目，好處是最多可以延兩學期畢業，也就是6個quarter/兩年，延的這兩個學期只需要選一門placeholder課，價格100刀，整體上來看不便宜

缺點就是學費很貴，總學費大概至少7.6W+

## 錄取bar 和dp {#录取bar-和dp}
美本高gpa保底，中外合辦疑似沒有4年美本那麼有說服力。官方郵件明確說了喜歡招高gpa+ 有很好的research背景的同學，隻字未提internship，
因此想來nwu mscs的還是推薦做research拿高分比較好

1. NWU CS本科gpa3.95
2. uci cs本科gpa3.85,uci+港中文一年半RA
3. University of Rochester cs本科gpa3.6
4. 北京工業大學信管本科，gpa3.92
