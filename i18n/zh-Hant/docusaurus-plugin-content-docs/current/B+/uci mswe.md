
# UCI MSWE

## 項目介紹： {#项目介绍}
項目全稱master of software engineering，從官網上就能看出來是一個非常找工導向的項目。地處爾灣富人區，非常安全+安逸👏。是一個典型的轉碼項目，招收了不少轉碼同學。uci一共有三個計算機相關項目，分別是mcs, mswe, netsys。其中mcs偏向計算機科班申請者，mswe偏向轉專業申請者。兩個項目最主要的區別就是workload，mcs wld蠻大的，mswe沒有那麼大的壓力，可以有很多時間刷題做項目，且mswe有保底實習

## Bar和先修課： {#bar和先修课}
明說的先修課只有一門數據結構✅。（Knowledge of data structures, such as lists, arrays, trees, and associative arrays.）和兩門編程語言，要求比較容易滿足。gpa 3.7以上往年看就非常有機會。

## 優勢： {#优势}
入學就送leetcode美區會員🤩，uci郵箱使用udemy免費。項目工作人員幫忙改簡歷非常上心，
Wld很小，學費6w刀。個人認為也適合cs科班，require 實習，如果找不到實習，項目會給幫忙找一個。（但是據說質量沒有那麼的高）。房租一個月不到900還包水電

## 簡歷關： {#简历关}
通過簡歷篩選應該沒問題。三年前入學的學長們(21fall) 實習情況很好，有不少人去了谷歌、Meta、亞馬遜等大公司，尤其是Meta，四五十個人中有四五個去了，比例很高。之後情況風雲突變，三道題上岸amazon的盛世不復存在了，，但是問到的uci 學長也有幾家不錯公司的面試機會。

上一屆的同學建議暑假找老師或合作小公司做項目和實習，最後一個學期的capstone也能補充簡歷的不足。
