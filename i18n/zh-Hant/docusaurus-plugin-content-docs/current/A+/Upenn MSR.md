# Upenn MSR

## 項目介紹 {#项目介绍}
來之前對這個program的想像是“很硬核、很卷、實驗室捲到飛起”……
結果來了之後才發現：ROBO真的是全美最自由、最能“do yourself”的機器人碩士項目之一！ 並且也可以dual mcit/mcis等

一句話總結我的最大Takeaway
“高度自由 = 無限可能，也意味著你必須非常清楚自己想要什麼”
沒有既定路線，想學什麼就學什麼，想做哪個方向的研究就去找對應大牛，真的可以完全按照自己的興趣和職業規劃來塑造這份碩士經歷。

費城消費：中等偏高，低於紐約/灣區，但高於休斯敦/中部城市。
房租（合租單間）：$900-1400/月；吃飯自己做+偶爾外食：$500-800/月。平時作息：
不做research：週一到週五上課+寫作業，效率高的話還有很多空閒時間參加各種event。
做research：上課+作業+lab，一週research大概10-20小時，時間會比較滿。
但Penn Engineering每週幾乎都有各種research seminar，對方向感興趣的同學可以把空閒時間塞滿～

## 錄取bar 和dp {#录取bar-和dp}
每年秋季入學新生大約30人左右，中國人通常6-8人。
背景非常多樣：有國內頂尖本科直申的，有美本轉過來的，也有工作幾年再來深造的。
錄取確實competitive，但有個神奇的“後門”——如果你先進Penn Engineering其他項目（比如EE,SE），對robotics真感興趣，轉ROBO其實相對容易很多，很多學長姐都是這麼操作的。

1. umass 機械工程本科，有多段機器人相關實習
2.  Worcester Polytechnic Institute 機器人本科gpa3.95
3. iit 自動化本科gpa 9.04/10, 三年全職經驗
4. 印度本科gpa 8.72/10
5. nyu cs+ds gpa 3.87/4
## 項目找工 {#项目找工}

最多的方向還是Computer Vision + Coding相關崗位（FAANG/大廠AI部門、自動駕駛、機器人公司等），也有不少去Control、Planning、Manipulation方向的。

公司類型：Tesla、Waymo、Aurora、Boston Dynamics、Amazon Robotics、Apple、Meta Reality Labs、Google X 等，title多為Robotics Engineer、Perception Engineer、Software Engineer - Robotics等。

工資水平（參考前幾年數據）：起薪一般在15-22萬美元之間（base + bonus + RSU），看公司和地點差異較大。

1. upenn ee本科，上岸小廠硬件實習
2. upenn ce本科，上岸amazon 硬件實習
3. iit 自動化本科gpa 9.04/10, 三年全職經驗，上岸amazon ds
4. 印度本科gpa 8.72/10，多段實習，上岸sf 小廠cv engineer
4. upenn ee 本科，有實習經歷，上岸space x sde test intern
5. nyu cs+ds 本科，有小廠ds intern，上岸amazon ds 實習
6. University of Houston cs本科，入學前有 Kyndryl 實習和近兩年 Software Developer 全職，碩士期間在 PCASO Lab 做兼職 RA（2025年起）。

## 大牛教授

GRASP lab全美數一數二， 
隨便舉幾個響噹噹的名字：
1. Vijay Kumar（無人機、空中機器人之神）
2. George Pappas（控制與優化大神）
3. Mark Yim（模塊化機器人傳奇）
4. Kostas Daniilidis（計算機視覺+機器人感知）
5. Jianbo Shi（CV經典人物）

這些教授手下幾乎每年都有很多master/PhD在做research，機會非常多。
只要你方向匹配、主動溝通，找到帶你的PhD帶你入lab的概率很高。
