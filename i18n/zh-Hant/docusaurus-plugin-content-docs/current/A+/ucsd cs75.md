# UCSD CS75

## 項目介紹 {#项目介绍}


UCSD的CS 75是非常大眾情人校的一個項目，在UC裡面應該屬於CS就業友好度前二的項目☺️.

UCB只有一年制項目MENG，UCLA的MSCS錄取過難，且偏向科研，對就業並不友好，因此對就業同學來說sd 或許更好。

從2025年開始，ucsd cs75提供coop，地理位置好+學費便宜+當ta減免一半學費+有coop，基本接近六邊形項目了

![cs75coop](/img/cs75coop.png)

項目wld可以極其小✌️，認識的學長說，可以做到不去上課然後拿GPA 4.0（通過合理選課規避wld大的課程，比如選擇CSE 258 - Recommender Systems and Web Mining這樣的課程就wld很低）。當然，對於追求課程質量的同學來說，也可以選擇喜歡的coding課程。（比如CSE 210 - Principles of Software Engineering，做一個全棧項目）

UCSD位於聖地亞哥，旁邊就是大海，坐擁海景房❤️。同時學校宿舍極其便宜且質量極其好，因此成為眾多北美CS申請者的必申項目。和這個項目一起比較的經常還有CMU MSIN、UIUC MCS、UT AUSTIN SES、GT CSE


## 項目錄取偏好和dp {#项目录取偏好和dp}
一句話總結：錄取非常玄學，有被stanford ee錄取的同學被rej。也有不少雙非的同學ad。

但是從24 fall offer holder統計群的結果來看，3.9+的gpa佔據了offer holder群的一半人數。可以認為高GPA是被錄取的必要不充分條件。剩下的科研、實習等等因素都看不出來和錄取結果有明顯的關聯。文書也看不出來有什麼偏好，樓主寫的是找工作找工作也被ad，有朋友👬🏻寫的全科研轉phd方向被ad。【吹風機理論】：ucsd有著數量可觀的dp表示錄取並不是跟申請人的三維、實習、科研錄取有關係，單純隨機，有很多三維很好的大佬最後直接被rej。（推測是沒看材料直接拒了）
