# 項目介紹 {#项目介绍}
ucla牌子大，在國內的話很認可。 ucla ms的class size 很小，可能也就30-40人，ucla mscs是一個研究型的項目，課程設置沒有很多方便找工的課程，而且比較偏向ai，如果你想上csapp或者storage或者os 請移步cmu，ucla 沒有提供過任何一節grad-level的OS和Database課程。 lab 對ms比較友好，教授也歡迎做科研，如果進了lab 可以選一些水課然後全力搞科研爭取return phd。

ucla校內食堂真的很好吃，和本科生買swipe吃飯的話8刀吃到撐，中餐亞洲菜美洲菜都有。而且la 附近很繁華，westwood最近還又開了鮮芋仙。有時間還可以去南邊sawtelle，有很好吃的鐵板燒，蘸面，適合想吃日料的人

# 生活和治安
洛杉磯生活很貴，而且UCLA毗鄰著名富人區比佛利山莊，房租應該是全美最高的幾個區之一。好在UCLA是公立校，學費相對便宜。學校周邊生活很方便，步行範圍內就有好幾家超市。去年附近的大華開了，也在步行/公交範圍內。開車10分鐘就是小大阪，很多日式美食。中餐也很多。而且加州的氣候很好，四季如春，陽光充足。
