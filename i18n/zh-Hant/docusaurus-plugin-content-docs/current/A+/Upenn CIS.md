# Upenn CIS

## 項目介紹 {#项目介绍}

實際上就是 CS 專業，Master 需要完成 10 門課。常見的畢業節奏有：

兩年制（3-3-2-2）
一年半制（3-3-4）
學生可以選擇 course track 或 thesis track，找工作和申請 PhD 都比較靈活。學費 如果是 full-time，每學期約 $26,000，但如果研二課少可能會低一些。

大藤title很香，bar 對陸本的標準可以上升到SS，對美本應該在S，但是找工確實對標不了stanford 或者cmu scs這樣的

## 課程體驗 {#课程体验}
節奏快、workload 大、沒有水課。 workload 是本科的兩倍。特別是 系統類課程，
幾乎每個組員都會在圖書館泡好幾天，寫 project 寫到半夜是常態。
比如 CIS 5050 Software System 這門課，需要 搭建一個類似 Gmail 的分佈式郵件系統，整個學期都在和各種 併發、同步、負載均衡 問題debug。
CIS 5530 Networked System 需要實現 Layer 3 路由協議 + Layer 7 的分佈式搜索引擎，
每次 debug 都和os較勁。CIS 5550 Internet and Web System 是 Penn 最難的課之一，
是 模擬 Google Search Engine，這已經不只是個大作業，很hardcore可以放到簡歷上
