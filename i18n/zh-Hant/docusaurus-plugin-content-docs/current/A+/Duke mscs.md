# Duke MSCS


## 項目介紹 {#项目介绍}
CS和ECE兩個項目分工比較明確：CS負責research，ECE負責engineering，不過這是不準確的，mscs也有很多同學去工業界，並且找的placement 都很好。
mscs 選課很自由，十門課畢業，如果選project或thesis畢業只需要四門CS課號的課，如果course only需要上六門CS課。
杜克CS還有一門專門刷題面試的課，由工業界的人來講課帶你刷leetcode，如果想多選一點找工有關的課也可以多關注一下ece那邊的課

OS / Network / Algorithm / Web Full Stack / Distributed System / Compiler / Architecture / Security 這些該開的課都有開到
項目時間正常的話是2年，一般課程數量是3-3-3-1，前三個學期上多少課都一樣學費，最後一個學期上幾節交幾節的學費

## RA和轉博 {#ra和转博}
基本上只要找到教授願意讓你進組就有戲，CS系裡的大多數教授每年都在從mscs項目裡招新人進組,
老師點頭就能轉phd，身邊數量可觀的dp都轉了duke cs phd

duke mscs本身是研究型項目，由於其小而精的特點，在research進組機會，
和轉博友好程度上是優於ucsd cs75和gatech mscs等公立大項目的
（from 22fall已經轉博成功的學長，他當時有gatech mscs和cornell本校區cs meng的offer，他的女朋友去了cs75，反映人多內捲，讀博向的大多數都放棄了）。
同時duke mscs的兩年明確可以算在博士時間裡，因此碩博連讀4-5年非常划算。

## 課程測評 {#课程测评}

1. CPS 510 Operating System
教授：Matthew Lentz（研究生級別，偏抽象）/ Danyang Zhuo（本科 OS，講解更清晰）
課程內容：跟著 UW CSE 451 講 OSTEP（x86），作業跟 MIT 6.828 走（xv6 RISC-V），兩者之間有 gap，需要自學填補。
作業：每次都給 grading script，保證全部通過再交就是滿分；項目自主選題，難度隨機。
考試：可帶 A4 紙 cheatsheet（雙面），多為簡答題，不考代碼。
總體評價：如果本科沒上過 OS，跟課難度較大，需課外深挖。努力肝一學期收穫很大。

2. CPS 514 Advanced Computer Networks（ECE 558）
教授：Bruce Maggs / Xiaowei Yang
課程內容：前半部分是傳統 networks，後半部分涉及 distributed system，知識點很多。
作業：可以去 OH 狂問問題，Bruce 會直接給答案，考試答對率大幅提升。
考試：選擇題+2/-2 分機制，答錯扣分多，要非常小心，考試內容難以預測。
項目：給了一堆 past projects，可以自由發揮，學期 coding 量有限，更多靠自學。
總體評價：教授懂得很多但講課隨性，知識點龐雜，複習量大，考試壓力高。

3. CPS 590 Advanced Web App Development（Dennis Quan）
教授：Dennis Quan（強烈推薦，業界經驗豐富）
課程內容：
TypeScript
JS 核心概念（closure, scoping, promise）
Vue + Express + MongoDB + Socket.io
自動化測試（Playwright）
負載均衡（nginx），CI/CD（GitLab），Docker，TLS
身份驗證（authentication, authorization, Cookie, Session）
作業：5 個 assignment，難度循序漸進。
考試：每週 quiz，後期不簡單，需跟進學習。
項目：Final project 方向明確，可選 4 個類型，能完整串起課程所學。
總體評價：邏輯清晰，接軌業界，Dennis 講課能力極強，值得一上。

4. CPS 512 Distributed Systems
教授：Danyang Zhuo
課程內容：每節課都需要讀 paper 並寫 response，課堂內容與 paper 相關。
項目：需自己實現一個分佈式系統。
總體評價：研究導向，適合想深入學習分佈式系統的同學。
