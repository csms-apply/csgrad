# CMU MSR

## 項目介紹 {#项目介绍}
可以當成phd來申請，MSR 是research導向的兩年制項目，一共是168學分，一半上課一半研究，項目的初衷是培養學生做科研，轉phd，
要求每個學生跟著導師做thesis，和phd要求相同，不過轉本校phd 需要重新申請，且不能保證是否跟著同一個老師，有點尷尬

全獎也是不準確的，主要看你和導師約的面試時候的面試表現和你對這個領域熟不熟悉，還有配套的工具鏈的熟悉程度，有可能只cover一些，甚至找不到導師都有可能

## 錄取dp {#录取dp}
1. CMU ME本科，兩篇pub
2. 印度同學本科gpa9.12/10, toefl 115, 有微軟和aws全職經歷
3. 重慶大學ME本科 gpa3.84，在epfl當過RA
4. CMU ECE本科，有META intern 和小廠intern, 一篇pub
5. 西交利物浦本科，申請時候一篇Pub,在CMU intern過半年 
6. 南方科技大學ME本科，gpa3.94,申請時候一篇ICRA,在MIT 交換過
7. cornell cs本科，四年全職經歷，後成功轉CMU MSR phd
8. ucb eecs本科gpa3.86，兩年RA，四篇pub
## 優點 {#优点}
1. 兩年時長，苟著能多一條命，也能多抽一次h1b
2. phd申請不利可以來這裡苟兩年重新申請
## 缺點 {#缺点}

如果本著找工來這個項目，找到實習了也得需要老師同意才能去intern，老闆也有可能不放人

也有uci cs本科、2023–2025讀MSR的同學，2024和2025年暑假去NASA JPL做Robotics Perception Engineer實習。
