## 課程情況 {#课程情况}
UT 的 MSCS 項目算是標準 CS Master，和 PhD 共享不少課程，所以偏研究方向的課會多一些，有些課的 project 甚至是按照發表 paper 的標準來要求的。項目分為 coursework 和 thesis 兩個 track，兩個選項都需要修 30 個學分，如果選擇 thesis，會有 6 個學分是寫論文，相當於少修 2 門課。無論哪個 track，都需要在 theory、system、application 這三個方向上至少修一門課。

選課上，UT CS 的本科課開的非常全，質量很高，很多 Master 同學第一學期會選本科的 Web Dev、Mobile Dev 之類的課，workload 小一點，學的東西也比較實用。不過研究生的課程大部分 workload 都不小，尤其是 偏研究的課程，有的課會要求每節課都讀論文，還有一些是 算法純理論課，基本不寫代碼，就靠推公式和證明。選課優先級上，二年級的 Master 學長學姐更高，所以新生搶課會稍微麻煩點。

具體來說，CS 課程涵蓋面很廣，喜歡系統的可以選 操作系統、網絡、分佈式系統，喜歡 AI/ML 的可以選 NLP、強化學習、深度學習，偏 Web 的話也有 Web Dev、Cloud Computing 之類的課。大部分課程的 workload 都不算輕，比如：

1. NLP 課（Natural Language Processing）：project 需要按照 ACL/NIPS 論文格式 來寫，作業裡有 HMM/CRF 之類的東西，還是有挑戰的。
2. 算法課：不寫代碼，純推理論，講 NP 完備、近似算法、斐波那契堆，作業全是證明題，適合喜歡理論的同學。
3. Web 開發：如果你對 Web 開發感興趣，可以修 Modern Web Application 這門課，很多同學修完以後去找 Full Stack 方向的工作。
4. CS 裡的 seminar 課：每節課都要讀論文，適合想要深入某個領域的同學，比如系統、AI、數據庫等方向




## 生活體驗 {#生活体验}

Austin 真的很熱，九月中旬的時候，下午五六點還能有 30 多度，所以出門一定要防曬。不過好處是冬天不會太冷，聽說最冷也就是零度以上，不像東海岸或者中西部那種暴風雪天氣。
生活上，Austin 該有的都有，生活用品在 Walmart、HEB、大華 都能買到，物價相對還行。租房的話，Far West 是中國學生的主要聚集地，房租 600-800 刀左右；West Campus 主要是本科生，價格稍貴 800-1000，但距離學校更近，騎車 10 分鐘就能到 CS 樓，不用等校車，體驗很好。

社交方面，UT 其實有很多 International Student Activities，但大部分 CS 研究生都忙著刷題找工作，真正去參加的並不多。CS 這邊 networking 的機會也不少，每年都有不少大公司來校招，比如 Google、Apple、Microsoft、Bloomberg、Goldman Sachs 都會舉辦專場活動。另外，UT 還有一個 Friends of Computer Science (FoCS) 項目，基本上每天都會有公司來，走進系樓就能看到一群人排隊投簡歷
