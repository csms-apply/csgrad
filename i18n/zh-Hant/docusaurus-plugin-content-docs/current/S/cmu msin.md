# CMU MSIN

## 項目介紹 {#项目介绍}
ini學院下面旗艦就業項目，可以拼出來跟cmu mscs差不多的課表，基本是🇺🇸cs碩士找工就業項陸本申請的天花板，項目硬核，課程proj 有深度，往年就業placement出路很好(具體參考後文)。如果決定去的話暑假會被要求上一門cmu 15213(csapp)，這門課是很多課程的先修課。不過也可以不修，來了匹茲堡再修。如果覺得自己基礎比較好或者本科學過csapp,甚至可以不上這門課，cmu不太會卡graduate的prerequsite。基本一個cs人想選的cs課程(ml、storage、acc... )都能修到, 如果有打算想上分佈式系統/os/storage三件套的話，這個項目就只比mscs多兩門14水課(business和security), 堪比小mscs

## 2024 Fall 入學體驗：系統課很香，課表別排太滿 {#2024-fall-入学体验系统课很香课表别排太满}

### 喜歡系統的人，有很多課會捨不得放 {#喜欢系统的人有很多课会舍不得放}

MSIN 的 24 units Systems Core 很適合對底層感興趣的人：數據庫、存儲、操作系統可以按興趣選，再搭配分佈式系統。2026–2027 課程表仍保留了這些選擇。14-513 的系統基礎要儘早補好，後面的課會默認你能讀 C 代碼、理解內存，也願意花時間定位 bug。

挑課可以從想做的東西出發。15-645 數據庫會接觸存儲、索引、查詢執行和併發控制，適合想弄清數據庫內部怎麼工作的人；15-605 OS 則要做好長期投入的準備。它的選課會看系統課基礎，候補也不是先到先得，先修過一門紮實的系統選修再來會更合適。不要因為註冊系統沒攔住，就把基礎已經準備好了當成默認條件。

### 重項目課要給找工讓出空間 {#重项目课要给找工让出空间}

2024–2025 的修課體驗中，15-619 雲計算很有代表性：團隊部署服務，在預算限制內提高吞吐量。這樣的項目既要寫代碼，也要協調隊友、做壓測和排查性能問題。只看學分數，很容易低估它要佔多少時間。

比較舒服的排法，是先把三學期想上的重課攤開，再放進招聘和麵試安排。某學期已經決定認真做 OS，就不要順手把其他最想上的大項目課也全塞進去。每門課都沾一點，往往不如留出整塊時間把一門做明白。求職時也更容易講清自己為什麼這樣設計、遇到過什麼問題，而不是隻在簡歷上列課程名。

### 招聘活動要去，生活也別隻剩找工 {#招聘活动要去生活也别只剩找工}

2024 Fall 這一屆的經驗裡，企業專場、技術分享和校友聯繫都值得花時間。有些 tech talk 會收簡歷，現場聊過自己做的項目，也比只留下姓名更有話可說。準備一個短版本的項目介紹就夠了：負責了什麼、怎麼驗證結果、還有哪裡沒做好。

匹茲堡的日常可以圍繞學校和公交展開，不一定要買車。生活節奏沒紐約、西雅圖那麼熱鬧，對想專心上課的人倒是省事。真正容易累的是課業和求職疊在一起，還總能聽到別人又拿了面試；給自己留出做飯、運動和不聊找工的時間，會更容易把這一年半走完。

### 實習政策更新：2026-10-11 {#实习政策更新2026-10-11}

當前 Standard 和 Advanced 的實習都非畢業必修，最新 MS38 手冊明確標為可選的 3-unit 實習；舊 Applied 選項的必修條款不能套用到現在的項目。CMU OIE 自 2026-08-27 按全體學生畢業必需條件授權 CPT，因此普通 MSIN 選修實習目前不構成 CPT 路徑，在美實習需另獲適用工作授權。
