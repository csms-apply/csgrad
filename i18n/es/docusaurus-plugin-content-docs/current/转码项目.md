# Programas para cambiarse a CS

Los programas para cambiarse a CS se dividen en programas sin ninguna base (sin haber tomado ningún curso prerrequisito de CS) y programas con base parcial (con algunos prerrequisitos de CS ya cursados). Si vienes de economía, negocios o biología y no has tomado prerrequisitos como Data Structures, Computer Organization, Operating Systems, etc.,
puedes consultar [Cursos prerrequisito para cambiarse a CS](useful_docs/转码需要补的专业课.md) para planificar tus cursos.

## Cambio a CS sin ninguna base


1. NEU CS Align
2. [UPenn MAS-CS (antes MCIT)](A/Upenn%20MCIT.md) (prefiere GPA alto de universidades de prestigio; un GPA 3.9+ es relativamente seguro)
3. [UChicago MPCS](A-/uchicago%20mpcs.md)
4. USC CS37
5. NEU ISB
6. [UIUC MSIM](B-/UIUC%20MSIM.md)
7. Columbia CS Bridge
8. NYU Tandon MSCS Bridge
9. [JHU MSECS](A-/jhu%20msecs.md)
10. CMU MITS


## Requiere algunos cursos prerrequisito
1. [Duke ECE](A-/duke%20ece.md)
2. Duke Game Design
3. [Columbia MSCS](A/columbia%20mscs.md)
4. [Columbia EE](B+/Columbia%20ee.md)
5. [CMU MSIN](S/cmu%20msin.md) (hay casos anteriores de estudiantes con pregrado de 5 años en Medicina Clínica que completaron los prerrequisitos y se cambiaron a CS, además de muchos admitidos de EE/IS/Cybersecurity)
6. [CMU MISM](B+/cmu%20mism.md)
7. [Emory MSCS](B/Emory%20MSCS.md)
