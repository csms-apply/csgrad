# Programas de MSCS en línea

Gatech OMSCS — matrícula muy económica, tasa de aceptación muy alta (cerca de 85%+), buena opción para quienes se cambian a CS

UIUC OMSCS

UT Austin OMSCS

Stanford OMSCS (se dice que tiene la misma exigencia de admisión que el MSCS presencial; recomendado para solicitantes locales; el diploma es idéntico)

Purdue OMSCS

JHU OMSECS

Columbia CVN (la oferta de cursos es de primer nivel y puedes usar la biblioteca del campus; prácticamente no hay diferencia con los estudiantes presenciales)

Boston OMSCS

UPenn MAS-CS Online (antes MCIT Online) — prefiere a quienes se cambian de carrera con GPA alto; no puedes haber tomado más de dos cursos de CS. Para Fall 2027, la fecha límite prioritaria es el 1 de marzo de 2027 y la fecha límite final es el 31 de mayo
