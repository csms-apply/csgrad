# Cronograma de búsqueda de empleo en EE. UU. para Summer 2026
Enero - junio de 2025: consigue unas prácticas en China

Junio - agosto de 2025: postula a las empresas que abren temprano sus puestos de SDE intern para el verano de 2026, como Google, DE Shaw, Citadel, etc.

Septiembre - diciembre de 2025: entrevistas. Empresas como TikTok envían invitaciones a entrevista temprano. Si consigues una oferta, ya puedes relajarte.

Enero - marzo de 2026: entrevistas. Si consigues una oferta, ya puedes relajarte. Si para marzo no tienes nada, empieza a buscar prácticas en China.

Marzo - mayo de 2026: relájate y disfruta.

Mayo - agosto de 2026: prácticas. Apunta a una oferta de retorno.

Agosto - diciembre de 2026: entrevistas new grad.
