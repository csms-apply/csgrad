# Cursos prerrequisito para cambiarse a CS

Últimamente varios estudiantes me han escrito sobre cambiarse a CS y conseguir prácticas. Noté que sus carreras de pregrado suelen ser Math/Statistics/EE y que quieren pasarse a CS durante el posgrado, idealmente obteniendo un título de CS (MSCS, MCS, etc.).

Este artículo trata sobre los cursos prerrequisito que necesitas tomar desde la perspectiva de aplicar a un programa de MSCS (usando como ejemplo el plan de estudios de pregrado de UIUC).


## Lenguajes de programación
Como todos saben, cualquier estudiante de CS aprende al menos un lenguaje de programación que las máquinas puedan ejecutar, como C++, C, Java, etc. Al cambiarte a CS, puedes empezar tomando un curso de C++/Java.
Curso de Java: CS 125 - Intro to Computer Science

## Cursos centrales de CS
El departamento de CS tiene muchos cursos, como Databases, Computer Networks, Operating Systems, Computer Architecture, Data Structures, Parallel Computing, Software Engineering, Machine Learning, etc. A continuación comento cuáles son esenciales y más útiles desde la perspectiva de la solicitud.

Resumen en una línea: Databases + Computer Networks + Operating Systems + Data Structures/Algorithms

Data Structures: CS 225 - Data Structures (al terminarlo, deberías poder practicar LeetCode con soltura)
Databases: CS 411 - Database Systems (al terminarlo, deberías dominar MySQL y entender conceptos como los índices de MySQL, o ser capaz de construir una base de datos desde cero)
Computer Networks: CS 438 - Communication Networks (al terminarlo, deberías entender qué pasa por detrás cuando abres una URL en el navegador)
Operating Systems: CS 423 - Operating Systems Design (al terminarlo, deberías entender la diferencia entre procesos e hilos y ser hábil depurando bugs de memoria en C++)

Si te queda tiempo y energía: (los siguientes son opcionales; tómalos si tienes tiempo y sáltalos si no)
Computer Architecture: CS 233 - Computer Architecture (al terminarlo, deberías entender cómo interactúan la CPU y los demás componentes de una computadora)
Software Engineering: CS 427 - Software Engineering I (construye un proyecto real listo para producción)
Compilers: CS 426 - Compiler Construction (construye un compilador sencillo)
CS 425 - Distributed Systems (implementa un almacén clave-valor distribuido)
