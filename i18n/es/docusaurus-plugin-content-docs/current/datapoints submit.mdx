# 📌 Guía de envío a la base de datos DataPoints

## 1. Aviso importante

**La base de datos DataPoints© es una tabla de solo lectura.**

Para agregar o actualizar contenido en estas 3 subtablas:

- DataPoints
- Información del solicitante
- Lista de programas

Hazlo siempre a través del **formulario de recolección (Form)** correspondiente, no modificando la base de datos directamente.

---

## 2. Proceso de envío

### Paso 1️⃣ Envía tu información de solicitante (una sola vez)

Primero completa tus datos personales en el **"Formulario de información del solicitante"**.

- ✅ Solo se envía una vez
- ❌ No se puede modificar después de enviarlo
- 🔗 Todos tus DataPoints posteriores quedarán vinculados a esta cuenta

---

### Paso 2️⃣ Envía tus DataPoints de admisión

Envía tus datos de admisión en el **"Formulario de DataPoints"**.

- Al llenarlo, vincula la información personal que enviaste antes mediante el **campo Solicitante**
- Admite **actualizaciones y modificaciones ilimitadas**

---

## 3. Agregar programas que no están en la lista

Si el programa al que aplicaste todavía no está en la base de datos:

1. Envía el programa con el formulario **"Agregar nuevo programa"**
2. Espera a que se apruebe
3. Después podrás buscarlo y seleccionarlo en el "campo Programa" cuando llenes futuros registros

---

## ✅ Resumen del flujo

Información del solicitante (una sola vez)
↓
DataPoints (se puede actualizar varias veces)
↓
Progreso (se puede actualizar varias veces)
↓
Si falta el programa → Agregar nuevo programa

---

Si tienes alguna pregunta, contacta al administrador.
