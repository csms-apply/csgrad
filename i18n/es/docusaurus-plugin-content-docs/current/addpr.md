# Contribuir contenido

## El proyecto CS Grad acepta contribuciones de contenido mediante Pull Requests
1. Primero, entra al [repositorio del proyecto CS Grad](https://github.com/csms-apply/csgrad) y haz clic en Fork

![Botón de fork del repositorio de CS Grad en GitHub](/img/en/fork.png)

2. Haz clic en Create fork para copiar el proyecto a tu propio repositorio

![Formulario de GitHub para crear el fork de CS Grad](/img/en/createfork.png)
