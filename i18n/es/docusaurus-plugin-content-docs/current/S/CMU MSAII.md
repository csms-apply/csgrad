# CMU MSAII

## Descripción del programa
Programa insignia de AI de SCS, orientado al empleo. Si quieres hacer investigación, mira mejor SCS MSR o MSML. El programa es muy flexible y amigable con quienes cambian de carrera: hay muchos casos de cambio de carrera desde todo tipo de formaciones. El director del departamento prefiere candidatos con números fuertes: cuanto más altos el GPA, el GRE y el TOEFL, mejor (TOEFL 105+, GRE 330+, GPA de primer nivel). Hay muchos cursos fáciles y de poca carga, y los 8 cupos de optativas se pueden llenar con cursos duros de sistemas de SCS: CC, ACC, OS y Storage están todos disponibles. Hay un curso Coding Bootcamp para practicar LeetCode, muy útil para conseguir puestos de SDE.
