## 收录口径

通过 Google 找到 LinkedIn 候选，再读取个人页的 Education 和 Experience，不使用 LinkedIn 站内搜索，也不以搜索摘要代替核验。部分候选在其他项目的搜索结果中出现，此情况在分组记录中明确说明。

“核验”指确认页面确实列出这些自述信息，不等于学校或雇主独立背书。只引用教育、职业与时间等有关字段；不推断申请季、申请时 GPA、录取条件、return offer、因果关系或整体就业率。未来结束日期是页面所列预计日期；Present 是核验当日页面状态。

新样本与旧匿名 DP 分开，未将个人主页映射到旧匿名案例。未重新验证原文所有历史叙述、学费、政策或就业率，因此新增来源不应被视为给整个旧页面背书。日期、职位类型或项目标签矛盾时，在正文或研究记录注明，不自行纠正来源。
