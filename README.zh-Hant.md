## 歡迎來到 CS Grad 項目

CS Grad 項目專注於北美 MSCS 申請，涵蓋 CS、DS、EE、ECE、IS 等相關專業的介紹。Motivation 是幫助來自 **中國大陸** 和 **北美本科** 的申請者更高效地瞭解各項目的定位及其 **實際價值**。與側重錄取門檻（admission bar）排名的 Open CS App 不同，CS Grad 更關注 **項目的真實價值**，尤其是在北美 **SDE求職** 方面的幫助，而 **非單純的錄取難度**。

此外，為了讓申請者更全面地評估各項目，我們引入了 **錄取數據點（admission DP）** 和 **求職數據點（job DP）**，以便直觀展示項目的錄取趨勢及其在求職市場的表現。畢竟，大多數人選擇前往美國攻讀 MSCS，歸根結底是為了找個班上，因此找工dp也是申請中不可忽視的關鍵因素。

## CS Grad 與 Open CS 的區別

如前所述，Open CS 主要基於 **錄取門檻** 進行排名，尤其針對 **陸本申請者**，但這未必能準確反映項目的 **實際價值**。某些項目對 **美本** 申請者較為友好，卻對 **陸本** 申請者不甚友好（比如NWU MSCS和UIUC MCS）。而一些項目雖然錄取門檻友好(bar低)，
但是項目的出路卻非常好(比如UW EE PMP)。CS Grad 項目則重點關注 **項目的實際價值**，幫助申請者更理性地評估擇校策略。

基於這一初衷，我開發了 CS Grad 項目，希望能夠為大家提供更具實用性的申請和擇校參考。



## 項目梯度計算方式

項目梯度是由前期的幾個核心contributor討論計算得出的，具體來說考慮的核心因素有：
院校綜合排名+專業排名、專業找工數據（找工數據和dp已經部分放到了正文中）、轉博/讀博情況（比如brown scmcs這種適合讀博向）、生活體驗(比如ucsd 生活體驗感拉滿)、經濟因素（比如gatech mscs非常經濟友好）、地理位置（比如在紐約的Columbia 和NYU的地理位置就非常好）、畢業靈活性（比如UT ECE畢業靈活性非常友好）、課程硬核程度（比如CMU MCDS、MSIN的課程非常system，很硬核）、TA/RA是否對MS在讀生友好等。**同時again，該項目梯度是由我和幾個前期的核心
contributor討論計算得出的，難免會有bias，歡迎大家提pr修正**

## CS選校之禪

1. 人是過去經歷的總和, 沒有什麼項目能徹底改變人生，真正能改變的是不斷向上、積極求索的自己
2. 越是人生中重要的選擇，越不需要聽從別人的指引、或者進行過量的分析，反而要耐心聽取自己內心的直覺。大方向要憑本能，具體操作才要靠理性
3. 不是bar 越高的項目越適合你
4. 讀研只是實現人生理想的方法，讀研不是避風港，人生也不會永遠靜止在拿到offer的那一天
